## Struttura dello spazio di lavoro [#workspace-structure]

| Oggetto | Scopo |
| --- | --- |
| Progetto | Una cartella locale o connessione SSH, organizzata in gruppi nella barra laterale |
| Sessione | Una scheda di progetto che puoi rinominare, colorare, fissare e raggruppare |
| Pannello | Un terminale, browser, editor o diff all'interno di una scheda; dividi i pannelli per lavorare affiancati |
