---

<Accordions>

<Accordion title="Zshell ฟรีหรือไม่?">

ฟรี ดาวน์โหลดได้โดยไม่มีค่าใช้จ่าย ซอร์สเปิดเผยภายใต้ PolyForm Noncommercial License 1.0.0 ไม่ต้องมีบัญชีหรือสมาชิก

</Accordion>

<Accordion title="มันแทนที่ shell ของฉันหรือไม่?">

ไม่ Zshell เป็นที่รัน shell เดิมของคุณ โดยเริ่ม `$SHELL -l` และคงพรอมป์ alias ฟังก์ชัน และ dotfile ไว้ ช่องเทอร์มินัลเลือกใช้ backend Ghostty หรือ Alacritty ได้

</Accordion>

<Accordion title="มีการเก็บข้อมูลหรือไม่?">

ไม่มี telemetry หรือการวิเคราะห์พฤติกรรม การตรวจอัปเดตค้นหาประเทศจาก IP เครือข่ายเพื่อเลือก GitHub หรือ Gitee แล้วโหลดฟีดรุ่น ปิดการตรวจอัตโนมัติใน **การตั้งค่า → การอัปเดต** เพื่อหยุดคำขอเบื้องหลัง การตรวจด้วยตนเองยังส่งคำขอเหล่านี้ ดู[การอัปเดต](/th/docs/installation#updates) หน้าคำแนะนำตรวจเวอร์ชันเครื่องมือขณะเปิดอยู่

หน้าใน[ช่องเบราว์เซอร์](/th/docs/browser) และ CLI เอเจนต์ที่คุณรันส่งคำขอตามการใช้งานของคุณเอง เหมือนรันนอก Zshell

</Accordion>

<Accordion title="อ่านการตั้งค่า Ghostty หรือ Alacritty ของฉันไหม?">

ไม่ Backend ฟอนต์ สี และพฤติกรรมอินพุตมาจาก[การตั้งค่า](/th/docs/configuration) ของ Zshell เอง ไม่โหลดไฟล์ตั้งค่าของแอปเทอร์มินัลทั้งสอง

</Accordion>

<Accordion title="เซสชันเป็นอย่างไรเมื่อออกจากแอป?">

โปรเจกต์ แท็บ และเค้าโครงกลับมาเมื่อเปิดใหม่ แต่ละเทอร์มินัลเปิด shell ใหม่ในไดเรกทอรีเดิม ไม่มีอะไรทำงานเบื้องหลังหลังออก

เอาต์พุตเดิมกลับมาด้วยหากเปิด [`terminal.restore-history`](/th/docs/configuration#terminalrestore-history) โดยแสดงเป็นข้อความนิ่งเหนือเส้น `Session Contents Restored`

</Accordion>

<Accordion title="นี่คือ IDE หรือไม่?">

ไม่ และไม่ได้พัฒนาไปทางนั้น เทอร์มินัลยังเป็นศูนย์กลาง แผง Git และไฟล์ช่วยตรวจและส่งมอบสิ่งที่เกิดในเทอร์มินัลโดยไม่สลับแอป ไม่ได้มีไว้เป็นพื้นที่ทำงานหลัก

</Accordion>

<Accordion title="ทำไมต้องถามก่อนโปรแกรมอ่านคลิปบอร์ด?">

เพราะโปรแกรมร้องขอ ลำดับ escape `OSC 52` ให้โปรแกรมเทอร์มินัลอ่านคลิปบอร์ดระบบได้ รวมโปรแกรมบนโฮสต์ระยะไกลผ่าน SSH Zshell ยืนยันกับคุณก่อนแทนส่งให้เงียบ ๆ ซึ่งเป็นค่าเริ่มต้นเดียวกับ Ghostty

</Accordion>

<Accordion title="ใช้กับเอเจนต์เขียนโค้ด AI ได้ไหม?">

ได้ การผสาน AI เปิดโดยค่าเริ่มต้น ขอเอเจนต์ที่รองรับด้วยภาษาปกติให้รันงานในช่องเบื้องหลังหรือมอบหมายงานที่มีขอบเขต เอเจนต์ต่างช่องยังแลกคำถาม ข้อค้นพบ และคำขอต่อได้โดยไม่ให้คุณคัดลอกบริบท Zshell แสดงสถานะทำงาน/ติดขัด/เสร็จที่ผู้ให้บริการรายงาน ไม่เดาจากข้อความเทอร์มินัล และคุณคงควบคุมการอนุมัติและ diff สุดท้าย ดู[ทำงานร่วมกับเอเจนต์ AI](/th/docs/automation)

ยังใช้เอเจนต์เป็นโปรแกรมเทอร์มินัลปกติได้ ตรวจ diff ใน[แผง Git](/th/docs/git) อ่านไฟล์ข้างมัน แล้ว stage เฉพาะที่ต้องการ

</Accordion>

<Accordion title="รายงานบั๊กที่ไหน?">

เปิด issue บน [GitHub](https://github.com/wzz6423/zshell/issues) โดยปกติเวอร์ชัน macOS และสิ่งที่ทำขณะเกิดปัญหาก็เพียงพอให้เริ่มตรวจ

</Accordion>

</Accordions>
