---
title: Быстрый запуск
description: Сохраните часто запускаемые команды и SSH-подключения и открывайте любое из них одним нажатием.
---

<kbd>Cmd</kbd>+<kbd>O</kbd> открывает **Быстрый запуск**: список записей с поиском, каждая из которых открывает новый проект с терминальным сеансом. Сохранённая запись — это либо **команда**, которую вы часто вводите, например `npm run dev` или `make watch`, либо **SSH-подключение**.

## Запуск [#launching]

Введите название, команду, адрес подключения или группу для нечёткого поиска по списку. Нажмите на строку или выберите её клавишами со стрелками и нажмите <kbd>Return</kbd>. Запись запускается в новом проекте с её названием, собственным терминальным сеансом и каталогом.

Когда команда завершится или соединение закроется, панель вернётся к обычному приглашению оболочки, а не исчезнет. Ни один запущенный таким образом сеанс не сможет незаметно закрыть свою панель.

Сохранённую запись также можно запустить по имени из любого терминала Zshell:

```bash
zshell "Entry name"
```

Укажите точное имя записи, заключив его в кавычки, если в нём есть пробелы. Этот синтаксис показан в подсказке внизу окна быстрого запуска. Запись откроется в новом проекте.

## Управление записями [#managing-entries]

- <kbd>Cmd</kbd>+<kbd>N</kbd> — новая запись
- <kbd>Cmd</kbd>+<kbd>E</kbd> — изменить выбранную запись
- <kbd>Cmd</kbd>+<kbd>Delete</kbd> — удалить выбранную запись

Используйте необязательное поле **Группа**, чтобы объединять записи в именованные разделы. Кнопки редактирования и удаления действуют на свою запись, не запуская её.

Для команды можно закрепить **рабочий каталог**, в котором она будет запускаться всегда; иначе используется каталог по умолчанию для нового проекта. Для SSH-подключения задаются хост, необязательные пользователь и порт, а также произвольные дополнительные параметры `ssh`, например `-L 8080:localhost:80`.

## Где хранятся записи [#where-entries-live]

Записи сохраняются в `~/.config/zshell/quick-launch.json` и доступны во всех окнах. Это обычные пользовательские данные — файл можно свободно редактировать или копировать для резервного хранения.

<Callout type="info">
Команды выполняются через вашу оболочку входа и получают окружение из её профиля. После этого панель остаётся обычным сеансом с привычными псевдонимами и приглашением.
</Callout>
