---
title: よくある質問
description: 料金、プライバシー、Zshell とシェルの関係についてのよくある質問。
---

<Accordions>

<Accordion title="Zshell は無料ですか？">

はい。無料でダウンロードできます。ソースコードは PolyForm Noncommercial License 1.0.0 のもとで公開されており、アカウントやサブスクリプションは不要です。

</Accordion>

<Accordion title="使用中のシェルは置き換わりますか？">

いいえ。Zshell は既存のシェルを実行します。`$SHELL -l` を起動し、プロンプト、エイリアス、関数、設定ファイルは変更しません。ターミナルのバックエンドには Ghostty または Alacritty を使えます。

</Accordion>

<Accordion title="データは収集されますか？">

テレメトリや分析機能はありません。更新確認は接続元 IP の国情報で GitHub と Gitee を選び、リリースフィードを取得します。
**設定 → 更新**で自動確認をオフにすると、これらのバックグラウンド通信が停止します。手動確認では引き続き通信します。[更新](/ja/docs/installation#updates)を参照してください。
おすすめのページは開いている間、ツールのバージョンを確認します。

[ブラウザペイン](/ja/docs/browser)で開くページと実行するエージェント CLI は、Zshell の外で使うときと同様、ユーザーの操作に応じてそれぞれ通信します。

</Accordion>

<Accordion title="Ghostty や Alacritty の設定を読み込みますか？">

いいえ。バックエンド、フォント、色、入力動作には Zshell 自身の[設定](/ja/docs/configuration)を使います。どちらのターミナルアプリの設定ファイルも読み込みません。

</Accordion>

<Accordion title="終了するとセッションはどうなりますか？">

再起動時にプロジェクト、タブ、ペイン配置が戻り、各ターミナルは以前のディレクトリで新しいシェルを起動します。終了後にバックグラウンドで動き続ける処理はありません。

[`terminal.restore-history`](/ja/docs/configuration#terminalrestore-history) を有効にすると、過去のスクロールバックも戻ります。`Session Contents Restored` の区切りより上に静的なテキストとして表示されます。

</Accordion>

<Accordion title="これは IDE ですか？">

いいえ。その方向を目指してもいません。ターミナルが常に中心です。Git とファイルのパネルは、別のアプリに切り替えずにターミナルでの作業をレビューし、成果を届けるためのもので、主な作業場所になることを目的としていません。

</Accordion>

<Accordion title="プログラムのクリップボード読み取りで確認画面が出たのはなぜですか？">

プログラムが読み取りを要求したためです。`OSC 52` エスケープシーケンスにより、SSH 先のプログラムも含め、ターミナル内のプログラムはシステムのクリップボードを読めます。
Zshell は黙って渡さず、先に確認します。Ghostty と同じ標準動作です。

</Accordion>

<Accordion title="AI コーディングエージェントと使えますか？">

はい。AI 連携は標準で有効です。対応エージェントに、バックグラウンドのペインで処理を実行したり、範囲を絞った作業を分担したりするよう自然な言葉で依頼できます。
別々の Zshell ペインのエージェント同士で質問、発見、追加の依頼を交換できるため、手作業で文脈をコピーする必要が減ります。
Zshell はターミナルの文字から推測せず、提供元が報告する実行中・停止中・完了の状態を表示します。承認と最終的な差分の判断は引き続きあなたが行います。[AI エージェントとの作業](/ja/docs/automation)を参照してください。

通常のターミナルプログラムとしてもエージェントを使えます。[Git パネル](/ja/docs/git)で差分を確認し、隣でファイルを読み、必要な変更だけをステージしてください。

</Accordion>

<Accordion title="不具合はどこへ報告しますか？">

[GitHub](https://github.com/wzz6423/zshell/issues) に課題を作成してください。通常は macOS のバージョンと、発生時に行っていた操作があると調査を始められます。

</Accordion>

</Accordions>
