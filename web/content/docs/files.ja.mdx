<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> でファイルツリーを開きます。
Git パネルと同じく[プロジェクトディレクトリ](/ja/docs/projects#the-project-directory)をルートとするため、`cd` のたびにルートが変わることはありません。

## ツリー [#the-tree]

ファイルをクリックすると、フォーカス中のペインに開きます。その他の操作は右クリックで表示します。

| 項目 | 動作 |
| --- | --- |
| **開く（Open）**／**横に開く（Open to the Side）** | 現在のペイン、または新しい分割に開きます |
| **デフォルトのアプリで開く（Open in Default App）** | macOS に登録されたアプリへ渡します |
| **Finder に表示（Reveal in Finder）** | |
| **パスをコピー（Copy Path）** | 絶対パスをコピーします |
| **ここに cd（cd Here）** | フォーカス中のターミナルで `cd <folder>` を実行します |
| **新規ファイル…（New File…）**／**新規フォルダ…（New Folder…）** | 選択中のフォルダ内に作成します |
| **名前を変更（Rename）** | |
| **ゴミ箱に入れる（Move to Trash）** | 完全削除せずゴミ箱に移動します |

行にはファイル名に応じた Material アイコンを表示します。Git リポジトリでは、変更されたパスに状態を示す色とバッジを付け、無視されたファイルは薄く表示します。Git パネルを開かなくても、同じワークツリーの状態を確認できます。

## ファイルと内容の検索 [#find-files-and-search-contents]

コマンドパレット（<kbd>Cmd</kbd>+<kbd>P</kbd>）では、コマンドや開いているセッションとともに、現在のウィンドウで開かれているローカルプロジェクトのファイルを名前やパスで検索できます。
ファイルを選ぶと、そのプロジェクトへ切り替えて開きます。

ファイル内のテキストを検索するには、ファイルパネルの虫眼鏡をクリックするか、コマンドパレットで<strong>ファイル内容を検索（Search File Contents）</strong>を選びます。
テキストを入力し <kbd>Return</kbd> を押すと、現在のローカルプロジェクトディレクトリを検索します。<strong>Aa</strong> で大文字小文字を区別でき、結果を開くとエディタ内の該当行へ移動します。

内容検索は文字列をそのまま照合し、バイナリファイルや一般的な依存関係・ビルド用フォルダを除外し、2,000 件で停止します。
結果を残したまま検索を中止したり、検索を閉じてファイルツリーに戻ったりできます。これらのローカル検索に SSH プロジェクトは含まれません。

## エディタ [#the-editor]

ファイルを開くと、ペイン内でシンタックスハイライト付きのエディタを使用できます。

| 操作 | ショートカット |
| --- | --- |
| 保存 | <kbd>Cmd</kbd>+<kbd>S</kbd> |
| 検索 | <kbd>Cmd</kbd>+<kbd>F</kbd> |
| 検索と置換 | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> |
| 次を検索 | <kbd>Cmd</kbd>+<kbd>G</kbd> |

長い行は標準でペイン幅に折り返します。横スクロールを使うには [`editor.wrap-lines`](/ja/docs/configuration#editorwrap-lines) を無効にします。

ツリーでファイル名を変更すると、開いているすべてのペインに反映されます。名前を変えたフォルダ配下のファイルも対象です。

別のプログラムが開いているファイルを変更した場合、Zshell が再びアクティブになると、未編集のプレビューを更新します。未保存の変更がある編集バッファは上書きしません。

<Callout type="info">
このエディタは、今見ている変更に対処するためのものです。誤字を直す、定数を変える、差分で参照されたファイルを読む、といった用途を想定しています。言語サーバー、補完、プロジェクト全体のリファクタリングは、意図的に備えていません。
</Callout>

## Markdown プレビュー [#markdown-preview]

`.md` ファイルを開くと、同じペインにレンダリング結果を表示します。右上の<strong>編集（Edit）</strong>でソースを編集し、<strong>プレビュー（Preview）</strong>で結果を確認できます。
選んだ表示モードは、ほかの Markdown ファイルや次回起動時にも使われます。

モードを切り替えても編集内容と取り消し履歴は保持されます。変更は通常どおり <kbd>Cmd</kbd>+<kbd>S</kbd> で保存します。別の拡張子の Markdown ファイルはソースとして開きます。

## 差分 [#diffs]

[Git パネル](/ja/docs/git)から開く差分も通常のペインなので、1 つのタブに差分、ファイル、ターミナルを並べられます。
ターミナルのフォントを使用し、1,000 ファイルの変更でも 1 行の変更と同じように素早く開きます。
現在のワークツリーの未ステージ差分は、確認から編集へ切り替えることもできます。ステージ済みや過去の差分は読み取り専用です。[差分を読む](/ja/docs/git#reading-diffs)を参照してください。
