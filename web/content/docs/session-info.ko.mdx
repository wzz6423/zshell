<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd>를 누르세요. 정보 패널은 프로젝트가 아닌 **포커스된 세션**을 보여 주며, 작업의 시작과 종료에 맞춰 갱신됩니다.

## 디렉터리 [#directory]

두 디렉터리는 항상 같지는 않으므로 구분하여 표시합니다.

- **현재 디렉터리** — 셸의 현재 작업 디렉터리입니다. 아래 디렉터리와 다를 때 표시됩니다.
- **프로젝트 디렉터리** — 파일 및 Git 패널의 기준 폴더입니다. Zshell이 자동으로 정하는 경우 `(AUTO)` 표시가 붙습니다. `?` 팝오버에서 두 디렉터리를 설명합니다.

옆에는 **Finder**에서 폴더 보기, 설치된 **VS Code**에서 열기, 경로 **복사** 단축 동작이 있습니다.

## 프로세스 [#processes]

세션 셸 아래에서 실행 중인 모든 프로세스와 각 PID, CPU 사용률, 상주 메모리를 표시합니다. 프로세스를 오른쪽 클릭하면 다음 작업을 할 수 있습니다.

- **종료** — 정상 종료를 요청하는 `SIGTERM` 전송
- **강제 종료** — 종료 요청에 응답하지 않을 때 `SIGKILL` 전송
- **PID 복사** / **실행 파일 경로 복사**

이미 종료되었지만 아직 회수되지 않은 자식 프로세스(`<defunct>`)는 제외합니다. 확인하거나 종료할 실행 작업이 없기 때문입니다.

## 포트 [#ports]

해당 프로세스가 수신 대기 중인 모든 TCP 포트와 포트를 소유한 프로세스를 보여 줍니다. *이번에 개발 서버가 어떤 포트를 골랐는지*, *아직 3000번 포트를 점유하는 것이 무엇인지* 확인할 때 유용합니다.

- 포트를 클릭하면 브라우저에서 `http://localhost:<port>/`을 엽니다.
- **URL 복사**
- **프로세스 강제 종료** — 포트를 점유한 원인이 잊고 있던 프로세스일 때 사용합니다.
