## 工作區結構 [#workspace-structure]

| 對象 | 用途 |
| --- | --- |
| 專案 | 本地目錄或 SSH 連線；在側邊欄中分組管理 |
| 工作階段 | 專案中的分頁，可重新命名、標色、固定和分組 |
| 窗格 | 分頁內的終端機、瀏覽器、編輯器或 diff，可分割畫面排列 |
