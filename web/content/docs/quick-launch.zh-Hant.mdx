---
title: 快速啟動
description: 把反復使用的指令和 SSH 連線存成條目，一鍵啟動。
---

<kbd>Cmd</kbd>+<kbd>O</kbd> 打開**快速啟動**：一個可搜尋的啟動條目列表，每一條都會新建一個專案，並打開終端機工作階段。條目要麼是**指令**——任何你經常敲的東西，比如 `npm run dev`、`make watch`——要麼是 **SSH 連線**。

## 啟動 [#launching]

輸入名稱、指令、連線目標或分組名即可模糊過濾。單擊條目，或用方向鍵選中後按 <kbd>Return</kbd>，條目會在以它命名的新專案裡執行，有自己的終端機工作階段和工作目錄。

指令結束或連線斷開後，面板會落回一個正常的 shell 提示符，而不是整個消失。你啟動的東西不會悄悄把自己關掉。

也可以在 Zshell 終端機裡按名稱執行已儲存的條目：

```bash
zshell "指令名"
```

名稱須與儲存的條目名稱完全一致，包含空格時加引號。快速啟動底部也會提示這一用法。條目會在新專案裡打開。

## 管理條目 [#managing-entries]

- <kbd>Cmd</kbd>+<kbd>N</kbd>——新建條目
- <kbd>Cmd</kbd>+<kbd>E</kbd>——編輯選中的條目
- <kbd>Cmd</kbd>+<kbd>Delete</kbd>——刪除選中的條目

填寫可選的**分組**字段，可以把條目整理到命名分區。行內的編輯和刪除按鈕只操作對應條目，不會啟動它。

指令條目可以固定一個**工作目錄**，每次都從這裡啟動；不填就使用新專案的預設目錄。SSH 條目填主機、可選的使用者和連接埠，外加自由格式的 `ssh` 參數，比如 `-L 8080:localhost:80`。

## 條目存在哪 [#where-entries-live]

條目儲存在 `~/.config/zshell/quick-launch.json`，所有視窗共用。就是一份普通的使用者資料——直接編輯檔案或備份都行。

<Callout type="info">
指令通過你的登錄 shell 執行，能看到你 profile 裡的環境。指令跑完之後，面板就是一個正常的工作階段，別名和提示符原樣都在。
</Callout>
