## Проекты [#projects]

Проект — отдельная задача, на практике обычно один репозиторий, со своими терминалами, вкладками и состоянием панелей.

<kbd>Cmd</kbd>+<kbd>N</kbd> создаёт проект с одним терминалом. Терминал запускается в каталоге текущего сеанса, а если его нет — в домашнем каталоге. Обычно следующим шагом вы переходите в нужную папку командой `cd`. После этого Zshell привязывает дерево файлов и панель Git к репозиторию, содержащему этот каталог.

Чтобы обойтись без `cd`, нажмите папку в Finder правой кнопкой и выберите **Службы → Новый проект Zshell здесь**: откроется проект с терминалом, уже запущенным в этой папке.

В Zshell переключение работы происходит между проектами:

| Действие | Сочетание клавиш |
| --- | --- |
| Новый проект | <kbd>Cmd</kbd>+<kbd>N</kbd> |
| Перейти к проекту 1–9 | <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> |
| Следующий / предыдущий проект | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> |
| Скрыть боковую панель проектов | <kbd>Cmd</kbd>+<kbd>B</kbd> |

Имя проекта берётся из выбранного сеанса и следует за терминалом так же, как заголовок вкладки. В контекстном меню проекта доступны **Переименовать…**, **Использовать автоматический заголовок** для отмены ручного имени, **Задать каталог проекта…** и **Закрыть проект**. Закрытие проекта завершает его сеансы, но ничего не меняет на диске.

### Сохранённые SSH-проекты [#saved-ssh-projects]

Откройте палитру команд (<kbd>Cmd</kbd>+<kbd>P</kbd>) и выберите **Новый SSH-проект…**. Укажите хост, при необходимости пользователя и порт, а также удалённый каталог. Для аутентификации выберите **SSH-агент**, **Пароль**, **Файл закрытого ключа** или **Текст закрытого ключа**, сохраните подключение и нажмите **Подключиться**.

Сохранённые подключения доступны после перезапуска. Необязательное поле **Группа** помогает организовать список; кнопки редактирования и удаления позволяют управлять записями. Пароли и вставленные закрытые ключи сохраняются в Связке ключей macOS; для файла ключа сохраняется путь к существующему файлу.

Запуск команд и SSH с дополнительными параметрами описан в разделе [Быстрый запуск](/ru/docs/quick-launch).

### Группы боковой панели [#sidebar-groups]

Кнопка **Новая группа** внизу боковой панели создаёт **Обычную группу** или **Группу папки…**. Обычная группа запускает новые терминалы в домашнем каталоге; группа папки использует выбранную папку по умолчанию. Явно заданный каталог проекта имеет приоритет. Перемещение проекта между группами не влияет на работающие терминалы и не заменяет закреплённый каталог.

Перетащите проект на заголовок группы или другой проект, чтобы организовать список. Перетаскивание на **+ (Новый проект)** внизу боковой панели убирает проект из группы. Заголовки групп тоже можно перетаскивать для изменения порядка. Щёлкните заголовок, чтобы свернуть или развернуть группу, дважды щёлкните для переименования либо используйте контекстное меню. **Задать цветовую метку…** назначает цвет, **Убрать цветовую метку** удаляет его. **Удалить группу** оставляет все её проекты открытыми. Числовые сочетания клавиш соответствуют видимым строкам проектов; переход к следующему или предыдущему проекту может раскрыть участника свёрнутой группы.

Папки из Finder можно перетащить в любое место списка проектов. Если папка уже открыта, Zshell перейдёт к ней вместо создания дубликата.

### Каталог проекта [#the-project-directory]

Дереву файлов и панели Git нужно знать, какую папку показывать. По умолчанию Zshell берёт текущий каталог терминала и поднимается до **ближайшего содержащего его репозитория Git**.

Поэтому переходы `cd` внутри репозитория не меняют корень дерева файлов: им остаётся корень репозитория. Вне репозитория панели просто следуют за терминалом.

Когда программа на переднем плане переходит в другую рабочую копию, например агент — в собственное рабочее дерево Git, панели «Файлы», Git и «Информация» следуют за этой копией. Они возвращаются, когда возвращается задача переднего плана. Закреплённый вручную каталог проекта всегда имеет приоритет и отключает автоматическую смену корня.

Чтобы закрепить каталог, нажмите проект правой кнопкой и выберите **Задать каталог проекта…**. Папка сохраняется после перезапуска; **Использовать автоматический каталог** возвращает автоматический выбор.

<Callout type="info">
Панель «Информация» (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd>) показывает оба пути: актуальный **Текущий каталог** оболочки, когда он отличается, и **Каталог проекта**, к которому привязаны панели. Автоматически определённый каталог отмечен `(AUTO)`.
</Callout>

## Сеансы [#sessions]

Проект может содержать сколько угодно сеансов, показанных вкладками вверху. Сеанс — настоящая оболочка входа, например `zsh`, `fish` или `bash`, заданная для вашей учётной записи, со своим рабочим каталогом и историей вывода.

| Действие | Сочетание клавиш |
| --- | --- |
| Новый сеанс | <kbd>Cmd</kbd>+<kbd>T</kbd> |
| Перейти к вкладке 1–9 | <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> |
| Переключатель вкладок по недавнему использованию | <kbd>Ctrl</kbd>+<kbd>Tab</kbd> |
| Следующая / предыдущая вкладка | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> |
| Закрыть панель в фокусе | <kbd>Cmd</kbd>+<kbd>W</kbd> |

Новый локальный сеанс запускается в закреплённом каталоге проекта, если он задан, иначе — в каталоге по умолчанию группы боковой панели. Если нет ни того, ни другого, он наследует каталог текущего сеанса и при необходимости использует домашний каталог.

### Группы вкладок [#tab-groups]

Нажмите вкладку правой кнопкой и выберите **Переместить в группу → Новая группа вкладок**. Вкладка войдёт в новую группу, обозначенную цветной стрелкой без имени. Новые сеансы из сгруппированной вкладки остаются в этой группе; для непосредственного создания сеанса внутри группы нажмите её стрелку правой кнопкой и выберите **Новый сеанс в группе**.

Перетащите вкладку на стрелку группы или другую вкладку, чтобы переместить её. Контекстное меню также содержит список групп и **Удалить из группы**. Нажатие стрелки сворачивает или разворачивает группу. Сворачивание сохраняет активный терминал работающим и видимым; переход к скрытой вкладке разворачивает группу. Удаление группы оставляет вкладки и сеансы открытыми. Закрепление сгруппированной вкладки переносит её в фиксированную область вне групп. Контекстное меню стрелки содержит **Задать цветовую метку…** и **Убрать цветовую метку**. Цвет и состояние сворачивания восстанавливаются после перезапуска Zshell.

Вкладку можно перетащить на проект боковой панели или на заголовок группы, чтобы создать в ней новый проект. Перетаскивание на **+ (Новый проект)** внизу боковой панели создаёт проект вне всех групп. **Переместить вкладку в проект** в меню вкладки позволяет выбрать и проект другого окна. Такие перемещения сохраняют работающие терминалы и расположение панелей. Проекты должны иметь одинаковое локальное или SSH-расположение; новый проект из вкладки сохраняет исходное расположение. Вкладки со сравнениями остаются в текущем проекте.

### Заголовки вкладок [#tab-titles]

Заголовок вкладки задаётся терминалом: управляющей последовательностью приглашения оболочки или работающей программой. В контекстном меню выберите **Переименовать…** для ручного имени и **Использовать автоматический заголовок**, чтобы снова следовать за терминалом.

Остальное меню содержит **Закрыть**, **Закрыть другие**, **Закрыть вкладки справа**, **Закрыть все**, а также **Показать в Finder** и **Скопировать абсолютный путь** для каталога сеанса. **Закрыть файлы** и **Закрыть сравнения** убирают соответствующий тип содержимого во всём проекте, сохраняя терминалы и панели браузера.

## Окна [#windows]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> открывает ещё одно окно. Окна независимы: у каждого свои проекты и состояние боковых панелей; каждое восстанавливается отдельно.

## Что сохраняется после перезапуска [#what-survives-a-relaunch]

Zshell сохраняет снимок расположения во время работы. После закрытия и повторного открытия восстанавливаются:

- все проекты в исходном порядке;
- все вкладки, включая ручные имена, закрепление и цветовые метки;
- группы боковой панели с именами, цветами, порядком, составом и состоянием сворачивания;
- группы вкладок с цветами, порядком, составом и состоянием сворачивания;
- закреплённые каталоги и пустые проекты;
- расположение панелей внутри вкладок;
- открытые боковые панели и выбранная правая панель.

Терминалы возвращаются как **новые оболочки** в прежних каталогах. Zshell не оставляет процессы работать в фоне: сборка, выполнявшаяся при выходе, завершается вместе с приложением.

Предыдущий вывод восстанавливается только при включении [`terminal.restore-history`](/ru/docs/configuration#terminalrestore-history). По умолчанию это выключено, поскольку восстанавливаемая история хранится на диске.

## Окружение терминала и инициализация [#terminal-environment-and-initialization]

Выберите проект и откройте **Терминал → Окружение терминала проекта…**, чтобы задать переменные окружения и команду инициализации. Для переопределений текущей вкладки используйте **Терминал → Окружение терминала вкладки…**.

| Область | Поведение |
| --- | --- |
| Проект | Новые терминалы проекта наследуют его переменные и команду инициализации |
| Вкладка | Переменные заменяют одноимённые значения проекта; команда может наследовать, заменять или отключать команду проекта |

Изменения действуют только на терминалы, созданные после сохранения. Существующие процессы сохраняют своё окружение. Инициализация выполняется для обычной оболочки входа, но не для пользовательской программы запуска или явно заданного argv.
`ZSHELL_*`, `TERM`, `COLORTERM`, `TERM_PROGRAM` и `TERM_PROGRAM_VERSION` управляются Zshell и не могут быть переопределены.
