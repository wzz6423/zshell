---
title: Scorciatoie da tastiera
description: Tutte le scorciatoie predefinite di Zshell, raggruppate per funzione.
---

Ne hai dimenticata una? <kbd>Cmd</kbd>+<kbd>P</kbd> apre la palette e mostra la scorciatoia accanto a ogni comando.

## Terminale rapido globale [#global-quick-terminal]

| Scorciatoia | Azione |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>I</kbd> | Mostra / chiudi Terminale rapido |
| <kbd>Esc</kbd> | Chiudi Terminale rapido e termina la shell |

Registra un'altra combinazione in **Impostazioni → Terminale → Terminale rapido**. Un terminale non fissato si chiude anche quando perde il focus. Vedi [Terminale rapido](/it/docs/terminal#global-quick-terminal).

## Progetti e sessioni [#projects-and-sessions]

| Scorciatoia | Azione |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>N</kbd> | Nuovo progetto |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | Nuova sessione |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | Nuova finestra |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | Chiudi il pannello attivo |
| <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Passa al progetto 1–9 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Progetto successivo / precedente |
| <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Passa alla scheda 1–9 |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Selettore di schede per utilizzo recente |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Scheda successiva / precedente |

## Pannelli [#panes]

| Scorciatoia | Azione |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Dividi a destra |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Dividi in basso |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+frecce | Attiva il pannello in quella direzione |
| <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> | Alterna il focus dei pannelli |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> | Attiva/disattiva l'ingrandimento |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+frecce | Ridimensiona il pannello attivo |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> | Uniforma i pannelli |

Dividere a sinistra e in alto non ha scorciatoie predefinite: usa **Schede**, il menu contestuale del pannello o la palette.

| Scorciatoia | Azione |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>P</kbd> | Palette dei comandi |
| <kbd>Cmd</kbd>+<kbd>O</kbd> | Avvio rapido |
| <kbd>Cmd</kbd>+<kbd>B</kbd> | Mostra/nascondi la barra sinistra |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | Mostra/nascondi la barra destra |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Pannello Git |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Pannello File |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | Pannello Info |

## Browser e agenti [#browser-and-agents]

| Scorciatoia | Azione |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>L</kbd> | Attiva l'indirizzo del browser corrente |
| <kbd>Cmd</kbd>+<kbd>R</kbd> | Ricarica la pagina corrente |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Passa al prossimo agente che richiede attenzione |

Nuove schede e pannelli browser non hanno scorciatoie predefinite; usa **File** o la palette.

## Testo e ricerca [#text-and-search]

| Scorciatoia | Azione |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>F</kbd> | Cerca nel pannello attivo |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> | Trova e sostituisci nell'editor |
| <kbd>Cmd</kbd>+<kbd>G</kbd> | Trova successivo |
| <kbd>Shift</kbd>+<kbd>Return</kbd> | Trova precedente dalla barra di ricerca |
| <kbd>Cmd</kbd>+<kbd>E</kbd> | Usa la selezione per cercare |
| <kbd>Cmd</kbd>+<kbd>K</kbd> | Pulisci il terminale |
| <kbd>Cmd</kbd>+<kbd>S</kbd> | Salva il file aperto |
| <kbd>Cmd</kbd>+<kbd>,</kbd> | Impostazioni |

## Trova precedente [#find-previous]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> è la solita scorciatoia macOS per Trova precedente, ma in Zshell apre o chiude Git. Usa <kbd>Shift</kbd>+<kbd>Return</kbd> nella barra di ricerca; funziona anche la voce in **Modifica → Trova**.
