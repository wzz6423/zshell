每个终端窗格都运行你真正的登录 shell，并使用两个原生 GPU 加速后端之一。窗格焦点、搜索、通知、链接、历史、主题和粘贴安全由 Zshell 统一管理，所以无论选哪个模拟器，外围行为都一致。

## 终端后端

在 **设置 → Terminal → Backend** 里选择：

| 后端 | 说明 |
| --- | --- |
| **Ghostty** | 默认选项 |
| **Alacritty** | 通常占用更少内存 |

两者都支持 GPU 加速、图片渲染、Zshell 的共享主题目录、查找、鼠标上报、通知和进度。后端改动只影响之后新建的终端；已有窗格继续使用启动时的模拟器。

## 你的 shell，原封不动

每个会话启动你账户的登录 shell，所以提示符、别名、函数和 dotfiles 都和其他终端里一样加载。
Zshell 额外设置了能力与身份变量：

| 变量 | 值 |
| --- | --- |
| `TERM_PROGRAM` | `ghostty` |
| `TERM_PROGRAM_VERSION` | Zshell 实现的 Ghostty 能力版本 |
| `ZSHELL_TERM` | `ghostty` 或 `alacritty`，也就是窗格实际使用的后端 |

两个后端都通过 `TERM_PROGRAM` 声明 Ghostty，因为支持图片和通知的 CLI 会把它当作能力提示。只有确实需要区分渲染器时，才看 `ZSHELL_TERM`。

<Callout type="info">
Zshell 不读取 `~/.config/ghostty`，也不读取 Alacritty 配置。字体、颜色、输入行为和后端都在 Zshell
自己的[设置](/docs/configuration)里配置。
</Callout>

## 搜索

| 操作 | 快捷键 |
| --- | --- |
| 查找 | <kbd>Cmd</kbd>+<kbd>F</kbd> |
| 查找下一个 | <kbd>Cmd</kbd>+<kbd>G</kbd> |
| 查找上一个 | 在查找栏里按 <kbd>Shift</kbd>+<kbd>Return</kbd> |
| 用选中内容查找 | <kbd>Cmd</kbd>+<kbd>E</kbd> |
| 清空终端 | <kbd>Cmd</kbd>+<kbd>K</kbd> |

查找作用于当前终端或编辑器窗格，并且在搜索输入框拿着键盘焦点时仍然有效。

## 提示符编辑

在活动 shell 提示符内点按，输入光标会移到点击位置，后续输入就从那里开始。zsh 提示符中，可在输入内容上拖拽选中一段文字：继续输入会替换选区，按 Backspace 或 Delete 会删除选区。双击、三击仍用于选择终端输出文字；全屏 TUI 等主动启用终端鼠标上报的程序，仍会收到自己的鼠标事件。

嵌套启动或替换的 shell 若未加载 Zshell 的提示符编辑支持，拖拽仍可选择、复制终端文字，但不会直接修改输入。退出嵌套 shell、回到原提示符后，输入选区编辑会自动恢复。

## 提示词队列

聚焦终端，按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd>，或在命令面板选择
**显示/隐藏 提示词队列**，即可在该终端底部打开队列栏。输入内容后按 <kbd>Return</kbd>
或点击 **加入队列**。每项只保留一行，粘贴内容中的换行会替换为空格。

原来的 zsh 回到空 Shell 提示符时，Zshell 会按入队顺序发送下一项并按下 Return。
Agent 或其他前台程序仍占用终端、或者提示符中已有草稿输入时，自动发送会等待。
自动发送需要 Zshell 的 zsh 集成；其他 Shell 和嵌套 Shell 可以手动发送。

每项都有 **立即发送**和 **移除**按钮。**立即发送**会直接把文字和 Return 交给终端当前运行的
程序，不等待 Shell 提示符。按 <kbd>Esc</kbd> 或关闭按钮只会隐藏队列栏，已有队列仍然保留。
每个终端的队列独立；关闭会话或退出 Zshell 后，队列会被清空。

## 路径与 URL

Zshell 能识别终端程序打印出来的网页 URL 和确实存在的本地路径。本地链接可以是绝对路径、以
`~/` 开头、以 `./` 或 `../` 开头，也可以相对窗格的实时工作目录。诊断信息末尾的 `:42` 或
`:42:7` 不会妨碍找到背后的文件。

- **Command 点按**本地路径会在 Finder 里显示它；点网页 URL 则交给系统默认浏览器。
- **按住 Command 右键**路径，会出现 **New File Tab** / **New File Pane**；对 URL 则出现
  **New Browser Tab** / **New Browser Pane**。
- 启用鼠标报告的全屏程序会收到普通右键。按住 **Shift** 再右键，可改为打开 Zshell 的终端和窗格菜单。

这样一来，编译器输出和 agent 对话就能直接回到同一个项目里。网页相关行为见
[浏览器窗格](/docs/browser)。

## 通知

Zshell 会把两类终端事件转给通知中心：

- 未聚焦会话里的铃声；
- 构建工具或编码 agent 发出的 `OSC 777;notify` 请求。

通知可以播放系统提示音。点通知会激活 Zshell，并跳到发出它的确切会话。macOS 只在某个终端第一次真的要通知时申请权限，不会在 Zshell 启动时就弹框。

### 命令完成通知

打开 **设置 → Terminal → 命令通知**，可以让 Zshell 在命令结束时提醒你：

- **长时间运行的命令**：可选 5、10、30、60 秒。运行时间达到该值后结束的命令会触发通知，
  默认 **关闭**。
- **失败的命令**：退出状态非零时通知，不受运行时长限制。默认关闭，可以独立开启。

设置只影响修改之后新建的 zsh 终端，两个终端后端都支持。通知依赖原 Shell 的命令完成事件；
嵌套 Shell 或交互程序内部运行的命令，不会通过这项集成逐条报告完成。

也可以写入 `~/.config/zshell/config.toml`：

```toml
terminal.notify-finish-seconds = 30
terminal.notify-on-error = true
```

将 `terminal.notify-finish-seconds` 设为 `0` 可关闭按时长触发的通知。
通知是否送达仍取决于 macOS 的通知设置。

## 进度显示

发出 `OSC 9;4` 进度的程序，会在终端上方得到一条细进度条，正常、暂停和错误状态各有区分。不需要打开任何开关——程序报告了，窗格就显示。

## 剪贴板、拖放与粘贴安全

- **读剪贴板要确认。** `OSC 52` 可以申请读取 macOS 剪贴板，包括通过 SSH 跑在远端的程序。Zshell 会先问你。
- **有风险的粘贴会提示。** 多行或看起来会立即执行命令的文本，会先停在确认步骤。
- **文件会变成 shell 安全路径。** 从 Finder 复制或拖进来的文件，会作为经过引用的绝对路径插入。剪贴板图片仍会交给支持图片的 TUI。

## Option 键输入

默认情况下，Option 交给当前 macOS 输入源，因此 Polish Pro 之类的布局可以输入组合字符。如果终端程序需要把 Option 组合键当成 Meta 快捷键，打开设置里的 **Use Option as Alt/Meta**。对应配置键是
[`terminal.macos-option-as-alt`](/docs/configuration#terminalmacos-option-as-alt)。

## `zshell` 命令

每个 Zshell 终端都带一套了解项目上下文的 CLI：

```sh
zshell                         # 以当前目录新建项目
zshell vim ~/src/app.swift     # 新建项目，并让第一个终端直接运行这组 argv
zshell +themes                 # 交互式浏览和预览主题
zshell +themes --list --dark   # 不打开浏览器，直接列出主题名
zshell +help                   # 查看全部命令组
```

主题浏览器会把当前选项实时预览到整个应用；Return 保存，Escape 恢复之前的主题。

## 字体

Zshell 内置 JetBrains Mono 和 Nerd Font 符号。拉丁字形可以换成任意已安装的等宽字族，
还可在符号字体与系统后备字体之前插入一个已安装的 CJK 字族。见
[`font-family`](/docs/configuration#font-family)、
[`terminal.font-fallback-family`](/docs/configuration#terminalfont-fallback-family)、
[`font-size`](/docs/configuration#font-size)、
[`terminal.font-thicken`](/docs/configuration#terminalfont-thicken) 和
[`terminal.line-height`](/docs/configuration#terminalline-height)。

## 全局快捷终端

Zshell 运行时，按 <kbd>Cmd</kbd>+<kbd>I</kbd> 可以在其他应用上方打开独立的快捷终端，再按一次关闭。
它使用临时 shell，不属于项目中的标签页。**设置 → 终端 → Quick Terminal** 可调整窗口大小、透明度和快捷键。

- 点击固定按钮后，切换到其他应用时仍保持打开。
- 未固定时，点击外部或失去焦点会关闭窗口。
- <kbd>Esc</kbd> 或再次按全局快捷键会关闭窗口，并终止其中的 shell 和运行任务；重新打开会创建新会话。

需要持续运行的服务请放在项目终端中。[快速启动](/docs/quick-launch)用于保存和运行命令，是另一项功能。
