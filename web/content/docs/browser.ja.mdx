---
title: ブラウザペイン
description: ターミナルの隣に Web サイトを開き、ネイティブの操作で移動し、リンクをプロジェクト内に保ちます。
---

Zshell では、どのタブや分割ペインにも内蔵ブラウザを置けます。ローカル開発サーバー、API ドキュメント、課題など、使用中のターミナルの隣で見たい内容に便利です。

## ブラウザを開く [#opening-a-browser]

- <strong>ファイル → 新規ブラウザタブ（New Browser Tab）</strong>で空のタブを開きます。
- コマンドパレット（<kbd>Cmd</kbd>+<kbd>P</kbd>）で<strong>新規ブラウザタブ</strong>または<strong>新規ブラウザペイン（New Browser Pane）</strong>を実行します。
- ターミナルで検出された URL を Command キーを押しながら右クリックし、**新規ブラウザタブ**または**新規ブラウザペイン**を選ぶと、アドレスをコピーせずに開けます。

ブラウザタブは選択中のプロジェクトに属し、通常のタブ・ペイン配置に組み込まれます。プロジェクトが開いていない場合は、ブラウザ用に 1 つ作成します。

## アドレスと検索 [#address-and-search]

上部の入力欄には完全な URL、ホスト名、検索語を入力できます。

- `zshell.sh` は HTTPS アドレスになります。
- `localhost`、ローカルホスト名、IP アドレス、明示的なポートには HTTP を使います。
- それ以外は Google 検索になります。

<kbd>Cmd</kbd>+<kbd>L</kbd> で入力欄にフォーカスし、<kbd>Cmd</kbd>+<kbd>R</kbd> で再読み込みします。
ツールバーには戻る、進む、中止／再読み込み、共有、<strong>デフォルトのブラウザで開く（Open in Default Browser）</strong>もあります。トラックパッドで戻る・進むジェスチャーも使えます。

| 操作 | ショートカット |
| --- | --- |
| アドレスバーにフォーカス | <kbd>Cmd</kbd>+<kbd>L</kbd> |
| ページを再読み込み | <kbd>Cmd</kbd>+<kbd>R</kbd> |

## 開く場所を選ぶ [#opening-links-where-you-want-them]

ページ内のリンクを右クリックし、<strong>リンクを新規タブで開く（Open Link in New Tab）</strong>または<strong>リンクを新規ペインで開く（Open Link in New Pane）</strong>を選びます。新しいページも同じプロジェクトに属します。

ターミナルでは、通常の Command クリックは検出した Web URL をデフォルトのブラウザで開きます。Zshell のタブやペインを選ぶ場合は Command 右クリックを使います。
ローカルパスにも同様の操作があります。[パスと URL](/ja/docs/terminal#paths-and-urls)を参照してください。

## 保持されるもの [#what-is-preserved]

タブやプロジェクトを切り替えても、ページの履歴、スクロール位置、フォーム、ページ内の状態が保たれます。
Zshell の再起動時には現在の URL とレイアウトを復元しますが、戻る・進むの履歴全体は復元しません。

ブラウザペインはタブやアプリの起動をまたいで Cookie、ログイン、その他のサイトデータを保持します。プライベートブラウズではありません。

## Agent にページをテストしてもらう [#let-an-agent-test-the-page]

コーディング Agent に、このプロジェクトで開いているページの確認、フォーム入力、結果の検証、表示領域の撮影を依頼できます。既存のブラウザーセッションを使い、通常はターミナルのフォーカスを維持します。ローカル開発用 URL をバックグラウンドのブラウザーペインで開くこともできます。

スクリプトから使う場合は Zshell ターミナル内で実行します。返された `browser_id` を記録し、下の `BROWSER_ID` を置き換えてください：

```sh
zshell +browser list
zshell +browser open http://localhost:3000 --wait
zshell +browser snapshot --browser BROWSER_ID
zshell +browser fill --browser BROWSER_ID --selector '#search' --text 'terminal'
zshell +browser click --browser BROWSER_ID --selector 'button[type="submit"]'
zshell +browser wait --browser BROWSER_ID --selector '#results' --timeout 10000
zshell +browser screenshot --browser BROWSER_ID --output /tmp/zshell-page.png
```

スナップショットはメインフレームのテキスト、アクセシブルなラベル、要素参照を返します。参照はページの変更や操作後に失効するため、再利用前に新しいスナップショットを取得します。CSS セレクターは一つの要素だけに一致する必要があります。移動には `navigate`、`back`、`forward`、`reload`、`stop` を使います。

自動化で使用できるのは完全な HTTP/HTTPS URL と `about:blank` です。他のプロトコル、ダウンロード、ファイル選択、ネイティブダイアログには直接操作が必要です。アドレスバーやツールバーから手動で移動すると、この制限が解除されます。対象は呼び出し元のプロジェクトとウインドウ内に限られます。`--timeout` は 100–30000 ミリ秒です。スナップショットは最大 200 要素、32768 文字、256 KiB で、パスワードとファイル入力の値を含みません。PNG は表示領域のみで最大 512 KiB、ペインを一度表示する必要があり、既存ファイルは上書きしません。`--width` で縮小できます。詳細は `zshell +browser --help` を参照してください。
