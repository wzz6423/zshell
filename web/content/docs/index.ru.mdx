## Структура рабочей среды [#workspace-structure]

| Объект | Назначение |
| --- | --- |
| Проект | Локальный каталог или подключение SSH, объединяемые в группы боковой панели |
| Сеанс | Вкладка проекта, которую можно переименовать, выделить цветом, закрепить и включить в группу |
| Панель | Терминал, браузер, редактор или сравнение внутри вкладки; разделяйте панели для работы рядом |
