---
title: 화면 분할과 분할 창
description: 탭을 여러 창으로 나누고 이동, 크기 조절과 전체 크기 확대를 사용하세요.
---

모든 탭은 여러 분할 창으로 나눌 수 있습니다. 보통 터미널을 담지만 파일, 차이 보기 또는 [브라우저](/ko/docs/browser)를 담을 수도 있습니다. 읽고 있는 내용을 그것을 만든 셸 바로 옆에 둘 수 있습니다.

## 분할 [#splitting]

| 작업 | 단축키 |
| --- | --- |
| 오른쪽으로 분할 | <kbd>Cmd</kbd>+<kbd>D</kbd> |
| 아래로 분할 | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> |
| 왼쪽으로 분할 | — |
| 위로 분할 | — |

왼쪽과 위로 분할하는 작업에는 기본 단축키가 없습니다. **탭** 메뉴, 명령 팔레트(<kbd>Cmd</kbd>+<kbd>P</kbd>) 또는 분할 창의 컨텍스트 메뉴에서 실행하세요. 새 분할 창은 포커스된 분할 창의 작업 디렉터리를 이어받습니다.

중첩된 배치에서도 항상 **포커스된 분할 창**을 나눕니다. 관계없는 이웃 창의 크기를 바꾸지 않습니다. 각 분할 창의 머리글에는 현재 상태를 반영하는 작은 제목과 분할 버튼이 있어 각 창의 맥락을 확인할 수 있습니다.

이미 열린 분할 창도 재배치할 수 있습니다. 창 위쪽의 얇은 띠를 잡고 다른 창의 가장자리로 드래그하세요. 놓기 전에 대상 창이 어느 절반에 들어갈지 표시합니다.

탭 전체를 분할 창으로 바꿀 수도 있습니다. 위쪽 탭 막대에서 탭을 끌어 현재 탭 내용의 왼쪽, 오른쪽, 위쪽 또는 아래쪽 가장자리에 놓으세요. 놓기 전에 미리보기가 결과 배치를 보여 줍니다.

## 분할 창 사이 이동 [#moving-between-panes]

| 작업 | 단축키 |
| --- | --- |
| 왼쪽 / 오른쪽 / 위 / 아래 창으로 포커스 이동 | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+방향키 |
| 이전 / 다음 창으로 순환 이동 | <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> |

## 확대와 크기 조절 [#zoom-and-resize]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd>로 포커스된 분할 창을 탭 전체에 맞게 확대하며, 다시 누르면 원래 크기로 돌아옵니다. 확대 중에는 탭 머리글에도 버튼이 나타나므로 단축키 없이도 돌아갈 수 있습니다.

| 작업 | 단축키 |
| --- | --- |
| 분할 창 확대 전환 | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> |
| 지정한 방향으로 창 늘리기 | <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+방향키 |
| 모든 분할 창 크기 균등화 | <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> |

분할 창 사이의 구분선도 드래그할 수 있습니다.

## 닫기 [#closing]

<kbd>Cmd</kbd>+<kbd>W</kbd>는 포커스된 분할 창을 닫습니다. 탭의 마지막 분할 창을 닫으면 탭도 함께 닫힙니다.

<Callout type="warn">
터미널 분할 창을 닫으면 그 안의 셸과 셸에서 실행한 작업도 종료됩니다. 다른 터미널을 닫을 때와 마찬가지로 Zshell은 별도 확인을 요청하지 않습니다.
</Callout>
