Zshell 大多數持久化設定都在一個檔案裡：

```
~/.config/zshell/config.toml
```

設定視窗（<kbd>Cmd</kbd>+<kbd>,</kbd>）寫的也是這個檔案。少數由 macOS 管理的設定——語言和自動更新——存在別處，列在本頁末尾。

新配置預設開啟 Vim 指令提示、工作階段歷史恢復和失敗指令通知。自動下載更新也預設開啟；既有配置和已儲存的開關選擇會保留。

**設定 → 終端機**中，輸入行為位於**輸入**，命令記錄與歷史入口位於**歷史記錄**，命令提醒與通知歷史位於**通知**。**游標**和**背景**位於**設定 → 外觀**。

關閉上層功能後，相依控制項會隱藏，已儲存的值會保留：包括快速終端機附屬控制項、Agent 工作階段恢復與通知、字型加粗強度、焦點環不透明度、Git 代理位址，以及瀏覽器過濾清單和狀態。背景模糊只在背景半透明且 macOS 未開啟「降低透明度」時顯示。

## 這個檔案的行為 [#how-the-file-behaves]

手動改之前值得先知道：

- **執行中自動讀取變更。** 有效的外部編輯會自動套用；標示只影響新終端的設定仍需新建窗格。檔案無法讀取或語法錯誤時保留最後有效設定。主動清空檔案會在短暫等待後還原預設值。
- **只要檔案型設定有變化，Zshell 就會重寫它。** 檔案會從頭生成，所以你的注釋和未知鍵會在下次使用這些控件時丟失。最好只選一種方式維護它，或者把權威版本放在 dotfiles 裡。
- **通常只寫非預設值。** `font-size`, `terminal.vim-command-hints`, `terminal.restore-history`, `terminal.notify-on-error`, `terminal.prompt-queue-enabled`, `terminal.prompt-queue-auto-dispatch` 總會儲存。在既有檔案中刪除 `terminal.vim-command-hints`、`terminal.restore-history` 或 `terminal.notify-on-error` 會關閉對應功能。刪除 `terminal.prompt-queue-enabled` 會恢復預設值 `true`，刪除 `terminal.prompt-queue-auto-dispatch` 會恢復預設值 `false`；刪除其他鍵也會恢復各自的預設值。
- **解析器有意保持精簡。** 支持扁平鍵、點號鍵、`[table]` 表頭、`#` 注釋，以及字串、數字和布林值；不支持數組、行內表和多行字串。
- **錯誤值會安全回退。** 超出範圍的字級、未知後端或拼錯的主題名不會讓 Zshell 啟動失敗。

設定儲存會保留檔案及目錄的符號連結，原子更新目標檔案並保留權限。外部編輯不會回寫註解或未知鍵；隨後透過設定視窗儲存時，仍會依上述規則重新產生檔案。

## 應用程式顯示位置 [#application-presence]

### `app-presence`

`"dock"` · `"dock-and-menu-bar"` · `"menu-bar"` — 預設 `"dock"`

在 **設定 → 一般 → Zshell 顯示位置** 中切換，立即生效。`"dock"` 僅顯示 Dock 圖示，`"dock-and-menu-bar"` 同時顯示 Dock 與選單列圖示，`"menu-bar"` 僅顯示選單列圖示。

選單列可開啟目前工作區、臨時終端機、設定與更新檢查。在兩種選單列模式下，關閉最後一個工作區視窗會將它隱藏，終端機和工作繼續執行；**開啟工作區** 會回到同一個視窗、專案和工作階段。關閉其他工作區視窗、面板或專案仍會結束相關工作。明確選擇 **結束** 時仍遵循 `terminal.preserve-sessions`；**結束並終止所有工作階段** 會終止它們。此模式會在重新啟動後保留。

## 保持電腦喚醒 [#keep-computer-awake]

### `keep-awake`

`"off"` · `"on"` · `"agents"` — 預設 `"off"`

在**設定 → 一般 → 保持電腦喚醒**或 **Zshell → 保持電腦喚醒**中選擇。`"off"` 允許自動睡眠，`"on"` 在 Zshell 執行期間防止系統自動睡眠，`"agents"` 僅在本機 Agent 工作時防止自動睡眠。

在 `"agents"` 模式下，所有本機終端機窗格都參與判斷，包括背景專案、其他視窗和隱藏或縮放後的分割窗格。遠端 Agent 不計入。沒有其他本機 Agent 工作時，等待、閒置和已完成狀態允許睡眠；關閉最後一個工作的窗格也會解除防止睡眠。`"on"` 模式在 Zshell 執行期間持續防止自動睡眠。無論哪種模式，選擇關閉或結束 Zshell 都會解除防止睡眠，即使終端機工作階段被保留。

設定列顯示防止睡眠是否實際生效或無法使用。顯示器仍可睡眠；手動睡眠、闔蓋和低電量睡眠繼續遵循 macOS 政策。

## 外觀 [#appearance]

### `theme` [#theme]

`"system"` · `"light"` · `"dark"`——預設 `"system"`

選擇應用外觀。`"system"` 跟隨 macOS，另外兩個把 Zshell 固定為淺色或深色。

### `theme-dark` 和 `theme-light` [#theme-dark-and-theme-light]

字串——預設 `"Default Dark"` 和 `"Default Light"`

兩種外觀各自使用的配色主題。它會同時重繪終端機、視窗裝飾、側邊欄、編輯器和 diff。Zshell 自帶的預設主題保留半透明側邊欄，其他主題會把側邊欄刷成與自身配色一致。

設定視窗列出兩個終端機後端共同支持的精選主題。手寫名稱必須與列表裡的顯示名完全一致，包括大小寫；否則會回退到對應的預設主題。

### `terminal.minimum-contrast` [#terminalminimum-contrast]

`1`–`21` · `3`

在 **設定 → 外觀 → 顏色 → 最小對比度** 中調整終端文字的可讀性，範圍為 `1`–`21`，預設 `3`。設為 `1` 可保留 ANSI 原色。兩個後端都會更新已開啟的終端和快捷終端，無需重新啟動 shell；終端設定檔仍使用各自的配色。Emoji 和圖片像素保留原色。選取範圍和游標繼續使用各後端原生的可讀性策略。若背景無法達到指定比例，各後端會使用可用的較清晰顏色。透明終端按解析後的儲存格背景計算，因此與桌面合成後的實際對比度可能不同。

### `toolbar.visibility` [#toolbarvisibility]

`"hide"` · `"auto"` · `"always"`——預設 `"hide"`

控制當前分頁下方的緊湊工具欄：

- `"hide"` 始終隱藏。
- `"auto"` 只在專案目錄是 Git 儲存庫時顯示。
- `"always"` 在每個專案裡顯示；不是儲存庫時會顯示 **No Git Repository**。

它具體展示什麼，見 [Git 工具欄](/zh-Hant/docs/git#the-git-toolbar)。

## 文字 [#text]

### `font-family` [#font-family]

字串——預設 `""`，表示內建的 JetBrains Mono

終端機、編輯器和 diff 共用這個拉丁字型家族。請寫字型家族名，不要寫具體字重：`"IBM Plex Mono"`，
而不是 `"IBM Plex Mono Regular"`。不存在或非等寬的字型家族會回退到內建預設值。

終端機的後備順序是：拉丁字型家族、下面可選的 CJK 後備字型家族、內建 Symbols Nerd Font，最後是
後端的系統後備字型。編輯器和 diff 繼續使用 macOS/WebKit 的正常後備機制。

### `terminal.font-fallback-family` [#terminalfont-fallback-family]

字串——預設 `""`，表示交給後端和系統選擇

在終端機的有序後備鏈中加入一個已安裝的 CJK 字型家族。設定列表會顯示包含代表性中文、日文或
韓文字形的字型家族；它們不必嚴格等寬，因為只負責拉丁主字型缺少的字形。

### `font-size` [#font-size]

數字，8–32——預設 `13`

終端機、編輯器和 diff 共用的字級，單位是磅。這是唯一一個即使等於預設值，Zshell 也會寫進檔案的鍵。

### `interface.scale` [#interfacescale]

數字，0.9–1.5——預設 `1`

縮放分頁、圖示、按鈕、側邊欄和應用介面的其他部分。終端機、編輯器和 diff 內容仍使用上方單獨配置的字級。

### `sidebar.font-size` [#sidebarfont-size]

數字，9–24——預設 `14`

左右側邊欄的基礎字級。調整後，分區標題、列表、元資料和控件仍會保持原本的大小層級。

### `sidebar.double-click-new-session` [#sidebardouble-click-new-session]

布林值——預設 `true`

按兩下側欄空白處會在所選專案新增工作階段。沒有選取專案時建立專案。列表列的點選與拖曳仍執行原有操作。

### `terminal.font-ligatures` [#terminalfont-ligatures]

布林值 — 預設 `true`

在 **設定 → 外觀 → 字型連字** 中啟用或停用兩個終端機後端的可選連字。停用時會覆寫 `calt`、`liga`、`clig`、`dlig` 和 `hlig`，保留文字必需的字形排版。原始字元、終端機占欄、游標和選取範圍保持不變。

### `terminal.font-features` [#terminalfont-features]

字串 — 預設 `""`，使用字型預設特性

在同一字型群組的 **OpenType 字形特性** 中填寫四字元標籤，以逗號或空白分隔：`-calt` 停用上下文替換，`ss01` 啟用樣式集 1，`zero=1` 啟用字型的替代零字形。`+liga` 和 `liga=1` 也能啟用特性。同一標籤以後面的值為準；連字開關對上述五個標籤具有優先權。

變更立即套用到已開啟的終端機和字型預覽。兩個後端均套用所選字型支援的特性，不支援的標籤不會產生效果。設定中的無效輸入繼續使用上次有效值；無效的外部設定使用字型預設值。重設為預設值會清空特性清單並啟用連字。

### `terminal.font-thicken` [#terminalfont-thicken]

布林值——預設 `false`

用稍粗的筆畫渲染終端機文字，效果類似經典 macOS 字型平滑。兩個終端機後端都支持，設定視窗裡的預覽也會反映效果。舊的 `font-thicken` 仍能讀取，但儲存後會改寫成現在的點號鍵。

### `terminal.font-thicken-strength` [#terminalfont-thicken-strength]

整數，0–255——預設 `255`

控制 `terminal.font-thicken` 打開時的粗化強度。零表示最輕的可用粗化，而不是關閉。Ghostty
使用其原生 macOS 強度；Alacritty 把同一範圍映射到 CoreText 描邊，所以方向和端點一致，
但光柵化像素可能不同。

### `terminal.cell-width` [#terminalcell-width]

數字，0.75–2——預設 `1`

在**設定 → 外觀 → 字型 → 字元欄寬**中調整終端機字元欄之間的距離。預設 100%，以整數百分比儲存。兩個後端都會立即更新已開啟的終端機，包括 PTY 欄數、游標、選取範圍和鍵盤提示。字形大小不變，寬字元仍占兩欄。像素取整會讓兩個後端的實際步進略有不同。無效值恢復為 100%，編輯器和 diff 的間距不受影響。

### `terminal.line-height` [#terminalline-height]

數字，0.75–2——預設 `1`

按比例調整各終端機後端的自然單元格高度，同時讓字形保持垂直居中。它只改變終端機行，不改變
編輯器或 diff 的行距。

Zshell 不提供基礎字重控件。Ghostty 使用具名字形樣式或可變軸，而 Alacritty/CoreText 按
trait 解析 regular 與 bold 字型；單個共享數值無法在靜態字型和可變字型之間一致地保留
regular/bold 區分及後備字型字重。

### `terminal.padding-color` [#terminalpadding-color]

`"background"` · `"extend"` · `"always"` — `"extend"`

在**設定 → 外觀 → 背景 → 邊距顏色**中選擇。`"background"` 讓邊距使用終端機主題背景。`"extend"` 延伸最近儲存格的背景，但首行或末行包含預設背景儲存格、Shell 提示字元或 Powerline 分隔符時，上下邊距維持主題背景。`"always"` 略過這些判斷，向所有邊緣延伸。空白末行保留自身背景，其上方的彩色行不會填滿底部邊距。變更立即套用至兩個後端的已開啟終端機。使用半透明背景時，預設背景保留設定的不透明度，明確指定的儲存格背景及其延伸部分維持不透明。

### `editor.wrap-lines` [#editorwrap-lines]

布林值——預設 `true`

在[檔案編輯器](/zh-Hant/docs/files)裡按窗格寬度軟折行。關閉時長行橫向捲動；它不會改變終端機或 diff
裡的折行行為。

### `editor.diff-wrap-lines` [#editordiff-wrap-lines]

布林值——預設 `false`

在**設定 → 編輯器 → 按 Diff 寬度換行**或 Diff 工具列的換行按鈕中切換。長行會按窗格寬度折行，適用於單欄和左右對照佈局、可編輯的工作區變更、歷史 Diff 和 PR 評論。選擇立即同步到所有已開啟的 Diff，並在重新啟動後保留。關閉後恢復橫向捲動。它獨立於檔案編輯器和終端機的換行設定。

### `editor.protect-saves` [#editorprotect-saves]

布林值——預設 `true`

儲存檔案或可編輯的工作區 Diff 前，檢查外部程式是否變更了磁碟版本。發生衝突時，可以比較版本、從磁碟重新載入、保留草稿或主動覆寫檔案。關閉後，儲存會直接取代外部變更，不再顯示衝突提示。

### `editor.recover-drafts` [#editorrecover-drafts]

布林值——預設 `true`

Zshell 預設備份本機檔案與可編輯工作樹 Diff 中未儲存的修改。意外結束後，重新開啟的窗格會還原草稿、選取範圍與版面。其他備份可從 **檔案 → 還原草稿…** 或 **設定 → 編輯器 → 還原草稿…** 找回：選取備份、查看內容，再按 **還原草稿**。還原只會開啟未儲存的編輯器，不會變更磁碟檔案；儲存時仍以編輯前的版本檢查外部變更。

在 **設定 → 編輯器 → 備份未儲存的草稿** 或 `editor.recover-drafts` 中控制備份。關閉後停止新增備份與自動還原，現有備份仍可手動還原或刪除。**刪除備份** 只移除選取的備份，保留已開啟的編輯內容。成功儲存或完成關閉時選擇 **不儲存** 會移除備份。備份以私有檔案儲存在此 Mac，最多 32 份、共 128 MiB，最多保留 30 天。容量限制可能導致較舊的備份提前刪除。超過 5 MiB 的檔案與編輯文字不會備份。

Zshell 在啟動時及執行期間每小時清理過期備份，關閉備份開關後仍會清理。應用程式關閉期間，過期檔案會留在磁碟上，直到下次啟動時刪除。

## 終端機 [#terminal]

### `terminal.startup-program` / `terminal.startup-arguments` [#terminalstartup-program--terminalstartup-arguments]

字串——預設未設定

選擇之後新建終端機使用的可執行程式與參數向量。未設定 `terminal.startup-program` 時，Zshell
繼續以 `-l` 啟動帳戶登錄 Shell。程式必須是可執行檔案的絕對路徑；路徑不存在或不可執行時會
回退到登錄 Shell，而不是打開一個立即關閉的空窗格。

`terminal.startup-arguments` 不經 Shell 直接拆分為參數。引號和反斜槓用於保留參數邊界，
包括含空格和空字串的參數，但不會展開變數、通配符或指令替換。引號不完整時也會回退到
登錄 Shell。Zshell CLI 為單個終端機顯式傳入的 argv 仍然優先。

### `terminal.new-session-directory` [#terminalnew-session-directory]

`"current"` · `"project"` · `"home"` · `"custom"` — 預設 `"current"`

在**設定 → 終端機 → 新工作階段目錄**中選擇。目前目錄使用作用中本機 shell 的目錄，新專案的第一個終端機也會繼承；沒有本機 shell 時使用個人目錄。專案目錄使用檔案和 Git 面板顯示的根目錄（最近的儲存庫或前景工作使用的簽出目錄），不在儲存庫內時使用目前目錄。個人目錄一律使用帳戶的個人目錄。同一規則也適用於首次開啟快速終端機及每次新建快速終端機工作區。

Finder、CLI、工作區範本、worktree、還原工作階段、專案固定目錄或側邊欄群組指定的目錄優先。分割窗格保留來源窗格的目錄。SSH 和共用遠端工作階段繼續使用遠端主機上的目錄。變更設定不會重新啟動已開啟的終端機或重複使用的快速終端機工作區。

### `terminal.custom-directory` [#terminalcustom-directory]

字串 — 預設 `""`

使用自訂規則時輸入絕對路徑或 `~/folder`，也可在設定中選擇資料夾。Zshell 會檢查資料夾是否存在且可進入。自訂資料夾不存在、無法存取或格式無效時，會回到目前本機目錄（沒有本機環境時為個人目錄），並在設定中顯示原因。切換其他規則時會保留已儲存的路徑。

### `terminal.term`

在 **設定 → 終端機 → TERM** 中設定 `terminal.term`（預設為 `"xterm-256color"`）。名稱必須由 1–128 個 ASCII 字母、數字或 `.-_+` 組成。請使用執行 shell 的主機上已安裝的 terminfo 名稱。修改僅適用於新建的本機與 SSH 階段作業；已開啟和保留的 PTY 維持原本的 `TERM`。共享遠端階段作業在更新後的伺服器上建立時使用此值；舊伺服器繼續使用 `xterm-256color`。啟動時遇到無效值會退回 `xterm-256color`；Zshell 執行期間的無效修改會保留上一個有效值。兩種情況都會在設定中顯示錯誤。此設定不會改變 `TERM_PROGRAM` 或 `ZSHELL_TERM`。

### `terminal.backend` [#terminalbackend]

`"libghostty"` · `"alacritty"`——預設 `"libghostty"`

選擇之後新建終端機使用的模擬器；已經打開的窗格繼續使用啟動時的後端。兩者都是原生 GPU 加速，都支持圖片渲染並共用 Zshell 主題；Alacritty 通常佔用更少記憶體。

環境變數與相容約定見[終端機後端](/zh-Hant/docs/terminal#terminal-backends)。

### `terminal.mouse-scroll-multiplier` / `terminal.trackpad-scroll-multiplier` [#terminal-scroll-multipliers]

數值，0.1–10 — 兩種裝置均預設為 `1`

在 **設定 → 終端機 → 捲動 → 滑鼠滾輪 / 觸控式軌跡板** 中分別調整速度。讀數使用百分比：100% 保持目前速度，50% 為一半，200% 為兩倍。變更立即套用至已開啟的 Ghostty 和 Alacritty 面板，包括回捲歷史、全螢幕程式和滑鼠回報。慣性捲動使用觸控式軌跡板倍率；水平捲動仍保持水平。回報精細捲動的裝置使用觸控式軌跡板倍率，包括支援精細捲動的滑鼠。缺少或無效的值還原為 `1`；匯入、匯出和重設設定均包含這兩個值。

### `terminal.macos-option-as-alt` [#terminalmacos-option-as-alt]

布林值——預設 `false`

打開後，Option 組合鍵會作為 Alt/Meta 快速鍵發送給終端機程式。預設關閉，讓 Option 繼續交給當前 macOS 輸入源，因此 Polish Pro 之類的鍵盤佈局仍能輸入組合字符。

### `terminal.bell` [#terminalbell]

布林值——預設 `true`

控制終端機程式觸發鈴聲時的提示音和 macOS 視覺提醒。關閉後，Zshell 不會播放提示音、發送終端機鈴聲通知或請求 Dock 提醒；輔助技術仍會收到鈴聲的語義公告。兩個終端機後端都遵循此設定。

### `terminal.vim-command-hints` [#terminalvim-command-hints]

布林值，預設 `true`。

在右側 **資訊** 欄的工作階段資訊下方顯示按模式排序的 Vim / Neovim 常用指令。
立即作用於兩種終端機後端，也支持識別 SSH 中的編輯器。
檢測條件見 [Vim 指令提示](/zh-Hant/docs/terminal#vim-command-hints)。

### `terminal.restore-history` [#terminalrestore-history]

布林值——預設 `true`

重新啟動後，在全新 shell 上方恢復每個終端機之前的捲動歷史。恢復的是靜態文本，不是仍在執行的程序。

恢復的捲動歷史會儲存在磁碟上，所以終端機裡顯示過的密鑰也可能包含在內。[專案、分頁和窗格佈局](/zh-Hant/docs/projects#what-survives-a-relaunch)無論如何都會恢復。

## 瀏覽器存取 [#browser-access]

若舊版 Zshell 保留的工作階段仍在執行，瀏覽器存取會提示選取 **結束並終止所有工作階段** 後重新開啟 Zshell。在你選擇結束前，既有工作會保留。

### `browser-access.enabled`

`browser-access.enabled` 為布林值，預設 `false`。在 **設定 → 瀏覽器存取** 啟用後，新開的本機終端機面板可供瀏覽器存取；既有面板保留目前程序。兩種終端機後端均可使用，且不會改變 `terminal.preserve-sessions`。

### `browser-access.interface` / `browser-access.port`

`browser-access.interface` 預設 `"loopback"`（**僅限本機**）。從其他裝置連線時，在設定中明確選取可用的私有 IPv4 LAN 或 Tailscale 介面。儲存值包含確切介面及位址，例如 `"en0|192.168.0.10"`。`browser-access.port` 是 HTTPS 連接埠，範圍 1024–65535，預設 `7443`。本機頁面使用獨立、僅限本機的 HTTP 位址。介面無法使用時需重新選取，服務不會改為監聽所有介面。

本機 HTTP 頁面通常使用設定的 HTTPS 連接埠加一（預設 `7444`）。連接埠占用情況不變時，睡眠恢復、重試和重新開啟會保留該位址與授權。若連接埠被占用，Zshell 會依序嘗試後續七個本機連接埠；到 `65535` 後從 `1024` 繼續。連接埠占用情況變更後，重新啟動可能選擇不同位址。既有授權綁定原來的來源位址，因此新位址需要重新配對。關閉存取時仍可查看和撤銷已儲存的用戶端；達到 32 個用戶端上限時，請先撤銷一個再核准新的用戶端。無法檢查工作階段服務時，存取開關仍保持開啟；服務就緒後按一下「重試」。

遠端配對前，請比對 TLS 憑證指紋，並在用戶端信任匯出的憑證。在這台 Mac 上核准或撤銷用戶端。關閉存取、睡眠或結束應用程式會中斷連線；結束時仍遵循既有工作階段保留設定。詳見[透過瀏覽器存取這台 Mac](/zh-Hant/docs/remote-sessions#browser-access)。

## 自動化 [#automation]

### `ai.enabled` [#aienabled]

布林值——預設 `true`

讓受支持的編碼 agent 按照你的自然語言要求協調 Zshell 後台窗格，並在介面裡顯示 provider 報告的生命週期狀態。推薦用設定視窗的開關，因為錯誤會直接顯示出來，而且衝突的現有配置會保持原樣。

具體怎麼使用，見[與 AI Agent 協作](/zh-Hant/docs/automation)。

多個終端共用 Codex app-server 時，Zshell 根據已驗證的對話 ID 配對前景窗格，有歧義時不綁定。託管整合會在 Codex 終端標題中加入 `session-id`，並保留其他標題項目。

### `ai.resume-conversations` [#airesume-conversations]

布林值——預設 `true`

恢復終端窗格時，若原 PTY 已不可用，繼續已記錄的 Claude Code、Codex、Pi 或 OpenCode 確切原對話。需要 `ai.enabled = true`。沒有已驗證對話的窗格會開啟新 shell；Zshell 不會按目錄選擇最近對話。

可在 **設定 → 自動化 → 恢復 Agent 對話** 中切換。它與 `terminal.restore-history` 獨立。

### `ai.usage-enabled`

布林值——預設 `false`

在 **設定 → Automation → 帳戶用量 → 讀取帳戶用量** 啟用本機 CLI 帳戶額度讀取。關閉後會取消待處理用量請求、隱藏資料，並拒絕儲存 Claude 用量報告，同時保留提供方選擇。用量設定不改變 Agent 識別、生命週期回報或對話恢復。

### `ai.claude-usage-enabled` / `ai.codex-usage-enabled`

布林值——各自預設 `true`

選擇 `ai.usage-enabled = true` 時允許讀取用量的提供方。Claude Code 讀取 Zshell 本機狀態列報告，Codex 查詢已安裝並登入的 CLI。關閉提供方會立即停止對應讀取並隱藏資料，不收集登入憑證。三項設定支援搜尋、匯入匯出、設定即時重新載入及還原預設值。

## 備份與遷移 [#backup-and-migration]

通過 **Zshell → Export Settings…** 匯出 TOML 檔案，使用 **Import Settings…** 匯入。
匯入前會要求確認替換，並嘗試將當前配置備份為同目錄的 `config.toml.bak`。

匯入會讀取所有支援的設定項目。省略項目遵循設定讀取器的預設規則；未包含 `ai.enabled` 時保留目前的 AI 開關。語言及專案、分頁的環境變數另行儲存。

## 一份完整的例子 [#a-complete-example]

```toml title="~/.config/zshell/config.toml"
theme = "dark"
theme-dark = "Catppuccin Mocha"
theme-light = "Catppuccin Latte"
font-family = "IBM Plex Mono"
font-size = 14
interface.scale = 1.25
sidebar.font-size = 13
toolbar.visibility = "auto"
terminal.font-fallback-family = "PingFang SC"
terminal.font-ligatures = true
terminal.font-features = "ss01, zero=1"
terminal.font-thicken = true
terminal.font-thicken-strength = 180
terminal.cell-width = 1.1
terminal.line-height = 1.15
terminal.mouse-scroll-multiplier = 1
terminal.trackpad-scroll-multiplier = 1
terminal.macos-option-as-alt = false
terminal.bell = false
terminal.startup-program = "/opt/homebrew/bin/fish"
terminal.startup-arguments = "--no-config"
terminal.backend = "alacritty"
terminal.restore-history = true
editor.wrap-lines = true
editor.diff-wrap-lines = false
ai.enabled = true
ai.resume-conversations = true
```

每個鍵都是可選的。刪掉某個鍵，就讓那項設定恢復預設值。

## 自訂快速鍵 [#keyboard-shortcuts]

打開 **設定 → 快速鍵**，可以為核心指令錄制新的組合鍵。若與其他指令衝突，
Zshell 會拒絕此次修改並顯示佔用它的指令。點擊 **恢復預設快速鍵**可以清除全部自訂項。

## 不在這個檔案裡的設定 [#settings-outside-this-file]

- **語言。** 設定裡可選「跟隨系統」及與官網一致的 17 種語言。切換立即生效，終端機工作階段繼續執行。它使用 macOS 的單應用語言偏好，所以不存進 TOML。「跟隨系統」會按 macOS 的語言優先級選擇。
- **自動更新。** **設定 → 更新**中的自動檢查、自動下載和自動安裝使用 TOML 之外的應用偏好，重新啟動後會保留選擇。開啟自動檢查且支援自動更新時才顯示下載控制項；自動安裝還要求開啟自動下載。見[安裝](/zh-Hant/docs/installation#updates)。
- **視窗與佈局狀態。** 視窗尺寸、側邊欄寬度、當前面板、專案、分頁、窗格、瀏覽器 URL 和
  diff 控件偏好，都存在 Zshell 的 macOS 偏好設定或工作階段快照裡。
- **後端自己的配置檔案。** Zshell 不讀取 `~/.config/ghostty`，也不讀取 Alacritty 配置。Zshell 的設定就是兩個後端共同支持的配置面。


## Agent 識別規則 [#agent-recognition-rules]

`ai.custom-recognition-rules` · `ai.screen-inference` — `true` / `false`, 預設 `true`

開啟 **設定 → AI → Agent 識別** 或 **Agents → 管理 Agent 規則…**，可新增、編輯、刪除、匯入、匯出或重設本機規則。**使用自訂識別規則** 與 **依畫面推斷 Agent 狀態** 是兩個獨立開關，預設均開啟。關閉會立即清除相關舊畫面證據。原生生命週期事件和程式報告仍優先。
