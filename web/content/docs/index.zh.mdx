<span id="工作区结构" data-canonical-heading="workspace-structure" />

## 工作区结构 [#workspace-structure]

| 对象 | 用途 |
| --- | --- |
| 项目 | 本地目录或 SSH 连接；在侧边栏中分组管理 |
| 会话 | 项目中的标签页，可重命名、标色、固定和分组 |
| 窗格 | 标签页内的终端、浏览器、编辑器或 diff，可分屏排列 |
