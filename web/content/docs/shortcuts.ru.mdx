title: Сочетания клавиш
description: Все стандартные сочетания клавиш Zshell, сгруппированные по назначению.
---

Забыли сочетание? <kbd>Cmd</kbd>+<kbd>P</kbd> открывает палитру команд, где рядом с каждой командой указано её сочетание клавиш.

## Глобальный быстрый терминал [#global-quick-terminal]

| Сочетание клавиш | Действие |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>I</kbd> | Показать / закрыть быстрый терминал |
| <kbd>Esc</kbd> | Закрыть быстрый терминал и завершить его оболочку |

Задайте другое сочетание в **Настройки → Терминал → Быстрый терминал**. Незакреплённый терминал также закрывается при потере фокуса. См. [Быстрый терминал](/ru/docs/terminal#global-quick-terminal).

## Проекты и сеансы [#projects-and-sessions]

| Сочетание клавиш | Действие |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>N</kbd> | Новый проект |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | Новый сеанс |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | Новое окно |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | Закрыть активную панель |
| <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Перейти к проекту 1–9 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Следующий / предыдущий проект |
| <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Перейти к вкладке 1–9 |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Переключатель вкладок по времени последнего использования |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Следующая / предыдущая вкладка |

## Панели [#panes]

| Сочетание клавиш | Действие |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Разделить вправо |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Разделить вниз |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+клавиши со стрелками | Активировать панель в указанном направлении |
| <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> | Циклически переключать активную панель |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> | Развернуть панель / вернуть прежний размер |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+клавиши со стрелками | Изменить размер активной панели |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> | Выровнять размеры панелей |

Для разделения влево и вверх стандартных сочетаний нет — используйте меню **Вкладки**, контекстное меню панели или палитру команд.

## Боковые панели и окна команд [#panels]

| Сочетание клавиш | Действие |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>P</kbd> | Палитра команд |
| <kbd>Cmd</kbd>+<kbd>O</kbd> | Быстрый запуск |
| <kbd>Cmd</kbd>+<kbd>B</kbd> | Показать / скрыть левую боковую панель |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | Показать / скрыть правую боковую панель |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Панель Git |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Панель файлов |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | Панель информации |

## Браузер и агенты [#browser-and-agents]

| Сочетание клавиш | Действие |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>L</kbd> | Перейти в адресную строку текущего браузера |
| <kbd>Cmd</kbd>+<kbd>R</kbd> | Перезагрузить текущую страницу браузера |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Перейти к следующему агенту, которому нужно внимание |

Для новых вкладок и панелей браузера стандартных сочетаний нет; используйте меню **Файл** или палитру команд.

## Текст и поиск [#text-and-search]

| Сочетание клавиш | Действие |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>F</kbd> | Найти в активной панели |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> | Найти и заменить (редактор) |
| <kbd>Cmd</kbd>+<kbd>G</kbd> | Найти следующее |
| <kbd>Shift</kbd>+<kbd>Return</kbd> | Найти предыдущее из строки поиска |
| <kbd>Cmd</kbd>+<kbd>E</kbd> | Использовать выделение для поиска |
| <kbd>Cmd</kbd>+<kbd>K</kbd> | Очистить терминал |
| <kbd>Cmd</kbd>+<kbd>S</kbd> | Сохранить открытый файл |
| <kbd>Cmd</kbd>+<kbd>,</kbd> | Настройки |

## Найти предыдущее [#find-previous]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> — обычное сочетание macOS для поиска предыдущего совпадения, но в Zshell оно переключает панель Git. Используйте <kbd>Shift</kbd>+<kbd>Return</kbd> в строке поиска; пункт меню **Правка → Найти** также работает.
