---
title: "การตั้งค่า"
description: "ตัวเลือกถาวรทั้งหมดของ Zshell หน้าที่ และตำแหน่งจัดเก็บ"
---

การตั้งค่าถาวรส่วนใหญ่ของ Zshell อยู่ในไฟล์เดียว:

```
~/.config/zshell/config.toml
```

หน้าต่างการตั้งค่า (<kbd>Cmd</kbd>+<kbd>,</kbd>) เขียนไฟล์เดียวกัน ค่าบางอย่างที่ macOS ดูแล เช่น ภาษาและอัปเดตอัตโนมัติ อยู่ที่อื่นและระบุท้ายหน้านี้

การตั้งค่าใหม่เปิดคำแนะนำคำสั่ง Vim การกู้คืนประวัติเซสชัน และการแจ้งเตือนคำสั่งล้มเหลวโดยค่าเริ่มต้น การดาวน์โหลดอัปเดตอัตโนมัติก็เปิดไว้โดยค่าเริ่มต้นเช่นกัน การตั้งค่าเดิมและตัวเลือกที่บันทึกไว้จะคงอยู่

ใน **การตั้งค่า → เทอร์มินัล** ตัวควบคุมการป้อนข้อมูลอยู่ใน **การป้อนข้อมูล** การบันทึกคำสั่งและทางเข้าประวัติอยู่ใน **ประวัติ** การแจ้งเตือนคำสั่งและประวัติการแจ้งเตือนอยู่ใน **การแจ้งเตือน** ส่วน **เคอร์เซอร์** และ **พื้นหลัง** อยู่ใน **การตั้งค่า → ลักษณะ**

ตัวควบคุมที่ขึ้นอยู่กับฟังก์ชันหลักจะถูกซ่อนเมื่อปิดฟังก์ชันนั้น โดยเก็บค่าที่บันทึกไว้ ได้แก่ ตัวควบคุมเทอร์มินัลด่วน การกลับสู่การสนทนาและการแจ้งเตือนของเอเจนต์ ความหนาของเส้นแบบอักษร ความทึบของกรอบโฟกัส ที่อยู่พร็อกซี Git และรายการตัวกรองกับสถานะของเบราว์เซอร์ ตัวเลือกเบลอพื้นหลังจะแสดงเฉพาะเมื่อพื้นหลังโปร่งแสงและปิดตัวเลือกลดความโปร่งใสของ macOS

## พฤติกรรมของไฟล์ [#how-the-file-behaves]

ควรรู้ก่อนแก้ด้วยมือ:

- **อ่านการเปลี่ยนแปลงขณะแอปทำงาน** การแก้ภายนอกที่ถูกต้องมีผลอัตโนมัติ ค่าสำหรับเทอร์มินัลใหม่ยังต้องเปิดบานใหม่ ไฟล์ที่อ่านไม่ได้หรือไวยากรณ์ผิดจะคงค่าที่ถูกต้องล่าสุด ไฟล์ที่จงใจว่างจะคืนค่าเริ่มต้นหลังรอสั้น ๆ
- **Zshell เขียนใหม่ทุกครั้งที่ค่าซึ่งเก็บในไฟล์เปลี่ยน** ไฟล์ถูกสร้างใหม่ทั้งหมด ความเห็นและคีย์ที่ไม่รู้จักจึงหายเมื่อใช้ตัวควบคุมเหล่านั้นครั้งต่อไป เลือกแหล่งแก้ไฟล์หนึ่งแห่ง หรือเก็บสำเนาหลักไว้ใน dotfile
- **ค่าที่เป็นค่าเริ่มต้นส่วนใหญ่ไม่ถูกเขียน** `font-size`, `terminal.vim-command-hints`, `terminal.restore-history`, `terminal.notify-on-error`, `terminal.prompt-queue-enabled`, `terminal.prompt-queue-auto-dispatch` จะถูกบันทึกเสมอ การลบ `terminal.vim-command-hints`, `terminal.restore-history` หรือ `terminal.notify-on-error` จากไฟล์เดิมจะปิดฟังก์ชันนั้น การลบ `terminal.prompt-queue-enabled` จะคืนค่าเริ่มต้น `true` และการลบ `terminal.prompt-queue-auto-dispatch` จะคืนค่าเริ่มต้น `false` การลบคีย์อื่นจะคืนค่าเริ่มต้นของคีย์นั้น
- **ตัวอ่านออกแบบให้เล็กโดยตั้งใจ** รองรับคีย์แบน คีย์แบบจุด หัว `[table]` ความเห็น `#` และค่าสตริง/ตัวเลข/บูลีน ไม่รองรับอาร์เรย์ ตารางอินไลน์ หรือสตริงหลายบรรทัด
- **ค่าไม่ถูกต้องกลับสู่ค่าปลอดภัย** ขนาดนอกช่วง backend ไม่รู้จัก หรือชื่อธีมผิด ไม่ขัดขวางการเปิด Zshell

การบันทึกคงลิงก์สัญลักษณ์ของไฟล์และโฟลเดอร์ อัปเดตไฟล์ปลายทางแบบอะตอมและรักษาสิทธิ์ การแก้ภายนอกไม่เขียนทับความเห็นหรือคีย์ที่ไม่รู้จัก แต่การบันทึกผ่านหน้าตั้งค่าภายหลังยังสร้างไฟล์ใหม่ตามที่อธิบายข้างต้น

## การแสดงแอป [#application-presence]

### `app-presence`

`"dock"` · `"dock-and-menu-bar"` · `"menu-bar"` — ค่าเริ่มต้น `"dock"`

เลือก **การตั้งค่า → ทั่วไป → แสดง Zshell ใน** เพื่อเปลี่ยนทันที `"dock"` แสดงไอคอน Dock เท่านั้น `"dock-and-menu-bar"` แสดงทั้งสองไอคอน และ `"menu-bar"` แสดงไอคอนแถบเมนูเท่านั้น

แถบเมนูใช้เปิดพื้นที่ทำงานปัจจุบัน เทอร์มินัลด่วน การตั้งค่า และการตรวจหารายการอัปเดต ในทั้งสองโหมดแถบเมนู การปิดหน้าต่างพื้นที่ทำงานสุดท้ายจะซ่อนหน้าต่างโดยเทอร์มินัลและงานยังทำงานอยู่ **เปิดพื้นที่ทำงาน** จะกลับไปยังหน้าต่าง โปรเจกต์ และเซสชันเดิม การปิดหน้าต่างอื่น แผง หรือโปรเจกต์ยังคงจบงานของสิ่งนั้น **ออก** ยังคงใช้ `terminal.preserve-sessions` ส่วน **ออกและจบทุกเซสชัน** จะจบงานทั้งหมด โหมดจะถูกบันทึกไว้หลังเปิดแอปใหม่

## ให้คอมพิวเตอร์ทำงานต่อ [#keep-computer-awake]

### `keep-awake`

`"off"` · `"on"` · `"agents"` — เริ่มต้น `"off"`

เลือก **การตั้งค่า → ทั่วไป → ให้คอมพิวเตอร์ทำงานต่อ** หรือ **Zshell → ให้คอมพิวเตอร์ทำงานต่อ** `"off"` อนุญาตให้พักเครื่องอัตโนมัติ `"on"` ป้องกันขณะที่ Zshell ทำงาน และ `"agents"` ป้องกันเฉพาะขณะที่เอเจนต์ในเครื่องทำงาน

ในโหมด `"agents"` นับทุกช่องเทอร์มินัลในเครื่อง รวมโปรเจกต์เบื้องหลัง หน้าต่างอื่น และช่องแบ่งที่ซ่อนหรือขยาย ไม่นับเอเจนต์ระยะไกล สถานะรอ ว่าง และเสร็จแล้วอนุญาตให้พักเมื่อไม่มีเอเจนต์ในเครื่องอื่นทำงาน และการปิดช่องสุดท้ายที่ทำงานจะยกเลิกการป้องกัน `"on"` ยังคงป้องกันการพักเครื่องอัตโนมัติขณะที่ Zshell ทำงาน การเลือกปิดหรือออกจาก Zshell จะยกเลิกการป้องกันในทุกโหมด แม้เก็บเซสชันไว้

แถวการตั้งค่าแสดงว่าการป้องกันทำงานหรือไม่พร้อมใช้งาน จอภาพยังพักได้ การสั่งพักเอง ปิดฝา และแบตเตอรี่ต่ำยังเป็นไปตาม macOS

## รูปลักษณ์ [#appearance]

### `theme` [#theme]

`"system"` · `"light"` · `"dark"` — เริ่มต้น `"system"`

เลือกหน้าตาแอป `"system"` ตาม macOS ส่วนอีกสองค่าล็อก Zshell ไว้ที่หน้าตานั้น

### `theme-dark` และ `theme-light` [#theme-dark-and-theme-light]

สตริง — เริ่มต้น `"Default Dark"` และ `"Default Light"`

ธีมสีของแต่ละหน้าตา ธีมเปลี่ยนสีช่องเทอร์มินัล กรอบหน้าต่าง แถบด้านข้าง ตัวแก้ไข และ diff พร้อมกัน ธีมเริ่มต้นรักษาแถบด้านข้างโปร่งแสง ส่วนธีมอื่นใช้สีตามชุดสีของตน

หน้าตั้งค่าแสดงชุดธีมคัดสรรร่วมกันของทั้งสอง backend ชื่อที่เขียนเองต้องตรงชื่อแสดงทุกตัวรวมตัวพิมพ์ใหญ่เล็ก ไม่เช่นนั้น Zshell กลับธีมเริ่มต้นที่สอดคล้อง

### `terminal.minimum-contrast` [#terminalminimum-contrast]

`1`–`21` · `3`

**การตั้งค่า → รูปลักษณ์ → สี → ความต่างสีขั้นต่ำ** ปรับความชัดของข้อความเทอร์มินัลได้ตั้งแต่ `1` ถึง `21` (ค่าเริ่มต้น `3`) ค่า `1` คงสี ANSI เดิม ทั้งสองแบ็กเอนด์อัปเดตเทอร์มินัลที่เปิดอยู่และ Quick Terminal โดยไม่เริ่มเชลล์ใหม่ และโปรไฟล์ยังใช้ชุดสีของตนเอง พิกเซลอีโมจิและรูปภาพคงสีเดิม การเลือกข้อความและเคอร์เซอร์ยังใช้แนวทางความชัดในการอ่านของแต่ละแบ็กเอนด์ หากพื้นหลังไม่รองรับอัตราส่วนที่ขอ แต่ละแบ็กเอนด์จะใช้สีที่อ่านง่ายที่สุดที่มี เทอร์มินัลโปร่งใสใช้พื้นหลังเซลล์ที่คำนวณแล้ว ดังนั้นความต่างสีหลังผสมกับเดสก์ท็อปอาจแตกต่างกัน

### `toolbar.visibility` [#toolbarvisibility]

`"hide"` · `"auto"` · `"always"` — เริ่มต้น `"hide"`

ควบคุมแถบเครื่องมือขนาดเล็กใต้แท็บที่ใช้งาน:

- `"hide"` ไม่แสดงในหน้าต่าง
- `"auto"` แสดงเมื่อไดเรกทอรีโปรเจกต์เป็น Git repository เท่านั้น
- `"always"` คงทางเข้า Git ไว้ทุกโปรเจกต์ รวมสถานะ **ไม่มี Git Repository**

ดูสิ่งที่แสดงใน[แถบเครื่องมือ Git](/th/docs/git#the-git-toolbar)

## ข้อความ [#text]

### `font-family` [#font-family]

สตริง — เริ่มต้น `""` หมายถึง JetBrains Mono ที่มาพร้อมแอป

เทอร์มินัล ตัวแก้ไข และตัวดู diff ใช้ตระกูล Latin นี้ร่วมกัน ระบุชื่อตระกูล ไม่ใช่แบบย่อย เช่น `"IBM Plex Mono"` ไม่ใช่ `"IBM Plex Mono Regular"` ตระกูลที่ไม่รู้จักหรือไม่ใช่ monospace กลับสู่ฟอนต์เริ่มต้นที่แนบมา

ลำดับฟอนต์สำรองของเทอร์มินัลคือ Latin ตามด้วย CJK ที่เลือกด้านล่าง Symbols Nerd Font ที่แนบมา และฟอนต์สำรองระบบของ backend ตัวแก้ไขและ diff ยังใช้ระบบสำรอง macOS/WebKit ตามปกติ

### `terminal.font-fallback-family` [#terminalfont-fallback-family]

สตริง — เริ่มต้น `""` หมายถึงฟอนต์สำรองของ backend/ระบบ

เพิ่มตระกูล CJK ที่ติดตั้งหนึ่งตระกูลในลำดับสำรอง ตัวเลือกในหน้าตั้งค่ารวมตระกูลที่มีตัวอักษรตัวอย่างจีน ญี่ปุ่น หรือเกาหลี ไม่จำเป็นต้องเป็น monospace เคร่งครัด เพราะใช้เฉพาะตัวอักษรที่ฟอนต์ Latin หลักไม่มี

### `font-size` [#font-size]

ตัวเลข 8–32 — เริ่มต้น `13`

ขนาดฟอนต์หน่วย point ร่วมกันของเทอร์มินัล ตัวแก้ไข และ diff เป็นคีย์เดียวที่ Zshell เขียนแม้ค่าเท่าค่าเริ่มต้น

### `interface.scale` [#interfacescale]

ตัวเลข 0.9–1.5 — เริ่มต้น `1`

ปรับสเกลแท็บ ไอคอน ปุ่ม แถบด้านข้าง และส่วนติดต่ออื่น เนื้อหาเทอร์มินัล ตัวแก้ไข และ diff ยังคงขนาดฟอนต์ที่ตั้งแยกด้านบน

### `sidebar.font-size` [#sidebarfont-size]

ตัวเลข 9–24 — เริ่มต้น `14`

ขนาดข้อความฐานของแถบด้านข้างทั้งสอง หัวส่วน แถว เมทาดาทา และตัวควบคุมรักษาลำดับขนาดสัมพันธ์เมื่อฐานเปลี่ยน

### `sidebar.double-click-new-session` [#sidebardouble-click-new-session]

บูลีน — เริ่มต้น `true`

ดับเบิลคลิกพื้นที่ว่างในแถบด้านข้างเพื่อสร้างเซสชันในโปรเจกต์ที่เลือก หากไม่ได้เลือกโปรเจกต์จะสร้างโปรเจกต์ใหม่ การคลิกและลากแถวยังคงทำงานตามปกติ

### `terminal.font-ligatures` [#terminalfont-ligatures]

บูลีน — ค่าเริ่มต้น `true`

เปิดหรือปิดอักษรควบแบบเลือกได้ของทั้งสอง backend ที่ **การตั้งค่า → รูปลักษณ์ → อักษรควบของฟอนต์** เมื่อปิดจะเขียนทับ `calt`, `liga`, `clig`, `dlig` และ `hlig` แต่คงการจัดรูปอักษรที่จำเป็นไว้ อักขระ คอลัมน์ เคอร์เซอร์ และการเลือกไม่เปลี่ยน

### `terminal.font-features` [#terminalfont-features]

ข้อความ — ค่าเริ่มต้น `""` ใช้ค่าเริ่มต้นของฟอนต์

กรอกแท็กสี่อักขระใน **คุณสมบัติ OpenType** โดยคั่นด้วยจุลภาคหรือช่องว่าง: `-calt` ปิดรูปอักษรตามบริบท, `ss01` เปิดชุดรูปแบบ 1 และ `zero=1` เปิดเลขศูนย์แบบอื่น `+liga` และ `liga=1` ก็เปิดคุณสมบัติได้ หากแท็กซ้ำจะใช้ค่าหลังสุด สวิตช์อักษรควบมีลำดับความสำคัญเหนือห้าแท็กนี้

การเปลี่ยนแปลงมีผลทันทีต่อเทอร์มินัลที่เปิดและพรีวิว ทั้งสอง backend ใช้คุณสมบัติที่ฟอนต์รองรับ แท็กที่ไม่รองรับไม่มีผล อินพุตไม่ถูกต้องคงค่าที่ถูกต้องล่าสุดไว้ ค่าภายนอกที่ไม่ถูกต้องใช้ค่าเริ่มต้นของฟอนต์ การรีเซ็ตจะล้างรายการและเปิดอักษรควบ

### `terminal.font-thicken` [#terminalfont-thicken]

บูลีน — เริ่มต้น `false`

วาดตัวอักษรเทอร์มินัลให้เส้นหนาขึ้นเล็กน้อยคล้ายการเกลี่ยฟอนต์แบบเดิมของ macOS ทั้งสอง backend รองรับและหน้าพรีวิวแสดงผล การตั้งค่าเก่า `font-thicken` ยังอ่านแล้วเขียนกลับด้วยคีย์แบบจุดปัจจุบัน

### `terminal.font-thicken-strength` [#terminalfont-thicken-strength]

จำนวนเต็ม 0–255 — เริ่มต้น `255`

ควบคุมความหนาเมื่อ `terminal.font-thicken` เป็น true ศูนย์คือระดับหนาน้อยที่สุด ไม่ใช่ปิด Ghostty ใช้ความแรง native macOS ส่วน Alacritty แปลงช่วงเดียวกันเป็นเส้น CoreText ทิศทางและปลายช่วงจึงตรงกัน แต่พิกเซลที่วาดอาจต่าง

### `terminal.cell-width` [#terminalcell-width]

ตัวเลข, 0.75–2 — ค่าเริ่มต้น `1`

ปรับระยะห่างระหว่างคอลัมน์เทอร์มินัลใน **การตั้งค่า → รูปลักษณ์ → ฟอนต์ → ความกว้างเซลล์** ค่าเริ่มต้นคือ 100% และบันทึกเป็นเปอร์เซ็นต์จำนวนเต็ม ทั้งสอง backend อัปเดตเทอร์มินัลที่เปิดอยู่ทันที รวมถึงจำนวนคอลัมน์ PTY เคอร์เซอร์ การเลือกข้อความ และคำใบ้แป้นพิมพ์ ขนาดตัวอักษรไม่เปลี่ยน และอักขระกว้างยังใช้สองคอลัมน์ การปัดเศษตามพิกเซลอาจทำให้ขั้นการปรับจริงต่างกันระหว่าง backend ค่าที่ไม่ถูกต้องจะกลับเป็น 100% ระยะห่างในตัวแก้ไขและ diff ไม่เปลี่ยน

### `terminal.line-height` [#terminalline-height]

ตัวเลข 0.75–2 — เริ่มต้น `1`

คูณความสูงเซลล์ตามธรรมชาติของ backend แต่ละตัวโดยวางตัวอักษรกลางแนวตั้ง เปลี่ยนเฉพาะแถวเทอร์มินัล ไม่เปลี่ยนช่องไฟของตัวแก้ไขหรือ diff

Zshell ไม่มีตัวควบคุมน้ำหนักฟอนต์พื้นฐาน Ghostty เลือกสไตล์ที่มีชื่อหรือแกนแปรผัน ขณะที่ Alacritty/CoreText เลือกหน้าปกติและหนาจากคุณลักษณะ ค่าเดียวร่วมกันไม่อาจรักษาความต่างปกติ/หนาและน้ำหนักฟอนต์สำรองให้สม่ำเสมอทั้งฟอนต์คงที่และแปรผัน

### `terminal.padding-color` [#terminalpadding-color]

`"background"` · `"extend"` · `"always"` — `"extend"`

เลือก **การตั้งค่า → รูปลักษณ์ → พื้นหลัง → สีพื้นที่ขอบ** `"background"` ใช้พื้นหลังธีมเทอร์มินัลในพื้นที่ขอบ `"extend"` ขยายพื้นหลังของเซลล์ที่ใกล้ที่สุด แต่ขอบบนหรือขอบล่างจะคงพื้นหลังธีมไว้หากแถวนั้นมีเซลล์พื้นหลังเริ่มต้น พรอมต์เชลล์ หรือตัวคั่น Powerline `"always"` ขยายทุกขอบโดยไม่ตรวจเงื่อนไขเหล่านี้ แถวล่างที่ว่างยังคงพื้นหลังของตนเอง แถวสีด้านบนจะไม่เติมขอบล่าง การเปลี่ยนแปลงมีผลทันทีต่อเทอร์มินัลที่เปิดอยู่ในทั้งสองแบ็กเอนด์ เมื่อใช้พื้นหลังโปร่งแสง พื้นหลังเริ่มต้นจะคงความทึบที่ตั้งไว้ ส่วนพื้นหลังเซลล์ที่กำหนดชัดเจนและส่วนที่ขยายจะทึบแสง

### `editor.wrap-lines` [#editorwrap-lines]

บูลีน — เริ่มต้น `true`

ตัดบรรทัดยาวแบบอ่อนตามความกว้างช่องใน[ตัวแก้ไขไฟล์](/th/docs/files) หาก false จะเลื่อนแนวนอน ไม่เปลี่ยนการตัดบรรทัดเทอร์มินัลหรือ diff

### `editor.diff-wrap-lines` [#editordiff-wrap-lines]

บูลีน — ค่าเริ่มต้น `true`

**การตั้งค่า → ตัวแก้ไข → ตัดบรรทัดตามความกว้าง diff** และปุ่มตัดบรรทัดในแถบเครื่องมือ diff ใช้ตัวเลือกเดียวกัน บรรทัดยาวจะตัดตามความกว้างช่องทั้งมุมมองรวมและแบ่ง การเปลี่ยนแปลงที่แก้ไขได้ diff ในอดีต และความคิดเห็น PR มีผลทันทีต่อ diff ที่เปิดอยู่ทั้งหมดและบันทึกไว้หลังเปิดแอปใหม่ ปิดเพื่อกลับไปเลื่อนแนวนอน ตัวเลือกนี้แยกจากการตัดบรรทัดในตัวแก้ไขไฟล์และเทอร์มินัล

### `editor.protect-saves` [#editorprotect-saves]

บูลีน — ค่าเริ่มต้น `true`

ตรวจสอบการเปลี่ยนแปลงจากโปรแกรมอื่นก่อนบันทึกไฟล์หรือ diff ที่แก้ไขได้ในเวิร์กทรี เมื่อเกิดความขัดแย้ง คุณสามารถเปรียบเทียบ โหลดใหม่ เก็บแบบร่าง หรือเขียนทับอย่างชัดเจน การปิดตัวเลือกนี้จะอนุญาตให้แทนที่การเปลี่ยนแปลงภายนอกโดยไม่แจ้งเตือน

### `editor.recover-drafts` [#editorrecover-drafts]

บูลีน — ค่าเริ่มต้น `true`

Zshell สำรองการเปลี่ยนแปลงที่ยังไม่ได้บันทึกในไฟล์ภายในเครื่องและ diff ที่แก้ไขได้ในต้นไม้การทำงานโดยค่าเริ่มต้น หลังออกจากแอปโดยไม่คาดคิด แผงที่เปิดอีกครั้งจะคืนค่าฉบับร่าง การเลือก และเค้าโครง กู้คืนข้อมูลสำรองอื่นได้จาก **ไฟล์ → กู้คืนฉบับร่าง…** หรือ **การตั้งค่า → ตัวแก้ไข → กู้คืนฉบับร่าง…** เลือกข้อมูลสำรอง ตรวจเนื้อหา แล้วเลือก **คืนค่าฉบับร่าง** การคืนค่าเปิดตัวแก้ไขที่ยังไม่ได้บันทึกและไม่เปลี่ยนไฟล์บนดิสก์ เมื่อบันทึกจะยังตรวจการเปลี่ยนแปลงภายนอกโดยใช้เวอร์ชันก่อนแก้ไข

ควบคุมจาก **การตั้งค่า → ตัวแก้ไข → สำรองฉบับร่างที่ยังไม่ได้บันทึก** หรือ `editor.recover-drafts` การปิดจะหยุดสำรองใหม่และกู้คืนอัตโนมัติ แต่เก็บข้อมูลสำรองเดิมไว้ให้กู้คืนหรือลบเอง **ลบข้อมูลสำรอง** ลบเฉพาะรายการที่เลือกและคงการแก้ไขที่เปิดอยู่ การบันทึกสำเร็จหรือเลือก **ไม่บันทึก** เมื่อปิดเสร็จจะลบข้อมูลสำรอง ไฟล์ส่วนตัวเหล่านี้อยู่ใน Mac เครื่องนี้ สูงสุด 32 ฉบับและ 128 MiB กู้คืนได้สูงสุด 30 วัน ขีดจำกัดความจุอาจทำให้ข้อมูลสำรองเก่าถูกลบก่อนกำหนด ไม่รวมไฟล์และข้อความที่แก้ไขเกิน 5 MiB

Zshell ลบข้อมูลสำรองที่หมดอายุเมื่อเริ่มแอปและทุกชั่วโมงขณะทำงาน แม้ปิดการสำรองไว้ หากปิด Zshell ไฟล์ที่หมดอายุจะยังอยู่บนดิสก์จนกว่าจะเปิดแอปครั้งถัดไป

## เทอร์มินัล [#terminal]

### `terminal.startup-program` / `terminal.startup-arguments` [#terminalstartup-program--terminalstartup-arguments]

สตริง — เริ่มต้นไม่ระบุ

เลือก executable และเวกเตอร์อาร์กิวเมนต์สำหรับเทอร์มินัลที่สร้างหลังจากนั้น หากไม่มี `terminal.startup-program` Zshell ใช้ login shell ของบัญชีกับ `-l` ต่อไป โปรแกรมต้องเป็นเส้นทางเต็มที่รันได้ หากเส้นทางหายหรือรันไม่ได้จะใช้ login shell แทนเปิดช่องที่ไม่ทำงาน

`terminal.startup-arguments` แยกอาร์กิวเมนต์โดยไม่เรียก shell เครื่องหมายคำพูดและแบ็กสแลชรักษาขอบเขต รวมช่องว่างและอาร์กิวเมนต์ว่าง แต่ไม่ขยายตัวแปร glob หรือ command substitution เครื่องหมายคำพูดไม่ถูกต้องก็กลับสู่ login shell เช่นกัน argv ที่ CLI ของ Zshell ระบุชัดยังมาก่อนสำหรับเทอร์มินัลนั้น

### `terminal.new-session-directory` [#terminalnew-session-directory]

`"current"` · `"project"` · `"home"` · `"custom"` — ค่าเริ่มต้น `"current"`

เลือก **การตั้งค่า → เทอร์มินัล → ไดเรกทอรีเซสชันใหม่** ปัจจุบันใช้ไดเรกทอรีของเชลล์ในเครื่องที่ทำงานอยู่ รวมถึงเทอร์มินัลแรกของโปรเจ็กต์ใหม่ หากไม่มีเชลล์ในเครื่องจะใช้โฟลเดอร์บ้าน โปรเจ็กต์ใช้รากที่แสดงในไฟล์และ Git (ที่เก็บใกล้ที่สุดหรือเช็กเอาต์ของงานเบื้องหน้า) และใช้ไดเรกทอรีปัจจุบันเมื่ออยู่นอกที่เก็บ บ้านใช้โฟลเดอร์ของบัญชีเสมอ นโยบายนี้ใช้กับเทอร์มินัลด่วนครั้งแรกและพื้นที่ทำงานใหม่ทุกครั้งด้วย

ไดเรกทอรีที่ระบุจาก Finder, CLI, เทมเพลตพื้นที่ทำงาน, worktree, เซสชันที่กู้คืน, โฟลเดอร์ที่ตรึงกับโปรเจ็กต์ หรือกลุ่มแถบด้านข้างมีความสำคัญก่อน การแบ่งบานหน้าต่างคงไดเรกทอรีต้นทางไว้ SSH และเซสชันระยะไกลที่แชร์ยังใช้ไดเรกทอรีบนโฮสต์ระยะไกล การเปลี่ยนค่าไม่เริ่มเทอร์มินัลที่เปิดหรือพื้นที่เทอร์มินัลด่วนที่ใช้ซ้ำใหม่

### `terminal.custom-directory` [#terminalcustom-directory]

ข้อความ — ค่าเริ่มต้น `""`

สำหรับกำหนดเอง ให้กรอกพาธสัมบูรณ์หรือ `~/folder` หรือเลือกโฟลเดอร์ในการตั้งค่า Zshell ตรวจว่าโฟลเดอร์มีอยู่และเข้าได้ หากไม่มี เข้าถึงไม่ได้ หรือพาธไม่ถูกต้อง จะใช้ไดเรกทอรีปัจจุบันในเครื่อง (บ้านหากไม่มี) และแสดงเหตุผลในการตั้งค่า พาธที่บันทึกยังอยู่เมื่อเปลี่ยนนโยบาย

### `terminal.term`

Zshell ตั้งค่า `xterm-256color` ให้อัตโนมัติ หากโฮสต์ต้องใช้เทอร์มินัลชนิดอื่น ให้ตั้ง `terminal.term` ใน `config.toml` เป็นชื่อ terminfo ที่ติดตั้งบนเครื่องที่รัน shell การเปลี่ยนแปลงมีผลกับเซสชันภายในและ SSH ใหม่ ส่วน PTY ที่เปิดอยู่และเก็บไว้จะคง `TERM` เดิม ชื่อที่ไม่ถูกต้องจะคงค่าที่ถูกต้องล่าสุด หรือใช้ `xterm-256color` เมื่อเริ่มต้น

### `terminal.backend` [#terminalbackend]

`"libghostty"` · `"alacritty"` — เริ่มต้น `"libghostty"`

เลือก emulator สำหรับเทอร์มินัลที่สร้างต่อจากนั้น ช่องเดิมคง backend ตอนเริ่ม ทั้งสองเป็น native เร่ง GPU รองรับภาพ และใช้ธีมเดียวกัน Alacritty มักใช้หน่วยความจำน้อยกว่า

ดูตัวแปรแวดล้อมและข้อกำหนดความเข้ากันได้ที่ [Backend เทอร์มินัล](/th/docs/terminal#terminal-backends)

### `terminal.mouse-scroll-multiplier` / `terminal.trackpad-scroll-multiplier` [#terminal-scroll-multipliers]

ตัวเลข 0.1–10 — ค่าเริ่มต้น `1` สำหรับแต่ละอุปกรณ์

ปรับความเร็วแยกกันที่ **การตั้งค่า → เทอร์มินัล → การเลื่อน → ล้อเมาส์ / แทร็คแพด** ค่าจะแสดงเป็นเปอร์เซ็นต์: 100% คงความเร็วปัจจุบัน 50% ลดครึ่งหนึ่ง และ 200% เพิ่มเป็นสองเท่า การเปลี่ยนแปลงมีผลทันทีในแผง Ghostty และ Alacritty ที่เปิดอยู่ รวมถึงประวัติเลื่อนย้อน โปรแกรมเต็มหน้าจอ และการรายงานเมาส์ การเลื่อนต่อเนื่องใช้ค่าแทร็คแพด ส่วนการเลื่อนแนวนอนยังคงเป็นแนวนอน เมาส์ที่ส่งค่าการเลื่อนแบบละเอียดจะใช้ค่าแทร็คแพดด้วย ค่าที่ขาดหายหรือไม่ถูกต้องจะกลับเป็น `1` การนำเข้า ส่งออก และรีเซ็ตการตั้งค่าครอบคลุมทั้งสองค่า

### `terminal.macos-option-as-alt` [#terminalmacos-option-as-alt]

บูลีน — เริ่มต้น `false`

เมื่อ true ส่งชุดปุ่ม Option เป็น Alt/Meta ให้โปรแกรมเทอร์มินัล ค่าเริ่มต้นคง Option กับแหล่งอินพุต macOS เพื่อให้เค้าโครงอย่าง Polish Pro พิมพ์ตัวอักษรผสมได้

### `terminal.bell` [#terminalbell]

บูลีน — เริ่มต้น `true`

ควบคุมเสียงเตือนและการเรียกความสนใจทางภาพของ macOS เมื่อโปรแกรมส่ง bell หาก false จะไม่เล่นเสียง ไม่ส่งการแจ้งเตือน bell และไม่เรียกความสนใจใน Dock เทคโนโลยีช่วยการเข้าถึงยังรับ bell เป็นการประกาศเชิงความหมาย ทั้งสอง backend ทำตามค่านี้

### `terminal.vim-command-hints` [#terminalvim-command-hints]

บูลีน — เริ่มต้น `true`

แสดงคำสั่ง Vim/Neovim ตามโหมดใต้ข้อมูลเซสชันในแถบ **ข้อมูล** มีผลทันทีบนทั้งสอง backend รวมตัวแก้ไขผ่าน SSH ที่จำแนกได้ ดูเงื่อนไขที่[คำแนะนำคำสั่ง Vim](/th/docs/terminal#vim-command-hints)

### `terminal.restore-history` [#terminalrestore-history]

บูลีน — เริ่มต้น `true`

กู้ประวัติเอาต์พุตของแต่ละเทอร์มินัลไว้เหนือ shell ใหม่เมื่อเปิดแอปใหม่ เนื้อหากู้คืนเป็นข้อความนิ่ง ไม่ใช่โปรเซสที่ยังอยู่

ประวัติเก็บบนดิสก์ จึงอาจรวมความลับที่เคยแสดงในเทอร์มินัล [โปรเจกต์ แท็บ และเค้าโครงช่อง](/th/docs/projects#what-survives-a-relaunch) กู้คืนไม่ว่าจะตั้งค่านี้อย่างไร

## การเข้าถึงผ่านเบราว์เซอร์ [#browser-access]

หากเซสชันที่เก็บไว้จาก Zshell รุ่นเก่ายังทำงาน การเข้าถึงผ่านเบราว์เซอร์จะแนะนำให้ออกและจบทุกเซสชันแล้วเปิดใหม่ งานเดิมจะยังทำงานจนกว่าคุณเลือก

### `browser-access.enabled`

`browser-access.enabled` เป็นบูลีน ค่าเริ่มต้น `false` เปิดใช้ใน **การตั้งค่า → เบราว์เซอร์ → การเข้าถึงผ่านเบราว์เซอร์** แล้วบานหน้าต่างเทอร์มินัลในเครื่องที่เปิดใหม่จะใช้งานได้ บานหน้าต่างเดิมยังใช้โปรเซสเดิม รองรับทั้งสองแบ็กเอนด์และไม่เปลี่ยน `terminal.preserve-sessions`

### `browser-access.interface` / `browser-access.port`

`browser-access.interface` มีค่าเริ่มต้น `"loopback"` (**เฉพาะ localhost**) สำหรับอุปกรณ์อื่น ให้เลือกอินเทอร์เฟซ IPv4 ส่วนตัวของ LAN หรือ Tailscale ที่พร้อมใช้งานอย่างชัดเจน ค่าที่บันทึกรวมชื่อและที่อยู่จริง เช่น `"en0|192.168.0.10"` ส่วน `browser-access.port` คือพอร์ต HTTPS ช่วง 1024–65535 ค่าเริ่มต้น `7443` หน้าท้องถิ่นใช้ที่อยู่ HTTP แยกต่างหากที่เข้าถึงได้เฉพาะบน Mac หากอินเทอร์เฟซหายไปต้องเลือกใหม่ บริการจะไม่เปลี่ยนไปรับฟังทุกอินเทอร์เฟซ

หน้า HTTP ในเครื่องปกติใช้พอร์ต HTTPS ที่ตั้งไว้บวกหนึ่ง (ค่าเริ่มต้น `7444`) เมื่อสถานะการใช้งานพอร์ตไม่เปลี่ยน การพักเครื่อง ลองอีกครั้ง และเปิดใหม่จะคงที่อยู่และสิทธิ์ไว้ หากพอร์ตถูกใช้งาน Zshell จะลองพอร์ตในเครื่องเจ็ดพอร์ตถัดไป และหลัง `65535` จะวนกลับไป `1024` หากสถานะการใช้งานพอร์ตเปลี่ยน การเริ่มใหม่อาจเลือกที่อยู่อื่น สิทธิ์เดิมผูกกับต้นทางเดิม จึงต้องจับคู่ใหม่สำหรับที่อยู่ใหม่ ยังดูและเพิกถอนไคลเอนต์ที่บันทึกไว้ได้เมื่อปิดการเข้าถึง เมื่อครบ 32 ไคลเอนต์ ให้เพิกถอนหนึ่งรายก่อนอนุมัติรายใหม่ หากตรวจสอบบริการเซสชันไม่ได้ การเข้าถึงจะยังเปิดอยู่ ให้คลิกลองอีกครั้งเมื่อบริการพร้อม

เทียบลายนิ้วมือ TLS และเชื่อถือใบรับรองที่ส่งออกบนไคลเอนต์ก่อนจับคู่ระยะไกล อนุมัติหรือเพิกถอนไคลเอนต์บน Mac การปิดใช้ พักเครื่อง หรือออกจากแอปจะตัดการเชื่อมต่อ การออกจากแอปยังทำตามการตั้งค่าเก็บเซสชัน ดู [เข้าถึง Mac เครื่องนี้ผ่านเบราว์เซอร์](/th/docs/remote-sessions#browser-access)

## ระบบอัตโนมัติ [#automation]

### `ai.enabled` [#aienabled]

บูลีน — เริ่มต้น `true`

ให้เอเจนต์เขียนโค้ดที่รองรับประสานช่องเบื้องหลังเมื่อขอด้วยภาษาปกติ และแสดงสถานะวงจรชีวิตจากผู้ให้บริการใน UI แนะนำให้เปลี่ยนด้วยสวิตช์ในหน้าตั้งค่า เพราะแสดงข้อผิดพลาดในหน้าและไม่แก้การตั้งค่าเดิมที่ชนกัน

ขั้นตอนสำหรับผู้ใช้อธิบายที่[ทำงานร่วมกับเอเจนต์ AI](/th/docs/automation)

เมื่อใช้ Codex app-server ร่วมกัน Zshell จะจับคู่ ID การสนทนาที่ตรวจสอบแล้วกับบานหน้าต่างเบื้องหน้า และไม่ผูกเมื่อกำกวม การผสานรวมที่จัดการจะเพิ่ม `session-id` ในชื่อเทอร์มินัล Codex โดยคงรายการอื่นไว้

### `ai.resume-conversations` [#airesume-conversations]

ค่าบูลีน — ค่าเริ่มต้น `true`

เมื่อกู้คืนแผงเทอร์มินัลและ PTY เดิมไม่พร้อมใช้งาน จะสนทนาเดิมที่บันทึกไว้ของ Claude Code, Codex, Pi หรือ OpenCode ต่อโดยใช้บทสนทนาเดิมนั้น ต้องมี `ai.enabled = true` แผงที่ไม่มีบทสนทนาที่ตรวจสอบแล้วจะเปิดเชลล์ใหม่ Zshell จะไม่เลือกบทสนทนาล่าสุดจากไดเรกทอรี

ควบคุมได้ที่ **การตั้งค่า → ระบบอัตโนมัติ → สนทนากับเอเจนต์ต่อ** แยกจาก `terminal.restore-history`

## สำรองและย้ายการตั้งค่า [#backup-and-migration]

ใช้ **Zshell → ส่งออกการตั้งค่า…** เพื่อบันทึก TOML และ **นำเข้าการตั้งค่า…** เพื่อโหลด การนำเข้าขอยืนยันแทนที่และพยายามสำรองไฟล์ปัจจุบันเป็น `config.toml.bak` ในโฟลเดอร์เดียวกัน

การนำเข้าจะอ่านการตั้งค่าที่รองรับทั้งหมด คีย์ที่ละไว้ใช้ค่าเริ่มต้นของตัวอ่าน หากไม่มี `ai.enabled` จะคงการตั้งค่า AI ปัจจุบัน ภาษาและตัวแปรสภาพแวดล้อมของโปรเจกต์หรือแท็บจะบันทึกแยกกัน

## แป้นพิมพ์ลัด [#keyboard-shortcuts]

เปิด **การตั้งค่า → ปุ่มลัด** เพื่อบันทึกชุดปุ่มใหม่ให้คำสั่งหลัก Zshell ปฏิเสธชุดที่ขัดกันและบอกชื่อคำสั่งที่ใช้อยู่ **คืนปุ่มลัดเริ่มต้น** ล้างค่าทับทั้งหมด [คู่มือปุ่มลัด](/th/docs/shortcuts) แสดงค่าเริ่มต้นที่มากับแอป

## การตั้งค่านอกไฟล์นี้ [#settings-outside-this-file]

- **ภาษา** หน้าตั้งค่ามีค่าตามระบบและ 17 ภาษาเช่นเดียวกับเว็บไซต์ เปลี่ยนแล้วมีผลทันทีขณะเซสชันเทอร์มินัลยังรัน ใช้ค่าภาษารายแอปของ macOS จึงเก็บใน preferences ของ Zshell ไม่ใช่ TOML ค่าตามระบบตามลำดับภาษาของ macOS
- **อัปเดตอัตโนมัติ** สวิตช์ตรวจ ดาวน์โหลด และติดตั้งใน **การตั้งค่า → การอัปเดต** เก็บใน preferences นอก TOML และจำข้ามการเปิดแอป ตัวควบคุมดาวน์โหลดจะแสดงเมื่อเปิดการตรวจอัตโนมัติและสามารถอัปเดตอัตโนมัติได้ ส่วนตัวควบคุมติดตั้งต้องเปิดการดาวน์โหลดอัตโนมัติด้วย ดู[การติดตั้ง](/th/docs/installation#updates)
- **สถานะหน้าต่างและเค้าโครง** ขนาดหน้าต่าง ความกว้างแถบ แผงที่เลือก โปรเจกต์ แท็บ ช่อง URL เบราว์เซอร์ และค่าตัวควบคุม diff อยู่ใน preferences macOS และสแนปช็อตเซสชันของ Zshell
- **ไฟล์ตั้งค่า backend** Zshell ไม่อ่าน `~/.config/ghostty` หรือไฟล์ Alacritty การตั้งค่า Zshell คือช่องทางตั้งค่าที่รองรับสำหรับทั้งคู่


## กฎการรู้จำ Agent [#agent-recognition-rules]

`ai.custom-recognition-rules` · `ai.screen-inference` — `true` / `false`, เริ่มต้น `true`

เปิด **การตั้งค่า → AI → การรู้จำ Agent** หรือ **เทอร์มินัล → เอเจนต์ → จัดการกฎ Agent…** เพื่อเพิ่ม แก้ไข ลบ นำเข้า ส่งออก หรือรีเซ็ตกฎในเครื่อง การรู้จำที่กำหนดเองและการอนุมานจากหน้าจอเป็นสวิตช์แยกกัน โดยเปิดทั้งสองไว้ตามค่าเริ่มต้น เมื่อปิดจะล้างหลักฐานหน้าจอเก่าทันที เหตุการณ์ดั้งเดิมและรายงานโปรแกรมมีความสำคัญก่อน
