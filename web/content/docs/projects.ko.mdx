## 프로젝트 [#projects]

프로젝트는 하나의 작업 단위로, 보통 하나의 저장소에 해당합니다. 각 프로젝트는 독립적인 터미널, 탭과 패널 상태를 가집니다.

<kbd>Cmd</kbd>+<kbd>N</kbd>로 터미널 하나가 있는 프로젝트를 만듭니다. 터미널은 현재 세션의 디렉터리에서 시작하며 세션이 없으면 홈 디렉터리를 사용합니다. 보통 다음으로 `cd`를 사용해 작업할 곳으로 이동하면 됩니다. 이후 Zshell은 그 디렉터리를 포함하는 저장소를 기준으로 파일 트리와 Git 패널을 표시합니다.

`cd` 단계를 건너뛰려면 Finder에서 폴더를 오른쪽 클릭한 뒤 **서비스 → 여기에 새 Zshell 프로젝트**를 선택하세요. 폴더 안에서 터미널이 시작된 프로젝트로 열립니다.

Zshell은 프로젝트 단위로 작업을 전환합니다.

| 작업 | 단축키 |
| --- | --- |
| 새 프로젝트 | <kbd>Cmd</kbd>+<kbd>N</kbd> |
| 프로젝트 1–9로 이동 | <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> |
| 다음 / 이전 프로젝트 | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> |
| 프로젝트 사이드바 가리기 | <kbd>Cmd</kbd>+<kbd>B</kbd> |

프로젝트 이름은 선택한 세션을 따르므로 탭 제목처럼 터미널 상태를 반영합니다. 사이드바에서 오른쪽 클릭하면 **이름 변경…**, 자동 제목으로 돌아가는 **자동 제목 사용**, **프로젝트 디렉터리 설정…**, **프로젝트 닫기**를 사용할 수 있습니다. 프로젝트를 닫으면 세션이 종료되지만 디스크의 파일은 건드리지 않습니다.

### 저장된 SSH 프로젝트 [#saved-ssh-projects]

명령 팔레트(<kbd>Cmd</kbd>+<kbd>P</kbd>)에서 <strong>새 SSH 프로젝트…</strong>를 선택하세요. 호스트, 선택적인 사용자와 포트, 열 원격 디렉터리를 입력합니다. 인증 방식으로 <strong>SSH 에이전트</strong>, <strong>암호</strong>, <strong>개인 키 파일</strong> 또는 <strong>개인 키 텍스트</strong>를 고르고 연결을 저장한 다음 <strong>연결</strong>을 선택하세요.

저장된 연결은 다시 실행한 뒤에도 사용할 수 있습니다. 선택 사항인 **그룹** 입력란으로 연결 목록을 정리하고 편집 및 삭제 버튼으로 관리하세요. 암호와 붙여넣은 개인 키는 macOS 키체인에 저장됩니다. 개인 키 파일 항목에는 기존 키 파일의 경로를 기억합니다.

추가 옵션이 있는 명령이나 SSH 연결을 실행하려면 [빠른 실행](/ko/docs/quick-launch)을 참고하세요.

### 사이드바 그룹 [#sidebar-groups]

사이드바 아래쪽 <strong>새 그룹</strong>으로 <strong>일반 그룹</strong>이나 <strong>폴더 그룹…</strong>을 만듭니다. 일반 그룹은 홈 디렉터리에서 새 터미널을 시작하고 폴더 그룹은 선택한 폴더를 기본 위치로 사용합니다. 명시적으로 정한 프로젝트 디렉터리가 있으면 그것이 우선합니다. 프로젝트를 다른 그룹으로 옮겨도 실행 중인 터미널이나 고정한 디렉터리는 바뀌지 않습니다.

프로젝트를 그룹 머리글이나 다른 프로젝트 위로 드래그하여 정리하세요. 사이드바 맨 아래 <strong>+ (새 프로젝트)</strong> 위로 끌면 그룹에서 빠집니다. 그룹 머리글을 드래그하여 순서를 바꿀 수도 있습니다. 머리글을 클릭하면 접거나 펼치고, 두 번 클릭하면 이름을 바꿀 수 있으며 컨텍스트 메뉴도 사용할 수 있습니다. <strong>색상 표시 설정…</strong>으로 그룹 색상을 정하거나 <strong>색상 표시 제거</strong>로 지우세요. <strong>그룹 제거</strong>를 해도 안의 프로젝트는 모두 열린 상태로 남습니다. 숫자 단축키는 현재 표시되는 프로젝트 행을 따르며, 다음/이전 프로젝트 탐색으로 접힌 그룹의 항목을 표시할 수도 있습니다.

Finder의 폴더를 사이드바 프로젝트 목록의 어느 곳에나 놓을 수 있습니다. 이미 열린 폴더라면 중복 프로젝트를 만들지 않고 해당 프로젝트로 포커스를 이동합니다.

### 프로젝트 디렉터리 [#the-project-directory]

파일 트리와 Git 패널은 어느 폴더를 표시할지 알아야 합니다. 기본적으로 Zshell이 터미널의 현재 디렉터리에서 위로 올라가며 **가장 가까운 상위 Git 저장소**를 찾습니다.

그래서 저장소 안에서 `cd`로 이동해도 파일 트리는 튀지 않고 저장소 루트를 유지합니다. 저장소 밖에서는 패널이 터미널 디렉터리를 그대로 따릅니다.

포그라운드 프로그램이 다른 체크아웃으로 이동하면 파일, Git과 정보 패널도 그 체크아웃을 따릅니다. 에이전트가 자기 Git 작업 트리로 이동하는 경우가 한 예입니다. 포그라운드 작업이 돌아오면 패널도 돌아옵니다. 수동으로 고정한 프로젝트 디렉터리가 항상 우선하며, 고정하면 이런 자동 루트 변경은 꺼집니다.

디렉터리를 고정하려면 프로젝트를 오른쪽 클릭한 뒤 <strong>프로젝트 디렉터리 설정…</strong>을 선택하세요. 고정 폴더는 재실행 후에도 기억하며 <strong>자동 디렉터리 사용</strong>으로 다시 자동 제어에 맡길 수 있습니다.

<Callout type="info">
정보 패널(<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd>)은 두 위치를 보여 줍니다. 서로 다를 때 셸의 실제 **현재 디렉터리**를 표시하고, 패널 기준인 **프로젝트 디렉터리**에는 자동으로 정한 경우 `(AUTO)` 표시를 붙입니다.
</Callout>

## 세션 [#sessions]

각 프로젝트에는 원하는 만큼 세션을 둘 수 있으며 위쪽에 탭으로 표시됩니다. 세션은 계정에 설정된 `zsh`, `fish`, `bash` 등의 실제 로그인 셸이며 독립적인 작업 디렉터리와 스크롤 기록을 가집니다.

| 작업 | 단축키 |
| --- | --- |
| 새 세션 | <kbd>Cmd</kbd>+<kbd>T</kbd> |
| 탭 1–9로 전환 | <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> |
| 탭 전환기 (최근 사용 순서) | <kbd>Ctrl</kbd>+<kbd>Tab</kbd> |
| 다음 / 이전 탭 | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> |
| 포커스된 분할 창 닫기 | <kbd>Cmd</kbd>+<kbd>W</kbd> |

새 로컬 세션은 고정된 프로젝트 디렉터리가 있으면 그곳에서 시작하고, 없으면 사이드바 그룹의 기본 디렉터리를 사용합니다. 둘 다 없으면 현재 세션의 디렉터리를 이어받으며 그것도 없으면 홈 디렉터리를 사용합니다.

### 탭 그룹 [#tab-groups]

탭을 오른쪽 클릭하고 **그룹으로 이동 → 새 탭 그룹**을 선택하세요. 탭이 새 그룹에 들어가며 그룹은 이름 없이 색상 화살표로 표시됩니다. 그룹 안의 탭에서 새로 연 세션은 그 그룹에 남습니다. 그룹 화살표를 오른쪽 클릭하여 **그룹에 새 세션**을 선택하면 그룹 안에 직접 만들 수 있습니다.

탭을 그룹 화살표나 다른 탭 위로 끌어 이동하세요. 컨텍스트 메뉴에도 그룹 목록과 **그룹에서 제거**가 있습니다. 화살표를 클릭하면 그룹을 접거나 펼칩니다. 접어도 활성 터미널은 실행 중이며 계속 표시됩니다. 숨겨진 그룹 항목으로 전환하면 그룹이 펼쳐집니다. 그룹을 제거해도 탭과 세션은 열린 상태로 남습니다. 그룹 안의 탭을 고정하면 그룹 밖의 고정 영역으로 옮깁니다. 그룹 화살표를 오른쪽 클릭하여 **색상 표시 설정…** 또는 **색상 표시 제거**를 선택하세요. 그룹 색상과 접힘 상태는 Zshell 재실행 후에도 복원됩니다.

탭을 사이드바 프로젝트에 놓거나 사이드바 그룹 머리글에 놓아 그 그룹 안에 새 프로젝트를 만들 수도 있습니다. 사이드바 아래쪽 <strong>+ (새 프로젝트)</strong>에 놓으면 모든 사이드바 그룹 밖에 프로젝트를 만듭니다. 탭 메뉴의 <strong>탭을 프로젝트로 이동</strong>은 다른 창의 프로젝트에도 이동할 수 있습니다. 이동해도 실행 중인 터미널과 분할 창 배치는 유지됩니다. 프로젝트의 로컬 또는 SSH 위치는 같아야 하며, 탭에서 새 프로젝트를 만들면 원래 위치를 유지합니다. 차이 보기가 들어 있는 탭은 현재 프로젝트에 남습니다.

### 탭 제목 [#tab-titles]

탭 제목은 터미널이 보고하는 내용을 사용합니다. 셸의 프롬프트 이스케이프나 현재 실행 중인 프로그램이 설정할 수 있습니다. 탭을 오른쪽 클릭해 <strong>이름 변경…</strong>으로 직접 정하고, <strong>자동 제목 사용</strong>으로 다시 터미널을 따르게 할 수 있습니다.

나머지 탭 메뉴에는 **닫기**, **다른 항목 닫기**, **오른쪽 탭 닫기**, **모두 닫기**와 세션 디렉터리의 **Finder에서 보기**, **절대 경로 복사**가 있습니다. **파일 닫기**와 **차이 보기 닫기**는 프로젝트 전체의 해당 유형 콘텐츠를 닫되 터미널과 브라우저 분할 창은 그대로 둡니다.

## 창 [#windows]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd>로 새 창을 엽니다. 각 창은 프로젝트와 사이드바 상태가 독립적이며 복원도 개별적으로 이루어집니다.

## 재실행 후 유지되는 항목 [#what-survives-a-relaunch]

Zshell은 작업 중에 배치를 저장하므로 종료한 뒤 다시 열면 다음 항목이 복원됩니다.

- 모든 프로젝트와 순서
- 사용자 지정 이름, 고정 여부와 색상 표시를 포함한 모든 탭
- 이름, 색상, 순서, 소속과 접힘 상태를 포함한 사이드바 그룹
- 색상, 순서, 소속과 접힘 상태를 포함한 탭 그룹
- 고정된 프로젝트 디렉터리와 빈 프로젝트
- 각 탭 안의 분할 창 배치
- 열린 사이드바와 선택한 오른쪽 패널

터미널은 이전 디렉터리의 **새 셸**로 돌아옵니다. Zshell이 백그라운드에 프로세스를 살려 두지는 않습니다. 종료할 때 빌드 중이었다면 그 빌드도 함께 멈춥니다.

이전 스크롤 기록은 [`terminal.restore-history`](/ko/docs/configuration#terminalrestore-history)로 요청한 경우에만 복원합니다. 복원할 기록을 디스크에 저장하므로 기본적으로 꺼져 있습니다.

## 터미널 환경과 초기화 [#terminal-environment-and-initialization]

프로젝트를 선택하고 <strong>터미널 → 프로젝트 터미널 환경…</strong>에서 환경 변수와 초기화 명령을 설정하세요. 현재 탭에 별도로 적용하려면 <strong>터미널 → 탭 터미널 환경…</strong>을 사용합니다.

| 범위 | 동작 |
| --- | --- |
| 프로젝트 | 프로젝트의 새 터미널이 해당 변수와 초기화 명령을 이어받음 |
| 탭 | 같은 이름의 프로젝트 변수를 덮어쓰며, 명령은 프로젝트 명령을 상속하거나 대체하거나 비활성화할 수 있음 |

변경은 저장 후에 만드는 터미널에만 적용됩니다. 기존 프로세스는 현재 환경을 유지합니다. 초기화는 일반 로그인 셸에서만 실행되며 사용자 지정 시작 프로그램이나 명시적인 argv에는 적용되지 않습니다. `ZSHELL_*`, `TERM`, `COLORTERM`, `TERM_PROGRAM` 및 `TERM_PROGRAM_VERSION`은 Zshell이 관리하므로 재정의할 수 없습니다.
