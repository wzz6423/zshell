لم يحصل Zshell على توثيق Apple. تعرض [الصفحة الرئيسية](/ar) الحد الأدنى من إصدار macOS الذي يتطلبه الإصدار الحالي، بجانب رابط التنزيل.

## التنزيل [#download]

نزّل ملف `.dmg` من [الصفحة الرئيسية](/ar). يوفّر الإصدار الحالي 0.1.8 حزم Universal وApple Silicon وIntel، مع نسخة مرآة على Gitee. افتح صورة القرص واسحب **Zshell** إلى مجلد التطبيقات.

قد يمنع macOS تشغيل التطبيق في المرة الأولى. بعد محاولة فتحه، انتقل إلى **إعدادات النظام ← الخصوصية والأمان ← فتح على أي حال**، ثم أكّد فتح Zshell. ينطبق ذلك أيضًا على التثبيت باستخدام Homebrew.

## Homebrew [#homebrew]

```bash
brew install wzz6423/tap/zshell
```

توجد حزمة cask في `wzz6423/homebrew-tap`، وتثبّت ملف ZIP المناسب لمعالج جهاز Mac لديك. يستخدم Zshell خدمة Sparkle للتحديثات بعد التثبيت. للتحديث صراحةً عبر Homebrew، أو لترقية نسخة مثبتة متأخرة عن الإصدار الحالي:

```bash
brew upgrade --cask --greedy-auto-updates zshell
```

## التحديثات [#updates]

تستخدم التنزيلات المباشرة وعمليات التثبيت عبر Homebrew خدمة [Sparkle](https://sparkle-project.org). في بر الصين الرئيسي، يجرّب Zshell مصدر Gitee أولًا ثم GitHub؛ وفي المناطق الأخرى يجرّب GitHub أولًا ثم Gitee. يعتمد على بلد عنوان IP الخاص بالشبكة عندما يتاح، ويرجع إلى منطقة macOS إذا فشل تحديد البلد. إذا فشل جلب موجز التحديث أو التنزيل، يجرّب المصدر الآخر مرة واحدة.
يستخدم تحديد البلد خدمة [ipinfo.io/country](https://ipinfo.io/country)، بمهلة خمس ثوانٍ وذاكرة تخزين مؤقت داخل الذاكرة لمدة 30 دقيقة. يكشف هذا الطلب عنوان IP العام للشبكة لتلك الخدمة؛ ولا يحفظ Zshell العنوان. يؤدي إيقاف التحقق التلقائي أيضًا إلى إيقاف طلبات تحديد البلد في الخلفية.

يتحقق Zshell من الموجز الموقّع وحزمة التحديث قبل التثبيت، ويحافظ على المعمارية المثبتة؛ أما تطبيقات Intel التي تعمل عبر Rosetta فتنتقل إلى Apple Silicon.

افتح **الإعدادات ← التحديثات** (<span dir="ltr"><kbd>Cmd</kbd>+<kbd>,</kbd></span>) للتحكم في التحقق التلقائي وخيار **تنزيل التحديثات تلقائيًا**. يكون التنزيل معطّلًا افتراضيًا ويتطلب تفعيل التحقق التلقائي. عند تفعيل التنزيل، يظهر مفتاح منفصل هو **تثبيت التحديثات تلقائيًا**، ويكون معطّلًا افتراضيًا. عندما يكون التثبيت معطّلًا، تُنزّل التحديثات في الخلفية وتُثبّت عند إنهاء Zshell. وعند تفعيل الخيارين، تُثبّت التحديثات الجاهزة ويُعاد تشغيل Zshell تلقائيًا. تتوقف عمليات الطرفية الجارية أثناء إعادة التشغيل؛ وتُستعاد مساحة العمل عند فتح Zshell مجددًا. يؤدي إيقاف التنزيل إلى إخفاء مفتاح التثبيت ومنع إعادة التشغيل التلقائية، مع الاحتفاظ بتفضيل التثبيت للمرة التالية التي يُفعّل فيها التنزيل. يبقى الخياران محفوظين بعد إعادة تشغيل التطبيق. عند توافر تحديث، تظهر أيقونة تحديث أسفل الشريط الجانبي للمشاريع، إلى يسار زر الملاحظات. انقر عليها لفتح التحديث أو عرض تقدمه، أو لإعادة محاولة إعادة تشغيل معلّقة. اختر **التحقق من وجود تحديثات…** للتحقق يدويًا. يظل أمر Homebrew أعلاه متاحًا لإجراء تحديث صريح.

## الأدوات الموصى بها [#recommended-tools]

افتح **الإعدادات ← التوصيات** لتصفح أدوات الطرفية والشبكات والتطوير والأدوات المساعدة وتطبيقات سطح المكتب، بما فيها Zisla. تكتشف الصفحة الأدوات المثبتة وتتحقق من التحديثات المتاحة ما دامت مفتوحة. استخدم زر **تثبيت** أو **تحديث** الخاص بالأداة، أو **تثبيت الأدوات الناقصة** لكل التوصيات غير المثبتة، أو **تحديث الكل** للتحديثات المتاحة للأدوات التي يديرها Homebrew.

يستخدم تثبيت الأدوات Homebrew. إذا لم يكن مثبتًا، تعرض الصفحة رابط تعليمات تثبيته. لا تثبّت عمليات التحقق الأدوات أو تحدّثها من تلقاء نفسها. تحمل الأدوات المكتشفة خارج Homebrew تسمية **خارج Homebrew**. يثبّت خيار **استخدام Homebrew** نسخة يديرها Homebrew؛ وقد تبقى النسخة الموجودة أسبق في `PATH` الخاص بالصدفة. استخدم **تحديث الحالة** للتحقق مجددًا بعد تغيير التثبيت. أما Zshell نفسه فتديره من **الإعدادات ← التحديثات**.

## فتح مجلد من Finder [#open-a-folder-from-finder]

يسجّل Zshell خدمة في macOS باسم **مشروع Zshell جديد هنا**. حدّد مجلدًا واحدًا أو عدة مجلدات في Finder، وانقر بزر الفأرة الأيمن، ثم اخترها من القائمة الفرعية **الخدمات**. يُفتح كل مجلد كمشروع مع طرفية بدأت فيه بالفعل.

إذا لم تظهر في القائمة، فعّلها من **إعدادات النظام ← لوحة المفاتيح ← اختصارات لوحة المفاتيح ← الخدمات ← الملفات والمجلدات**. لا يُدرج macOS الخدمة الجديدة إلا بعد تشغيل التطبيق مرة واحدة.

## إلغاء التثبيت [#uninstalling]

إذا كان **الإعدادات ← الأتمتة ← الذكاء الاصطناعي** مفعّلًا، فأوقفه قبل حذف التطبيق حتى يتمكن Zshell من إزالة دعم الوكلاء الذي ثبّته.

احذف `zshell.app` من مجلد التطبيقات، ثم أزل إعداداته إذا أردت البدء من حالة نظيفة:

```bash
rm -rf ~/.config/zshell
```

يوجد تخطيط النوافذ وعروض الأشرطة الجانبية ولقطة الجلسة في مخزن تفضيلات macOS نفسه:

```bash
defaults delete sh.zshell
```
