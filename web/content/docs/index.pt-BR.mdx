## Estrutura do espaço de trabalho [#workspace-structure]

| Objeto | Finalidade |
| --- | --- |
| Projeto | Uma pasta local ou conexão SSH, organizada em grupos na barra lateral |
| Sessão | Uma aba de projeto que você pode renomear, colorir, fixar e agrupar |
| Painel | Um terminal, navegador, editor ou diff dentro de uma aba; divida painéis para trabalhar lado a lado |

## Licença e privacidade [#license-and-privacy]

O Zshell é gratuito, tem código público sob a PolyForm Noncommercial License 1.0.0 e não exige conta nem assinatura. O aplicativo não tem telemetria nem análise de uso. Atualizações e verificações de versões de ferramentas podem acessar a rede; painéis de navegador e ferramentas de linha de comando fazem suas próprias requisições. Consulte as [perguntas frequentes](/pt-BR/docs/faq).
