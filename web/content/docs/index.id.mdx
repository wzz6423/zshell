## Struktur ruang kerja [#workspace-structure]

| Objek | Kegunaan |
| --- | --- |
| Proyek | Direktori lokal atau koneksi SSH, diatur dalam grup bilah samping |
| Sesi | Tab proyek yang dapat diubah namanya, diberi warna, disematkan, dan dikelompokkan |
| Panel | Terminal, browser, editor, atau tampilan perbedaan dalam tab; bagi panel untuk bekerja berdampingan |
