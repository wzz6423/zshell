## ワークスペースの構造 [#workspace-structure]

| 対象 | 役割 |
| --- | --- |
| プロジェクト | ローカルのディレクトリまたは SSH 接続。サイドバーのグループで整理します |
| セッション | プロジェクト内のタブ。名前や色の変更、固定、グループ化ができます |
| ペイン | タブ内のターミナル、ブラウザ、エディタ、差分表示。分割して並べて使えます |

## ライセンスとプライバシー [#license-and-privacy]

Zshell は無料です。ソースコードは PolyForm Noncommercial License 1.0.0 のもとで公開されており、アカウントやサブスクリプションは不要です。
アプリにテレメトリや分析機能はありません。更新、ツールのバージョン確認、設定したエージェント使用量サービスは通信する場合があります。
ブラウザペインとコマンドラインツールはそれぞれ独自に通信します。[よくある質問](/ja/docs/faq)も参照してください。
