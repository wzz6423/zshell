## 작업 공간 구조 [#workspace-structure]

| 요소 | 용도 |
| --- | --- |
| 프로젝트 | 사이드바 그룹으로 정리하는 로컬 디렉터리 또는 SSH 연결 |
| 세션 | 이름 변경, 색상 지정, 고정 및 그룹화할 수 있는 프로젝트 탭 |
| 분할 창 | 탭 안의 터미널, 브라우저, 편집기 또는 차이 보기. 창을 나누어 나란히 작업 |
