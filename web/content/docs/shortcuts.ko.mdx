---
title: 키보드 단축키
description: Zshell의 모든 기본 단축키를 작업별로 정리했습니다.
---

단축키가 기억나지 않으면 <kbd>Cmd</kbd>+<kbd>P</kbd>로 명령 팔레트를 여세요. 각 명령 옆에 단축키가 표시됩니다.

## 전역 빠른 터미널 [#global-quick-terminal]

| 단축키 | 작업 |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>I</kbd> | 빠른 터미널 표시 / 닫기 |
| <kbd>Esc</kbd> | 빠른 터미널을 닫고 셸 종료 |

**설정 → 터미널 → 빠른 터미널**에서 다른 단축키를 지정할 수 있습니다. 고정되지 않은 터미널은 포커스를 잃어도 닫힙니다. [빠른 터미널](/ko/docs/terminal#global-quick-terminal)을 참고하세요.

## 프로젝트와 세션 [#projects-and-sessions]

| 단축키 | 작업 |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>N</kbd> | 새 프로젝트 |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | 새 세션 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | 새 창 |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | 포커스된 분할 창 닫기 |
| <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | 프로젝트 1–9로 전환 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | 다음 / 이전 프로젝트 |
| <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | 탭 1–9로 전환 |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | 최근 사용 순서의 탭 전환기 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | 다음 / 이전 탭 |

## 분할 창 [#panes]

| 단축키 | 작업 |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | 오른쪽으로 분할 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | 아래로 분할 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+방향키 | 해당 방향의 분할 창으로 포커스 이동 |
| <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> | 분할 창 포커스 순환 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> | 분할 창 확대 전환 |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+방향키 | 포커스된 분할 창 크기 조절 |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> | 분할 창 크기 균등화 |

왼쪽과 위로 분할에는 기본 단축키가 없습니다. **탭** 메뉴, 분할 창의 컨텍스트 메뉴 또는 명령 팔레트를 사용하세요.

## 패널 [#panels]

| 단축키 | 작업 |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>P</kbd> | 명령 팔레트 |
| <kbd>Cmd</kbd>+<kbd>O</kbd> | 빠른 실행 |
| <kbd>Cmd</kbd>+<kbd>B</kbd> | 왼쪽 사이드바 전환 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | 오른쪽 사이드바 전환 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Git 패널 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | 파일 패널 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | 정보 패널 |

## 브라우저와 에이전트 [#browser-and-agents]

| 단축키 | 작업 |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>L</kbd> | 현재 브라우저 주소 막대로 포커스 이동 |
| <kbd>Cmd</kbd>+<kbd>R</kbd> | 현재 브라우저 페이지 새로 고침 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | 확인이 필요한 다음 에이전트로 이동 |

새 브라우저 탭과 분할 창에는 기본 단축키가 없습니다. **파일** 메뉴나 명령 팔레트를 사용하세요.

## 텍스트와 검색 [#text-and-search]

| 단축키 | 작업 |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>F</kbd> | 포커스된 분할 창에서 찾기 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> | 찾기 및 바꾸기 (편집기) |
| <kbd>Cmd</kbd>+<kbd>G</kbd> | 다음 찾기 |
| <kbd>Shift</kbd>+<kbd>Return</kbd> | 찾기 막대 안에서 이전 찾기 |
| <kbd>Cmd</kbd>+<kbd>E</kbd> | 선택 항목으로 찾기 |
| <kbd>Cmd</kbd>+<kbd>K</kbd> | 터미널 지우기 |
| <kbd>Cmd</kbd>+<kbd>S</kbd> | 열린 파일 저장 |
| <kbd>Cmd</kbd>+<kbd>,</kbd> | 설정 |

## 이전 찾기 [#find-previous]

macOS에서 보통 이전 찾기에 쓰는 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd>는 Zshell에서 Git 패널을 전환합니다. 대신 찾기 막대에서 <kbd>Shift</kbd>+<kbd>Return</kbd>을 사용하세요. **편집 → 찾기** 메뉴의 항목도 사용할 수 있습니다.
