กด <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> เพื่อเปิดต้นไม้ไฟล์ เช่นเดียวกับแผง Git รากอยู่ที่[ไดเรกทอรีโปรเจกต์](/th/docs/projects#the-project-directory) จึงไม่ย้ายรากทุกครั้งที่ `cd`

## ต้นไม้ไฟล์ [#the-tree]

เมื่อแผงไฟล์แสดงอยู่และ Zshell ทำงานอยู่เบื้องหน้า ไดเรกทอรีในเครื่องจะรีเฟรชในเบื้องหลัง สำหรับโปรเจกต์ SSH จะอ่านไดเรกทอรีรากและโฟลเดอร์ที่ขยายบนเครื่องระยะไกลใหม่เป็นระยะ

คลิกไฟล์เพื่อเปิดในช่องที่มีโฟกัส คลิกขวาสำหรับส่วนที่เหลือ:

| รายการ | หน้าที่ |
| --- | --- |
| **เปิด** / **เปิดด้านข้าง** | เปิดในช่องนี้หรือช่องแบ่งใหม่ |
| **เปิดในแอปเริ่มต้น** | ส่งไปยังแอปที่ macOS ใช้เปิดไฟล์นั้น |
| **แสดงใน Finder** | |
| **คัดลอกเส้นทาง** | เส้นทางเต็ม |
| **cd ที่นี่** | รัน `cd <folder>` ในเทอร์มินัลที่มีโฟกัส |
| **ไฟล์ใหม่…** / **โฟลเดอร์ใหม่…** | สร้างในโฟลเดอร์ที่เลือก |
| **เปลี่ยนชื่อ** | |
| **ย้ายไปถังขยะ** | ส่งลงถังขยะ ไม่ลบทิ้งทันที |

แต่ละแถวใช้ไอคอน Material ตามชื่อไฟล์ ใน Git repository เส้นทางที่เปลี่ยนมีสีและตราสถานะ ส่วนไฟล์ที่ ignore จะจางลง ต้นไม้จึงแสดงสถานะ worktree เดียวกับแผง Git โดยไม่ต้องเปิดแผง

## นำเข้าไฟล์และโฟลเดอร์ [#import-files-and-folders]

เลือก **ไฟล์ → นำเข้าไฟล์…** ปุ่มนำเข้าในแผงไฟล์ หรือรายการนี้จากเมนูคลิกขวาของโฟลเดอร์ เลือกได้หลายไฟล์และโฟลเดอร์ โดย Zshell จะคัดลอกไปยังโฟลเดอร์ที่เลือกหรือรากของโครงสร้างปัจจุบันและเก็บต้นฉบับไว้

หากต้องการลากรายการจาก Finder ไปยังโฟลเดอร์หรือพื้นที่ว่างของโครงสร้าง ให้เปิด **การตั้งค่า → ตัวแก้ไข → ไฟล์ → นำเข้าโดยลากไปยังโครงสร้างไฟล์** (`files.drag-import`) ค่าเริ่มต้นคือปิด และยังนำเข้าจากเมนูได้เสมอ

เมื่อมีชื่อซ้ำ เลือก **แทนที่** **ข้าม** หรือ **ยกเลิก** ได้ การแทนที่โฟลเดอร์จะแทนทั้งโฟลเดอร์ ไม่รวมเนื้อหาเข้าด้วยกัน การยกเลิกจะหยุดการนำเข้าทั้งหมดและคืนค่าสำเนาที่เพิ่มในครั้งนี้ หากโปรแกรมอื่นแก้ไขรายการก่อนคืนค่า Zshell จะเก็บการแก้ไขและแสดงโฟลเดอร์ที่อาจมีไฟล์สำหรับกู้คืน โครงสร้าง SSH ไม่รับการนำเข้าจากเครื่อง ลิงก์สัญลักษณ์จะคัดลอกเป็นลิงก์โดยไม่ตามเป้าหมาย

## หาไฟล์และค้นหาเนื้อหา [#find-files-and-search-contents]

จานคำสั่ง (<kbd>Cmd</kbd>+<kbd>P</kbd>) หาไฟล์ด้วยชื่อหรือเส้นทางข้ามโปรเจกต์ในเครื่องที่เปิดในหน้าต่างปัจจุบัน พร้อมคำสั่งและเซสชันที่เปิด เลือกไฟล์แล้วจะย้ายไปโปรเจกต์ของมันและเปิดที่นั่น

เพื่อค้นหาข้อความในไฟล์ คลิกแว่นขยายในแผงไฟล์หรือเลือก **ค้นหาเนื้อหาไฟล์** ในจานคำสั่ง ป้อนข้อความแล้ว <kbd>Return</kbd> เพื่อค้นหาในไดเรกทอรีโปรเจกต์ในเครื่องปัจจุบัน ใช้ **Aa** เพื่อแยกตัวพิมพ์ใหญ่เล็ก เปิดผลลัพธ์เพื่อไปบรรทัดที่ตรงในตัวแก้ไข

การค้นหาใช้ข้อความตรงตัว ข้ามไฟล์ไบนารีและโฟลเดอร์ dependencies/build ที่พบบ่อย และหยุดที่ 2,000 ผลลัพธ์ หยุดการค้นหาที่กำลังรันโดยเก็บผลไว้ได้ หรือปิดค้นหาเพื่อกลับต้นไม้ โปรเจกต์ SSH ไม่รวมอยู่ในการค้นหาไฟล์ในเครื่องนี้

## ตัวแก้ไข [#the-editor]

เปิดไฟล์แล้วจะได้ตัวแก้ไขจริงในช่อง พร้อมเน้นไวยากรณ์

| การกระทำ | ปุ่มลัด |
| --- | --- |
| บันทึก | <kbd>Cmd</kbd>+<kbd>S</kbd> |
| ค้นหา | <kbd>Cmd</kbd>+<kbd>F</kbd> |
| ค้นหาและแทนที่ | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> |
| ค้นหาถัดไป | <kbd>Cmd</kbd>+<kbd>G</kbd> |

เมื่อปิดไฟล์ Diff โปรเจกต์ หรือหน้าต่างพื้นที่ทำงาน หรือออกจาก Zshell จะมีการถามให้บันทึกการแก้ไขที่ยังไม่บันทึก หากเลือก **ยกเลิก** หรือบันทึกไม่สำเร็จ พื้นที่ทำงานและเทอร์มินัลที่เกี่ยวข้องจะยังเปิดอยู่ ในโหมดแถบเมนู การปิดหน้าต่างสุดท้ายเพียงซ่อนหน้าต่างและเก็บการแก้ไขไว้ เมื่อออกจากแอปยังคงมีการถามให้บันทึก

บรรทัดยาวตัดตามความกว้างช่องโดยค่าเริ่มต้น ปิด [`editor.wrap-lines`](/th/docs/configuration#editorwrap-lines) เพื่อเลื่อนแนวนอน

การเปลี่ยนชื่อในต้นไม้อัปเดตช่องที่เปิดไฟล์นั้น รวมไฟล์ใต้โฟลเดอร์ที่เปลี่ยนชื่อด้วย

หากโปรแกรมอื่นเปลี่ยนไฟล์ที่เปิด Zshell รีเฟรชพรีวิวที่ไม่มีการแก้ไขเมื่อแอปกลับมาทำงาน จะไม่แทนที่บัฟเฟอร์ตัวแก้ไขที่มีการเปลี่ยนแปลงยังไม่บันทึก

หากโปรแกรมอื่นเปลี่ยนไฟล์ขณะคุณแก้ไข การบันทึกจะเปิดกล่องความขัดแย้ง **เปรียบเทียบ…** แสดงดิสก์และแบบร่างคู่กัน **เก็บแบบร่าง** ยกเลิกการบันทึก **โหลดใหม่จากดิสก์** ทิ้งแบบร่าง และ **เขียนทับไฟล์** แทนที่เวอร์ชันที่เปรียบเทียบ การตรวจสอบนี้ใช้ก่อนปิดและกับ diff ที่แก้ไขได้ด้วย ควบคุมที่ **การตั้งค่า → ตัวแก้ไข → ป้องกันความขัดแย้งในการบันทึก** หรือ [`editor.protect-saves`](/th/docs/configuration#editorprotect-saves)

<Callout type="info">
ตัวแก้ไขนี้สำหรับการเปลี่ยนแปลงที่คุณกำลังดู เช่น แก้คำผิด ปรับค่าคงที่ อ่านไฟล์ที่ diff อ้างถึง ไม่มี language server การเติมโค้ด หรือ refactor ทั้งโปรเจกต์ นี่เป็นการออกแบบโดยตั้งใจ
</Callout>

## กู้คืนฉบับร่างที่ยังไม่ได้บันทึก [#recover-unsaved-drafts]

Zshell สำรองการเปลี่ยนแปลงที่ยังไม่ได้บันทึกในไฟล์ภายในเครื่องและ diff ที่แก้ไขได้ในต้นไม้การทำงานโดยค่าเริ่มต้น หลังออกจากแอปโดยไม่คาดคิด แผงที่เปิดอีกครั้งจะคืนค่าฉบับร่าง การเลือก และเค้าโครง กู้คืนข้อมูลสำรองอื่นได้จาก **ไฟล์ → กู้คืนฉบับร่าง…** หรือ **การตั้งค่า → ตัวแก้ไข → กู้คืนฉบับร่าง…** เลือกข้อมูลสำรอง ตรวจเนื้อหา แล้วเลือก **คืนค่าฉบับร่าง** การคืนค่าเปิดตัวแก้ไขที่ยังไม่ได้บันทึกและไม่เปลี่ยนไฟล์บนดิสก์ เมื่อบันทึกจะยังตรวจการเปลี่ยนแปลงภายนอกโดยใช้เวอร์ชันก่อนแก้ไข

ควบคุมจาก **การตั้งค่า → ตัวแก้ไข → สำรองฉบับร่างที่ยังไม่ได้บันทึก** หรือ `editor.recover-drafts` การปิดจะหยุดสำรองใหม่และกู้คืนอัตโนมัติ แต่เก็บข้อมูลสำรองเดิมไว้ให้กู้คืนหรือลบเอง **ลบข้อมูลสำรอง** ลบเฉพาะรายการที่เลือกและคงการแก้ไขที่เปิดอยู่ การบันทึกสำเร็จหรือเลือก **ไม่บันทึก** เมื่อปิดเสร็จจะลบข้อมูลสำรอง ไฟล์ส่วนตัวเหล่านี้อยู่ใน Mac เครื่องนี้ สูงสุด 32 ฉบับและ 128 MiB กู้คืนได้สูงสุด 30 วัน ขีดจำกัดความจุอาจทำให้ข้อมูลสำรองเก่าถูกลบก่อนกำหนด ไม่รวมไฟล์และข้อความที่แก้ไขเกิน 5 MiB

Zshell ลบข้อมูลสำรองที่หมดอายุเมื่อเริ่มแอปและทุกชั่วโมงขณะทำงาน แม้ปิดการสำรองไว้ หากปิด Zshell ไฟล์ที่หมดอายุจะยังอยู่บนดิสก์จนกว่าจะเปิดแอปครั้งถัดไป

## พรีวิว Markdown [#markdown-preview]

เปิด `.md` เพื่ออ่านพรีวิวที่เรนเดอร์ในช่องเดียวกัน คลิก **แก้ไข** มุมขวาบนเพื่อแก้ต้นฉบับ แล้ว **พรีวิว** เพื่อดูผล Zshell จำโหมดที่ชอบไว้ใช้กับ Markdown อื่นและการเปิดครั้งต่อไป

สลับโหมดแล้วการแก้ไขและประวัติ undo ยังอยู่ บันทึกด้วย <kbd>Cmd</kbd>+<kbd>S</kbd> ตามปกติ ไฟล์ Markdown นามสกุลอื่นเปิดเป็นซอร์ส

## Diff [#diffs]

Diff จาก[แผง Git](/th/docs/git) เป็นช่องเช่นกัน จึงวาง diff ไฟล์ และเทอร์มินัลข้างกันในแท็บได้ ใช้ฟอนต์เทอร์มินัล และชุดเปลี่ยนแปลงพันไฟล์เปิดเร็วเท่าหนึ่งบรรทัด Diff ของ worktree สดที่ยังไม่ stage สลับจากตรวจทานเป็นแก้ไขได้ ส่วน diff ที่ stage แล้วและประวัติยังอ่านอย่างเดียว ดู[อ่าน diff](/th/docs/git#reading-diffs)
