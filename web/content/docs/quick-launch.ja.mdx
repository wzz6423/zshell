---
title: クイック起動
description: 繰り返し使うコマンドや SSH 接続を保存し、キー操作で起動します。
---

<kbd>Cmd</kbd>+<kbd>O</kbd> は**クイック起動（Quick Launch）**を開きます。検索できる起動項目の一覧で、各項目は新しいプロジェクトとターミナルセッションを開きます。
保存できるのは、`npm run dev` や `make watch` などよく入力する**コマンド**、または **SSH 接続**です。

## 起動する [#launching]

名前、コマンド、接続先、グループを入力すると、あいまい検索で一覧を絞り込みます。
行をクリックするか、矢印キーで選んで <kbd>Return</kbd> を押します。
項目と同じ名前の新しいプロジェクトで、専用のターミナルセッションとディレクトリを使って実行されます。

コマンドが終了したり接続が閉じたりしても、ペインは消えず通常のシェルプロンプトに戻ります。起動したものが勝手にペインを閉じることはありません。

保存済み項目は、どの Zshell ターミナルからも名前で起動できます。

```bash
zshell "Entry name"
```

項目の正確な名前を使い、空白を含む場合は引用符で囲んでください。クイック起動の下部にもこの構文が表示されます。項目は新しいプロジェクトに開きます。

## 項目の管理 [#managing-entries]

- <kbd>Cmd</kbd>+<kbd>N</kbd> — 新規項目
- <kbd>Cmd</kbd>+<kbd>E</kbd> — 選択した項目を編集
- <kbd>Cmd</kbd>+<kbd>Delete</kbd> — 選択した項目を削除

任意の<strong>グループ（Group）</strong>欄で、名前付きのセクションに項目を整理できます。
編集・削除ボタンは項目を操作するだけで、起動はしません。

コマンド項目には、常に開始する**作業ディレクトリ**を固定できます。指定しなければ、新しいプロジェクトのデフォルトディレクトリを使います。
SSH 項目にはホスト、任意のユーザーとポート、`-L 8080:localhost:80` などの追加 `ssh` オプションを自由に指定できます。

## 項目の保存場所 [#where-entries-live]

項目は `~/.config/zshell/quick-launch.json` に保存され、全ウィンドウで共有されます。
通常のユーザーデータなので、ファイルを自由に編集・バックアップできます。

<Callout type="info">
コマンドはログインシェルを通して実行されるため、プロファイルの環境が反映されます。その後のペインは通常のセッションとなり、エイリアスやプロンプトもそのまま使えます。
</Callout>
