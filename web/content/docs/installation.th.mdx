Zshell ยังไม่ได้รับการรับรอง notarization จาก Apple [หน้าแรก](/th) แสดงเวอร์ชัน macOS ขั้นต่ำที่รุ่นปัจจุบันต้องใช้ไว้ข้างปุ่มดาวน์โหลด

## ดาวน์โหลด [#download]

ดาวน์โหลด `.dmg` จาก[หน้าแรก](/th) รุ่นปัจจุบัน 0.1.8 มีแพ็กเกจ Universal, Apple Silicon และ Intel พร้อมแหล่งดาวน์โหลดสำรองบน Gitee เปิดดิสก์อิมเมจแล้วลาก **Zshell** ไปที่ Applications

เมื่อเปิดครั้งแรก macOS อาจบล็อกแอป หลังจากลองเปิดแล้ว ให้ไปที่ **การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → เปิดต่อไป** และยืนยันเปิด Zshell วิธีนี้ใช้กับการติดตั้งผ่าน Homebrew ด้วย

## Homebrew [#homebrew]

```bash
brew install wzz6423/tap/zshell
```

Cask อยู่ใน `wzz6423/homebrew-tap` และติดตั้ง ZIP ที่ตรงกับหน่วยประมวลผลของ Mac หลังติดตั้ง Zshell ใช้ Sparkle สำหรับอัปเดต หากต้องการสั่งอัปเดตผ่าน Homebrew โดยตรง หรือไล่ตามรุ่นล่าสุดเมื่อรุ่นที่ติดตั้งเก่าแล้ว:

```bash
brew upgrade --cask --greedy-auto-updates zshell
```

## การอัปเดต [#updates]

ทั้งการดาวน์โหลดโดยตรงและการติดตั้ง Homebrew ใช้ [Sparkle](https://sparkle-project.org) ในจีนแผ่นดินใหญ่ Zshell ลอง Gitee ก่อน GitHub ส่วนที่อื่นลอง GitHub ก่อน Gitee หากทราบประเทศจาก IP เครือข่ายจะใช้ข้อมูลนั้น หากค้นหาประเทศไม่สำเร็จจะใช้ภูมิภาค macOS เมื่อฟีดหรือการดาวน์โหลดล้มเหลวจะลองอีกแหล่งหนึ่งครั้ง การค้นหาประเทศใช้ [ipinfo.io/country](https://ipinfo.io/country) โดยหมดเวลาห้าวินาทีและเก็บแคชในหน่วยความจำ 30 นาที คำขอนี้ทำให้บริการเห็น IP สาธารณะของเครือข่าย แต่ Zshell ไม่บันทึก IP การปิดตรวจอัปเดตอัตโนมัติหยุดการค้นหาประเทศเบื้องหลังด้วย

Zshell ตรวจสอบฟีดและแพ็กเกจที่ลงลายเซ็นก่อนติดตั้ง และคงสถาปัตยกรรมที่ติดตั้งไว้ แอป Intel ที่รันผ่าน Rosetta จะย้ายไป Apple Silicon

เปิด **การตั้งค่า → การอัปเดต** (<kbd>Cmd</kbd>+<kbd>,</kbd>) เพื่อควบคุมการตรวจอัตโนมัติและ **ดาวน์โหลดอัปเดตอัตโนมัติ** การดาวน์โหลดปิดไว้โดยค่าเริ่มต้นและต้องเปิดการตรวจอัตโนมัติก่อน เมื่อเปิดดาวน์โหลดจะเห็นสวิตช์แยก **ติดตั้งอัปเดตอัตโนมัติ** ซึ่งปิดไว้เช่นกัน หากปิดการติดตั้ง อัปเดตจะดาวน์โหลดเบื้องหลังแล้วติดตั้งเมื่อออกจาก Zshell หากเปิดทั้งสอง อัปเดตที่พร้อมจะติดตั้งและเริ่ม Zshell ใหม่โดยอัตโนมัติ โปรเซสเทอร์มินัลจะหยุดระหว่างเริ่มใหม่และพื้นที่ทำงานจะกลับมาเมื่อแอปเปิด การปิดดาวน์โหลดซ่อนสวิตช์ติดตั้งและป้องกันการเริ่มใหม่อัตโนมัติ แต่จดจำค่าติดตั้งไว้สำหรับการเปิดดาวน์โหลดครั้งต่อไป ทั้งสองค่าคงอยู่หลังเปิดแอปใหม่ เมื่อมีอัปเดตจะเห็นไอคอนที่ล่างแถบโปรเจกต์ ด้านซ้ายปุ่มข้อเสนอแนะ คลิกเพื่อเปิดอัปเดต ดูความคืบหน้า หรือลองเริ่มใหม่ที่ค้างอยู่อีกครั้ง เลือก **ตรวจสอบการอัปเดต…** เพื่อตรวจด้วยตนเอง คำสั่ง Homebrew ด้านบนยังใช้สั่งอัปเดตโดยตรงได้

## เครื่องมือแนะนำ [#recommended-tools]

เปิด **การตั้งค่า → คำแนะนำ** เพื่อดูเครื่องมือเทอร์มินัล เครือข่าย การพัฒนา ยูทิลิตี และเดสก์ท็อป รวมถึง Zisla เมื่อเปิดหน้าอยู่ ระบบตรวจหาเครื่องมือที่ติดตั้งและตรวจอัปเดต ใช้ปุ่ม **ติดตั้ง** หรือ **อัปเดต** ของแต่ละเครื่องมือ, **ติดตั้งที่ยังขาด** สำหรับทุกรายการที่ยังไม่มี หรือ **อัปเดตทั้งหมด** สำหรับเครื่องมือที่ Homebrew จัดการ

การติดตั้งเครื่องมือใช้ Homebrew หากยังไม่มี หน้าจะแสดงลิงก์คำแนะนำติดตั้ง การตรวจไม่ติดตั้งหรืออัปเดตเอง เครื่องมือที่ตรวจพบนอก Homebrew มีป้าย **นอก Homebrew** ปุ่ม **ใช้ Homebrew** ติดตั้งสำเนาที่ Homebrew จัดการ แต่สำเนาเดิมอาจยังมีลำดับก่อนใน `PATH` ของ shell ใช้ **รีเฟรช** เพื่อตรวจใหม่หลังเปลี่ยนการติดตั้ง ส่วน Zshell เองจัดการใน **การตั้งค่า → การอัปเดต**

## เปิดโฟลเดอร์จาก Finder [#open-a-folder-from-finder]

Zshell ลงทะเบียนบริการ macOS ชื่อ **โปรเจกต์ Zshell ใหม่ที่นี่** เลือกโฟลเดอร์อย่างน้อยหนึ่งโฟลเดอร์ใน Finder คลิกขวาแล้วเลือกจากเมนูย่อย **บริการ** แต่ละโฟลเดอร์เปิดเป็นโปรเจกต์พร้อมเทอร์มินัลที่เริ่มในตำแหน่งนั้นแล้ว

หากไม่พบในเมนู ให้เปิดที่ **การตั้งค่าระบบ → แป้นพิมพ์ → ปุ่มลัดแป้นพิมพ์ → บริการ → ไฟล์และโฟลเดอร์** macOS จะแสดงบริการใหม่หลังเปิดแอปแล้วอย่างน้อยหนึ่งครั้ง

## ถอนการติดตั้ง [#uninstalling]

หาก **การตั้งค่า → ระบบอัตโนมัติ → AI** เปิดอยู่ ให้ปิดก่อนลบแอป เพื่อให้ Zshell ลบส่วนสนับสนุนเอเจนต์ที่ติดตั้งไว้

ลบ `zshell.app` จาก Applications จากนั้นลบการตั้งค่าหากต้องการเริ่มใหม่ทั้งหมด:

```bash
rm -rf ~/.config/zshell
```

เค้าโครงหน้าต่าง ความกว้างแถบด้านข้าง และสแนปช็อตเซสชันอยู่ในที่เก็บค่ากำหนดของ macOS:

```bash
defaults delete sh.zshell
```
