---
title: Sneltoetsen
description: Alle standaardsneltoetsen van Zshell, gegroepeerd op functie.
---

Een sneltoets vergeten? <kbd>Cmd</kbd>+<kbd>P</kbd> opent het opdrachtenpalet en toont de sneltoets naast elke opdracht.

## Algemene snelle terminal [#global-quick-terminal]

| Sneltoets | Actie |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>I</kbd> | Snelle terminal tonen / sluiten |
| <kbd>Esc</kbd> | Snelle terminal sluiten en de shell beëindigen |

Leg een andere sneltoets vast onder **Instellingen → Terminal → Snelle terminal**. Een niet-vastgezette terminal sluit ook wanneer hij focus verliest. Zie [Snelle terminal](/nl/docs/terminal#global-quick-terminal).

## Projecten en sessies [#projects-and-sessions]

| Sneltoets | Actie |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>N</kbd> | Nieuw project |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | Nieuwe sessie |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | Nieuw venster |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | Deelvenster met focus sluiten |
| <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Naar project 1–9 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Volgend / vorig project |
| <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Naar tabblad 1–9 |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Tabbladwisselaar, op recent gebruik |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Volgend / vorig tabblad |

## Deelvensters [#panes]

| Sneltoets | Actie |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Naar rechts splitsen |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Naar beneden splitsen |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+pijltoetsen | Deelvenster in die richting focussen |
| <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> | Deelvensterfocus doorlopen |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> | Deelvenster vergroten / herstellen |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+pijltoetsen | Grootte van deelvenster met focus wijzigen |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> | Deelvensters even groot maken |

Naar links en boven splitsen heeft geen standaardsneltoets. Gebruik het menu **Tabbladen**, het contextmenu van het deelvenster of het opdrachtenpalet.

## Panelen [#panels]

| Sneltoets | Actie |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>P</kbd> | Opdrachtenpalet |
| <kbd>Cmd</kbd>+<kbd>O</kbd> | Snel starten |
| <kbd>Cmd</kbd>+<kbd>B</kbd> | Linkerzijbalk tonen / verbergen |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | Rechterzijbalk tonen / verbergen |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Git-paneel |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Paneel Bestanden |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | Info-paneel |

## Browser en agents [#browser-and-agents]

| Sneltoets | Actie |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>L</kbd> | Adresbalk van de huidige browser focussen |
| <kbd>Cmd</kbd>+<kbd>R</kbd> | Huidige browserpagina herladen |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Naar de volgende agent die aandacht nodig heeft |

Nieuwe browsertabbladen en -deelvensters hebben geen standaardsneltoets. Gebruik het menu **Archief** of het opdrachtenpalet.

## Tekst en zoeken [#text-and-search]

| Sneltoets | Actie |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>F</kbd> | Zoeken in het deelvenster met focus |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> | Zoeken en vervangen in de editor |
| <kbd>Cmd</kbd>+<kbd>G</kbd> | Volgende zoeken |
| <kbd>Shift</kbd>+<kbd>Return</kbd> | Vorige zoeken vanuit de zoekbalk |
| <kbd>Cmd</kbd>+<kbd>E</kbd> | Selectie gebruiken om te zoeken |
| <kbd>Cmd</kbd>+<kbd>K</kbd> | Terminal wissen |
| <kbd>Cmd</kbd>+<kbd>S</kbd> | Geopend bestand opslaan |
| <kbd>Cmd</kbd>+<kbd>,</kbd> | Instellingen |

## Vorige zoeken [#find-previous]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> is de gebruikelijke macOS-sneltoets voor Vorige zoeken, maar toont of verbergt in Zshell het Git-paneel. Gebruik <kbd>Shift</kbd>+<kbd>Return</kbd> in de zoekbalk. Het menu-item onder **Wijzig → Zoek** werkt ook.
