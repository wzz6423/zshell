---

จำปุ่มลัดไม่ได้? <kbd>Cmd</kbd>+<kbd>P</kbd> เปิดจานคำสั่งและแสดงปุ่มลัดข้างทุกคำสั่ง

## เทอร์มินัลด่วนส่วนกลาง [#global-quick-terminal]

| ปุ่มลัด | การกระทำ |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>I</kbd> | แสดง / ปิดเทอร์มินัลด่วน |
| <kbd>Esc</kbd> | ปิดเทอร์มินัลด่วนและยุติ shell |

บันทึกปุ่มลัดอื่นใน **การตั้งค่า → เทอร์มินัล → เทอร์มินัลด่วน** เทอร์มินัลที่ไม่ปักหมุดปิดเมื่อเสียโฟกัสด้วย ดู[เทอร์มินัลด่วน](/th/docs/terminal#global-quick-terminal)

## โปรเจกต์และเซสชัน [#projects-and-sessions]

| ปุ่มลัด | การกระทำ |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>N</kbd> | โปรเจกต์ใหม่ |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | เซสชันใหม่ |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | หน้าต่างใหม่ |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | ปิดช่องที่มีโฟกัส |
| <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | ไปโปรเจกต์ 1–9 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | โปรเจกต์ถัดไป / ก่อนหน้า |
| <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | ไปแท็บ 1–9 |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | ตัวสลับแท็บเรียงตามการใช้ล่าสุด |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | แท็บถัดไป / ก่อนหน้า |

## ช่อง [#panes]

| ปุ่มลัด | การกระทำ |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | แบ่งไปขวา |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | แบ่งลงล่าง |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+ปุ่มลูกศร | โฟกัสช่องในทิศนั้น |
| <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> | วนโฟกัสช่อง |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> | เปิด/ปิดการขยายช่อง |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+ปุ่มลูกศร | ปรับขนาดช่องที่มีโฟกัส |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> | ทำช่องให้เท่ากัน |

การแบ่งซ้ายและบนไม่มีปุ่มลัดเริ่มต้น ใช้เมนู **แท็บ** เมนูคลิกขวาช่อง หรือจานคำสั่ง

## แผง [#panels]

| ปุ่มลัด | การกระทำ |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>P</kbd> | จานคำสั่ง |
| <kbd>Cmd</kbd>+<kbd>O</kbd> | เรียกใช้ด่วน |
| <kbd>Cmd</kbd>+<kbd>B</kbd> | เปิด/ปิดแถบด้านซ้าย |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | เปิด/ปิดแถบด้านขวา |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | แผง Git |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | แผงไฟล์ |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | แผงข้อมูล |

## เบราว์เซอร์และเอเจนต์ [#browser-and-agents]

| ปุ่มลัด | การกระทำ |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>L</kbd> | โฟกัสแถบที่อยู่เบราว์เซอร์ปัจจุบัน |
| <kbd>Cmd</kbd>+<kbd>R</kbd> | โหลดหน้าเบราว์เซอร์ปัจจุบันใหม่ |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | ไปเอเจนต์ถัดไปที่ต้องการความสนใจ |

แท็บและช่องเบราว์เซอร์ใหม่ไม่มีปุ่มลัดเริ่มต้น ใช้เมนู **ไฟล์** หรือจานคำสั่ง

## ข้อความและค้นหา [#text-and-search]

| ปุ่มลัด | การกระทำ |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>F</kbd> | ค้นหาในช่องที่มีโฟกัส |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> | ค้นหาและแทนที่ (ตัวแก้ไข) |
| <kbd>Cmd</kbd>+<kbd>G</kbd> | ค้นหาถัดไป |
| <kbd>Shift</kbd>+<kbd>Return</kbd> | ค้นหาก่อนหน้าจากในแถบค้นหา |
| <kbd>Cmd</kbd>+<kbd>E</kbd> | ใช้ข้อความที่เลือกค้นหา |
| <kbd>Cmd</kbd>+<kbd>K</kbd> | ล้างเทอร์มินัล |
| <kbd>Cmd</kbd>+<kbd>S</kbd> | บันทึกไฟล์ที่เปิด |
| <kbd>Cmd</kbd>+<kbd>,</kbd> | การตั้งค่า |

## ค้นหาก่อนหน้า [#find-previous]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> มักเป็นค้นหาก่อนหน้าบน macOS แต่ใน Zshell ใช้เปิด/ปิดแผง Git ให้ใช้ <kbd>Shift</kbd>+<kbd>Return</kbd> ในแถบค้นหาแทน หรือเมนู **แก้ไข → ค้นหา** ก็ได้
