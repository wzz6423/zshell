---
title: Raccourcis clavier
description: Tous les raccourcis par défaut de Zshell, classés par fonction.
---

Vous avez oublié un raccourci ? <kbd>Cmd</kbd>+<kbd>P</kbd> ouvre la palette et affiche le raccourci à côté de chaque commande.

## Terminal rapide global [#global-quick-terminal]

| Raccourci | Action |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>I</kbd> | Afficher ou fermer le terminal rapide |
| <kbd>Esc</kbd> | Fermer le terminal rapide et arrêter son shell |

Enregistrez un autre raccourci dans **Réglages → Terminal → Terminal rapide**. Un terminal non épinglé se ferme aussi lorsqu'il perd le focus. Consultez [Terminal rapide](/fr/docs/terminal#global-quick-terminal).

## Projets et sessions [#projects-and-sessions]

| Raccourci | Action |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>N</kbd> | Nouveau projet |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | Nouvelle session |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | Nouvelle fenêtre |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | Fermer le volet actif |
| <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Sélectionner le projet 1 à 9 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Projet suivant ou précédent |
| <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Sélectionner l'onglet 1 à 9 |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Sélecteur d'onglets classés par utilisation récente |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Onglet suivant ou précédent |

## Volets [#panes]

| Raccourci | Action |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Diviser vers la droite |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Diviser vers le bas |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+les flèches | Activer le volet dans cette direction |
| <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> | Passer d'un volet à l'autre |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> | Agrandir ou rétablir le volet |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+les flèches | Redimensionner le volet actif |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> | Égaliser les volets |

Les divisions vers la gauche et vers le haut n'ont pas de raccourci par défaut. Utilisez le menu **Onglets**, le menu contextuel du volet ou la palette de commandes.

## Panneaux [#panels]

| Raccourci | Action |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>P</kbd> | Palette de commandes |
| <kbd>Cmd</kbd>+<kbd>O</kbd> | Lancement rapide |
| <kbd>Cmd</kbd>+<kbd>B</kbd> | Afficher ou masquer la barre latérale gauche |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | Afficher ou masquer la barre latérale droite |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Panneau Git |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Panneau Fichiers |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | Panneau Informations |

## Navigateur et agents [#browser-and-agents]

| Raccourci | Action |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>L</kbd> | Activer la barre d'adresse du navigateur actuel |
| <kbd>Cmd</kbd>+<kbd>R</kbd> | Recharger la page du navigateur actuel |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Rejoindre le prochain agent nécessitant votre attention |

La création d'onglets ou de volets de navigateur n'a pas de raccourci par défaut ; utilisez le menu **Fichier** ou la palette de commandes.

## Texte et recherche [#text-and-search]

| Raccourci | Action |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>F</kbd> | Rechercher dans le volet actif |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> | Rechercher et remplacer dans l'éditeur |
| <kbd>Cmd</kbd>+<kbd>G</kbd> | Occurrence suivante |
| <kbd>Shift</kbd>+<kbd>Return</kbd> | Occurrence précédente, depuis la barre de recherche |
| <kbd>Cmd</kbd>+<kbd>E</kbd> | Rechercher le texte sélectionné |
| <kbd>Cmd</kbd>+<kbd>K</kbd> | Effacer le terminal |
| <kbd>Cmd</kbd>+<kbd>S</kbd> | Enregistrer le fichier ouvert |
| <kbd>Cmd</kbd>+<kbd>,</kbd> | Réglages |

## Occurrence précédente [#find-previous]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> est le raccourci habituel de macOS pour rechercher l'occurrence précédente, mais il ouvre ou ferme le panneau Git dans Zshell. Utilisez <kbd>Shift</kbd>+<kbd>Return</kbd> dans la barre de recherche, ou la commande correspondante dans **Édition → Rechercher**.
