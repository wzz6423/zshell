يفتح <span dir="ltr"><kbd>Cmd</kbd>+<kbd>O</kbd></span> **التشغيل السريع**، وهو قائمة قابلة للبحث تضم عناصر يفتح كل منها مشروعًا جديدًا مع جلسة طرفية. العنصر المحفوظ إما **أمر** تكتبه كثيرًا، مثل `npm run dev` أو `make watch`، أو **اتصال SSH**.

## التشغيل [#launching]

اكتب اسمًا أو أمرًا أو وجهة اتصال أو مجموعة لتصفية القائمة بمطابقة تقريبية. انقر صفًا، أو حدده بمفاتيح الأسهم واضغط <kbd>Return</kbd>. يعمل العنصر في مشروع جديد يحمل اسمه، مع جلسة طرفية ومجلد خاصين به.

عندما ينتهي الأمر أو يُغلق الاتصال، تعود اللوحة إلى موجه الصدفة المعتاد بدل أن تختفي. لا يمكن لأي شيء شغّلته أن يغلق نفسه بصمت.

يمكنك أيضًا تشغيل عنصر محفوظ باسمه من أي طرفية Zshell:

```bash
zshell "Entry name"
```

استخدم اسم العنصر كما هو تمامًا، وضعه بين علامتي اقتباس إذا احتوى على مسافات. يعرض التلميح أسفل التشغيل السريع هذه الصيغة. يفتح العنصر في مشروع جديد.

## إدارة العناصر [#managing-entries]

- <span dir="ltr"><kbd>Cmd</kbd>+<kbd>N</kbd></span> — عنصر جديد
- <span dir="ltr"><kbd>Cmd</kbd>+<kbd>E</kbd></span> — تعديل العنصر المحدد
- <span dir="ltr"><kbd>Cmd</kbd>+<kbd>Delete</kbd></span> — حذف العنصر المحدد

استخدم حقل **المجموعة** الاختياري لتنظيم العناصر في أقسام مسماة. يعمل زرا التعديل والحذف على العنصر دون تشغيله.

يمكن لعنصر الأمر تثبيت **مجلد عمل** يبدأ فيه دائمًا؛ وبدونه يستخدم المجلد الافتراضي للمشروع الجديد. يستقبل عنصر SSH المضيف واسم مستخدم ومنفذًا اختياريين وخيارات `ssh` إضافية حرة، مثل `-L 8080:localhost:80`.

## مكان حفظ العناصر [#where-entries-live]

تُحفظ العناصر في `~/.config/zshell/quick-launch.json` وتُشارك بين جميع النوافذ. إنها بيانات مستخدم عادية، ويمكنك تعديل الملف أو نسخه احتياطيًا بحرية.

<Callout type="info">
تُنفّذ الأوامر عبر صدفة تسجيل الدخول، لذا تتلقى بيئة ملفك الشخصي. وبعدها تبقى اللوحة جلسة عادية مع الأسماء المستعارة والموجه كما هما.
</Callout>
