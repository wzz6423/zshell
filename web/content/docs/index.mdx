## Workspace structure

| Object | Purpose |
| --- | --- |
| Project | A local directory or SSH connection, organized in sidebar groups |
| Session | A project tab that you can rename, color, pin, and group |
| Pane | A terminal, browser, editor, or diff within a tab; split panes to work side by side |

## License and privacy

Zshell is free, with public source under the PolyForm Noncommercial License 1.0.0, and requires no account or subscription.
The app has no telemetry or analytics. Updates, tool version checks, and configured agent usage services may access the network;
browser panes and command-line tools make their own requests. See the [FAQ](/en/docs/faq).
