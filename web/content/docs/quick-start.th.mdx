---
title: "เริ่มต้นอย่างรวดเร็ว"
description: "จากหน้าต่างว่างสู่โปรเจกต์ที่พร้อมทำงาน พร้อมสิ่งที่ควรเรียนรู้ก่อน"
---

<Steps>

<Step>

### เริ่มโปรเจกต์ [#start-a-project]

กด <kbd>Cmd</kbd>+<kbd>N</kbd> จะได้โปรเจกต์ใหม่ในแถบด้านข้างพร้อมหนึ่งเทอร์มินัล จากนั้นใช้ `cd` ไปยัง repository ที่ต้องการเหมือนในเทอร์มินัลทั่วไป ต้นไม้ไฟล์และแผง Git จะตามไปแล้วตั้งรากที่ราก repository

หากอยากเริ่มจากโฟลเดอร์ ให้คลิกขวาใน Finder แล้วเลือก **บริการ → โปรเจกต์ Zshell ใหม่ที่นี่**

มีหลาย repository ก็เพิ่มทั้งหมดได้ <kbd>Cmd</kbd>+<kbd>1</kbd> ถึง <kbd>Cmd</kbd>+<kbd>9</kbd> ข้ามไปยังโปรเจกต์โดยตรง แต่ละโปรเจกต์มีแท็บและเค้าโครงของตนเอง

</Step>

<Step>

### เพิ่มเซสชัน [#add-sessions]

<kbd>Cmd</kbd>+<kbd>T</kbd> เปิดเทอร์มินัลอีกอันในโปรเจกต์เดียวกัน เป็นแท็บใหม่ที่มีไดเรกทอรีทำงานและประวัติเอาต์พุตของตัวเอง เช่น แยกหนึ่งแท็บสำหรับเซิร์ฟเวอร์พัฒนา หนึ่งแท็บสำหรับทดสอบ และอีกแท็บสำหรับพิมพ์คำสั่ง

<kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> สลับแท็บโดยตรง ส่วน <kbd>Ctrl</kbd>+<kbd>Tab</kbd> เปิดตัวสลับเรียงตามการใช้งานล่าสุด

</Step>

<Step>

### แบ่งแท็บ [#split-a-tab]

<kbd>Cmd</kbd>+<kbd>D</kbd> แบ่งช่องปัจจุบันไปทางขวา และ <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> แบ่งลงล่าง ใช้ <kbd>Opt</kbd>+<kbd>Cmd</kbd>+ปุ่มลูกศรเพื่อย้ายระหว่างช่อง และ <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> เพื่อขยายช่องให้เต็มแท็บขณะอ่านเนื้อหายาว

</Step>

<Step>

### เปิดแผงด้านข้าง [#open-the-side-panels]

แถบด้านขวามีแผงต่อไปนี้ แต่ละแผงเปิดได้ด้วยปุ่มลัด:

| แผง | ปุ่มลัด | ใช้สำหรับ |
| --- | --- | --- |
| Git | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Stage ตรวจ diff, commit และ push |
| ไฟล์ | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | เรียกดูต้นไม้ เปิดและแก้ไขไฟล์ |
| ข้อมูล | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | โปรเซสและพอร์ตที่รับการเชื่อมต่อ |

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> ซ่อนแถบด้านขวาทั้งหมด ส่วน <kbd>Cmd</kbd>+<kbd>B</kbd> ซ่อนแถบโปรเจกต์ด้านซ้าย

</Step>

<Step>

### จำปุ่มลัดหนึ่งชุด: <kbd>Cmd</kbd>+<kbd>P</kbd> [#learn-one-shortcut-cmdp]

จานคำสั่งค้นหาทุกโปรเจกต์ ทุกเซสชันที่เปิด และทุกคำสั่งของ Zshell หากลืมอย่างอื่นในหน้านี้ ให้จำชุดนี้ไว้ แต่ละคำสั่งแสดงปุ่มลัดข้างชื่อด้วย

</Step>

</Steps>

## สิ่งที่กลับมาหลังออกจากแอป [#what-comes-back-after-you-quit]

เมื่อออกแล้วเปิดใหม่ โปรเจกต์ แท็บ และเค้าโครงช่องจะอยู่ที่เดิม แต่ละเทอร์มินัลเริ่ม **shell ใหม่** ในไดเรกทอรีเดิม ไม่มีอะไรแอบทำงานเบื้องหลัง

ประวัติเอาต์พุตต้องเปิดเอง เปิด [`terminal.restore-history`](/th/docs/configuration#terminalrestore-history) แล้วเทอร์มินัลที่เปิดใหม่จะแสดงเอาต์พุตเก่าด้านบนเส้น `Session Contents Restored` โดย shell ใหม่ทำงานด้านล่าง

<Callout type="info">
ข้อความที่กู้คืนเป็นเพียงข้อความ เป็นบันทึกสิ่งที่เกิดขึ้น ไม่ใช่เซสชันที่ยังทำงาน การเลื่อนอ่านจึงไม่รันคำสั่งซ้ำ
</Callout>
