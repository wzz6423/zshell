<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd>로 파일 트리를 엽니다. Git 패널처럼 [프로젝트 디렉터리](/ko/docs/projects#the-project-directory)를 기준으로 하므로 `cd`를 할 때마다 루트가 바뀌지는 않습니다.

## 파일 트리 [#the-tree]

파일 패널이 보이고 Zshell이 활성 상태이면 로컬 디렉터리가 백그라운드에서 갱신됩니다. SSH 프로젝트에서는 원격 루트와 펼친 폴더를 주기적으로 다시 읽습니다.

파일을 클릭하면 포커스된 분할 창에서 열립니다. 그 밖의 작업은 오른쪽 클릭 메뉴에 있습니다.

| 항목 | 동작 |
| --- | --- |
| **열기** / **옆에 열기** | 현재 창 또는 새 분할 창에서 열기 |
| **기본 앱에서 열기** | macOS가 해당 파일에 사용하는 앱으로 열기 |
| **Finder에서 보기** | |
| **경로 복사** | 절대 경로 복사 |
| **여기로 cd** | 포커스된 터미널에서 `cd <folder>` 실행 |
| **새 파일…** / **새 폴더…** | 선택한 폴더 안에 생성 |
| **이름 변경** | |
| **휴지통으로 이동** | 즉시 영구 삭제하지 않고 휴지통으로 이동 |

각 행은 파일 이름에 맞는 Material 아이콘을 사용합니다. Git 저장소 안에서는 변경된 경로에 상태 색상과 배지도 표시하고 무시된 파일은 흐리게 표시합니다. Git 패널을 열지 않아도 같은 작업 트리 상태를 확인할 수 있습니다.

## 원격 파일 [#remote-files]

파일 패널에서 SSH 파일을 열 수 있습니다. 생성, 이름 변경, 원격 휴지통으로 이동 또는 저장하려면 **설정 → 편집기 → 파일 → 원격 파일 변경 허용**을 켜세요(`files.remote-write-enabled`, 기본값 켜짐).

Zshell은 호스트에 이미 설치된 도구만 사용하며 추가로 설치하지 않습니다. 파일 읽기와 편집에는 기존 Perl 핵심 모듈을 사용합니다. 각 쓰기 작업은 필요한 파일 시스템 기능도 확인하며, 지원하지 않는 작업은 비활성화됩니다. 호스트는 파일 작업마다 프로젝트 루트와 상위 디렉터리의 디렉터리 심볼릭 링크를 한 번 해석하며, 프로젝트 내부의 심볼릭 링크, 특수 파일 및 프로젝트 밖 경로는 거부합니다. UTF-8 텍스트 파일은 최대 5 MiB이며 원격 Markdown은 소스로 열립니다.

로컬 저장 보호를 꺼도 원격 저장은 변경 사항을 확인합니다. 충돌 시 비교, 초안 유지, 원격에서 다시 불러오기 또는 덮어쓰기를 선택할 수 있습니다. 완성된 파일을 반영하기 직전에 비교한 버전을 다시 확인하지만, 외부 프로세스가 마지막 확인 후에 쓸 가능성은 남습니다.

**원격 휴지통으로 이동**은 내용과 원래 경로 정보를 프로젝트의 비공개 `.zshell-trash` 디렉터리에 보관합니다. **마지막 원격 항목 복원**은 현재 프로젝트를 선택한 동안 마지막 항목을 복원하며 같은 이름의 항목을 대체하지 않습니다. 이전 항목도 해당 디렉터리에서 수동으로 복구할 수 있습니다.

## 파일과 폴더 가져오기 [#import-files-and-folders]

**파일 → 파일 가져오기…**, 파일 패널의 가져오기 버튼 또는 폴더의 오른쪽 클릭 메뉴에서 **파일 가져오기…**를 선택하세요. 여러 파일과 폴더를 선택하면 원본을 유지하면서 선택한 폴더나 현재 트리 루트로 복사합니다.

Finder 항목을 폴더 또는 트리의 빈 영역으로 드롭하려면 **설정 → 편집기 → 파일 → 파일 트리로 드래그하여 가져오기**(`files.drag-import`)를 켜세요. 기본값은 켜짐이며 메뉴 가져오기는 계속 사용할 수 있습니다.

같은 이름이 있으면 **대치**, **건너뛰기**, **취소**를 선택할 수 있습니다. 폴더 대치는 폴더 전체를 바꾸며 내용을 병합하지 않습니다. 취소하면 전체 가져오기를 중단하고 이번에 추가한 사본을 되돌립니다. 복원 전에 다른 프로그램이 가져온 항목을 변경하면 해당 변경을 보존하고 복구 파일이 있을 수 있는 폴더를 표시합니다. SSH 트리는 로컬 가져오기를 받지 않습니다. 심볼릭 링크는 대상을 따라가지 않고 링크로 복사됩니다.

## 파일 찾기와 내용 검색 [#find-files-and-search-contents]

명령 팔레트(<kbd>Cmd</kbd>+<kbd>P</kbd>)는 현재 창에 열린 로컬 프로젝트 전체에서 파일 이름이나 경로를 검색하며 명령과 열린 세션도 함께 찾습니다. 파일을 선택하면 해당 프로젝트로 전환하여 엽니다.

파일 안의 텍스트를 찾으려면 파일 패널의 돋보기를 클릭하거나 명령 팔레트에서 **파일 내용 검색**을 선택하세요. 텍스트를 입력하고 <kbd>Return</kbd>을 누르면 현재 로컬 프로젝트 디렉터리를 검색합니다. **Aa**로 대소문자를 구분하고, 결과를 열면 편집기에서 일치하는 줄로 이동합니다.

내용 검색은 입력한 텍스트를 그대로 찾습니다. 바이너리 파일과 일반적인 의존성 및 빌드 폴더는 제외하며, 2,000개 일치 항목에서 검색을 멈춥니다. 검색 중에 중지해도 결과를 유지할 수 있으며 검색을 닫으면 파일 트리로 돌아갑니다. SSH 프로젝트는 이 로컬 파일 검색에서 제외됩니다.

## 편집기 [#the-editor]

파일을 열면 구문 강조를 지원하는 편집기가 분할 창에 표시됩니다.

로컬 PNG, JPEG, GIF, HEIC, WebP, TIFF, BMP 및 ICNS 이미지 미리보기는 64 MiB 이하의 일반 파일만 읽으며, 이를 초과하면 파일이 너무 크다는 메시지를 표시합니다.

| 작업 | 단축키 |
| --- | --- |
| 저장 | <kbd>Cmd</kbd>+<kbd>S</kbd> |
| 찾기 | <kbd>Cmd</kbd>+<kbd>F</kbd> |
| 찾기 및 바꾸기 | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> |
| 다음 찾기 | <kbd>Cmd</kbd>+<kbd>G</kbd> |

파일, 차이 보기, 프로젝트 또는 작업 공간 창을 닫거나 Zshell을 종료할 때 저장하지 않은 변경을 저장할지 묻습니다. **취소**하거나 저장에 실패하면 해당 작업 공간과 터미널이 열린 상태로 유지됩니다. 메뉴 막대 모드에서는 마지막 창을 닫아도 숨겨지기만 하며 변경은 유지됩니다. 앱을 종료할 때는 여전히 저장 여부를 묻습니다.

긴 줄은 기본적으로 분할 창 너비에 맞게 줄바꿈됩니다. 가로로 스크롤하려면 [`editor.wrap-lines`](/ko/docs/configuration#editorwrap-lines)를 끄세요.

트리에서 파일 이름을 바꾸면 그 파일을 연 모든 분할 창에도 반영됩니다. 이름을 바꾼 폴더 아래의 파일도 포함됩니다.

다른 프로그램이 열린 파일을 수정한 경우, 저장되지 않은 변경이 없는 미리보기는 앱이 다시 활성화될 때 갱신됩니다. 저장하지 않은 변경이 있는 편집기 버퍼를 덮어쓰지는 않습니다.

편집 중 외부 프로그램이 파일을 변경하면 저장 시 충돌 대화상자가 열립니다. **비교…**는 디스크 버전과 초안을 나란히 보여 줍니다. **초안 유지**는 저장을 취소하고, **디스크에서 다시 불러오기**는 초안을 버리며, **파일 덮어쓰기**는 비교한 버전을 교체합니다. 닫기 전 저장과 편집 가능한 diff에도 같은 검사가 적용됩니다. **설정 → 편집기 → 저장 충돌 방지** 또는 [`editor.protect-saves`](/ko/docs/configuration#editorprotect-saves)에서 제어하세요.

<Callout type="info">
이미 보고 있는 변경을 다루는 편집기입니다. 오타를 고치거나 상수를 조정하거나 차이 보기가 가리키는 파일을 읽을 수 있습니다. 언어 서버, 자동 완성이나 프로젝트 전체 리팩터링은 제공하지 않으며 의도적인 선택입니다.
</Callout>

## 저장하지 않은 초안 복구 [#recover-unsaved-drafts]

Zshell은 로컬 파일과 편집 가능한 작업 트리 diff의 저장하지 않은 변경을 기본으로 백업합니다. 예기치 않은 종료 후 다시 열린 창에서 초안, 선택 영역, 레이아웃을 복구합니다. 다른 백업은 **파일 → 초안 복구…** 또는 **설정 → 편집기 → 초안 복구…**에서 선택하고 내용을 확인한 뒤 **초안 복구**를 누르세요. 복구는 저장하지 않은 편집기를 열기만 하며 디스크 파일을 변경하지 않습니다. 저장할 때는 편집 전 버전을 기준으로 외부 변경을 확인합니다.

**설정 → 편집기 → 저장하지 않은 초안 백업** 또는 `editor.recover-drafts`로 제어합니다. 끄면 새 백업과 자동 복구가 중지되며 기존 백업은 수동 복구나 삭제할 수 있습니다. **백업 삭제**는 선택한 백업만 삭제하고 열린 편집 내용은 유지합니다. 저장 성공 또는 닫기 완료 시 **저장하지 않음**을 선택하면 백업이 삭제됩니다. 백업은 이 Mac의 비공개 파일에 최대 32개, 총 128 MiB로 저장되며 최대 30일 동안 보관됩니다. 용량 제한으로 오래된 백업이 더 일찍 삭제될 수 있습니다. 5 MiB를 넘는 파일이나 편집 텍스트는 제외됩니다.

Zshell은 시작 시와 실행 중 매시간 만료된 백업을 삭제하며, 백업을 꺼도 정리는 계속됩니다. Zshell이 종료된 동안 만료된 파일은 다음 실행 때 삭제될 때까지 디스크에 남습니다.

## Markdown 미리보기 [#markdown-preview]

`.md` 파일을 열면 같은 분할 창에 렌더링된 미리보기가 표시됩니다. 오른쪽 위 **편집**으로 원문을 수정하고 **미리보기**로 결과를 확인하세요. Zshell은 선호 모드를 기억하여 다른 Markdown 파일과 다음 실행에도 적용합니다.

모드를 바꿔도 편집 내용과 실행 취소 기록은 유지됩니다. 평소처럼 <kbd>Cmd</kbd>+<kbd>S</kbd>로 저장하세요. 다른 확장자의 Markdown 파일은 원문으로 열립니다.

## 차이 보기 [#diffs]

[Git 패널](/ko/docs/git)에서 연 차이 보기도 하나의 분할 창이므로 한 탭 안에 차이, 파일과 터미널을 나란히 둘 수 있습니다. 터미널 글꼴을 사용하며 천 개 파일의 변경도 한 줄 변경만큼 빠르게 열립니다. 현재 작업 트리의 스테이징되지 않은 차이 보기는 검토에서 편집으로 전환할 수 있습니다. 스테이징된 차이와 과거 커밋의 차이는 읽기 전용입니다. [차이 읽기](/ko/docs/git#reading-diffs)를 참고하세요.
