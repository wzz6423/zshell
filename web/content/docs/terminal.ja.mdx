title: ターミナル
description: Zshell のターミナルバックエンド、シェル環境、リンク、通知、安全機能。
---

各ターミナルペインは実際のログインシェルを実行し、GPU アクセラレーション対応の 2 つのネイティブバックエンドのいずれかを使います。
ペインのフォーカス、検索、通知、リンク、履歴、テーマ、貼り付けの安全性は Zshell が管理するため、どちらを選んでも一貫した動作になります。

## ターミナルバックエンド [#terminal-backends]

<strong>設定 → ターミナル → バックエンド（Backend）</strong>で選びます。

| バックエンド | 補足 |
| --- | --- |
| **Ghostty** | 標準設定 |
| **Alacritty** | 一般にメモリ使用量が少なめ |

両方とも GPU アクセラレーション、画像描画、Zshell 共通のテーマ一覧、検索、マウスレポート、通知、進捗報告に対応します。
変更は新しいターミナルにだけ適用され、既存ペインは起動時のエミュレータを使い続けます。

## シェルはそのまま [#your-shell-unchanged]

各セッションはアカウントのログインシェルを起動するため、プロンプト、エイリアス、関数、設定ファイルは通常のターミナルと同様に読み込まれます。
Zshell は機能と識別のため、次の変数を追加します。

| 変数 | 値 |
| --- | --- |
| `TERM_PROGRAM` | `ghostty` |
| `TERM_PROGRAM_VERSION` | Zshell が実装する Ghostty の互換機能バージョン |
| `ZSHELL_TERM` | 実際のペインのバックエンドである `ghostty` または `alacritty` |

画像や通知に対応した CLI が機能の手掛かりに使うため、両バックエンドとも `TERM_PROGRAM` では Ghostty を名乗ります。
描画エンジンを区別する必要がある場合だけ `ZSHELL_TERM` を使ってください。

<Callout type="info">
Zshell は `~/.config/ghostty` や Alacritty の設定を読み込みません。フォント、色、入力動作、バックエンドは Zshell 自身の[設定](/ja/docs/configuration)で管理します。
</Callout>

## 検索 [#search]

| 操作 | ショートカット |
| --- | --- |
| 検索 | <kbd>Cmd</kbd>+<kbd>F</kbd> |
| 次を検索 | <kbd>Cmd</kbd>+<kbd>G</kbd> |
| 前を検索 | 検索バー内で <kbd>Shift</kbd>+<kbd>Return</kbd> |
| 選択範囲を検索に使用 | <kbd>Cmd</kbd>+<kbd>E</kbd> |
| ターミナルをクリア | <kbd>Cmd</kbd>+<kbd>K</kbd> |

検索はフォーカス中のターミナルまたはエディタペインに対して行い、検索欄がキーボードフォーカスを持つ間は有効です。

## プロンプトの編集 [#prompt-editing]

アクティブなシェルプロンプト内をクリックして入力カーソルを移動し、そこから入力を続けられます。
zsh のプロンプトでは、入力部分をドラッグして範囲選択できます。入力で選択範囲を置き換え、Backspace または Delete で削除します。
ダブルクリック・トリプルクリックは引き続きターミナルのテキストを選択します。全画面 TUI などマウスレポートを有効にしたプログラムには、そのプログラム用のマウスイベントを送ります。

入れ子のシェルや置き換えられたシェルが Zshell のプロンプト編集機能を読み込んでいない場合、ドラッグはコピー用のテキスト選択になり、入力は編集しません。元のプロンプトに戻ると入力選択の編集も復帰します。

Claude Code の標準入力欄では、両バックエンドでクリックによる位置指定とドラッグ編集に対応します。折り返した入力や複数行の下書きも対象です。
入力・貼り付けで選択範囲を置き換え、Backspace または Delete で削除できます。
Vim のノーマル／ビジュアルモード、ダイアログ、添付や折りたたまれた貼り付けのプレースホルダー、スクロールした会話履歴は、従来のターミナル選択動作を維持します。マウスを捕捉するアプリは自分で入力を処理します。

Zisla の音声入力はターミナルの貼り付け操作を使います。Claude Code では選択中の入力範囲も置き換えます。意図して同じ言葉を繰り返す入力も対応しています。

## 前面アプリのショートカット [#foreground-application-shortcuts]

ターミナル内のアプリと Zshell のショートカットが競合する場合、ペインを右クリックし、<strong>Zshell コマンドをブロック（Block Zshell Commands）</strong>を有効にします。
そのペインにキーボードフォーカスがある間、<kbd>Ctrl</kbd>+<kbd>Return</kbd> などの修飾キー付き入力は前面のアプリへ渡します。コピー、貼り付け、すべて選択は引き続き使用できます。

設定はそのペインにだけ適用します。再び右クリックしてチェックを外すと、Zshell のショートカットに戻ります。
アプリがマウスを捕捉する場合は、<kbd>Shift</kbd> を押しながら右クリックして Zshell のメニューを開いてください。

## プロンプトキュー [#prompt-queue]

ターミナルにフォーカスして <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> を押すか、コマンドパレットの<strong>プロンプトキューを切り替え（Toggle Prompt Queue）</strong>を選びます。
そのターミナルの下にバーが開きます。項目を入力して <kbd>Return</kbd> または<strong>キューに追加（Add to Queue）</strong>を押します。各項目は 1 行で、貼り付けた改行は空白に置き換えます。

元の zsh が空のプロンプトに戻ると、Zshell は次の項目と Return を送信します。項目はキュー順に実行されます。
エージェントなど別の前面プログラムがターミナルを使っている間や、プロンプトに下書きがある間は自動送信を待ちます。
自動送信には Zshell の zsh 連携が必要です。ほかのシェルや入れ子のシェルでは手動送信を使えます。

各項目には<strong>今すぐ送信（Send Now）</strong>と<strong>削除（Remove）</strong>があります。
<strong>今すぐ送信</strong>は、プロンプトを待たず現在のターミナルプログラムへ即座にテキストと Return を送ります。
<kbd>Esc</kbd> または閉じるボタンでバーを隠しても、キューは残ります。キューはターミナルごとに独立し、セッションを閉じるか Zshell を終了すると破棄されます。

## パスと URL [#paths-and-urls]

Zshell は、ターミナルプログラムが出力した Web URL と既存のローカルパスを認識します。
ローカルリンクは絶対パス、`~/`、`./`、`../`、またはペインの現在の作業ディレクトリからの相対パスに対応します。`:42` や `:42:7` といった診断用の接尾辞があっても、元のファイルを見つけられます。

- ローカルパスを **Command クリック**すると Finder に表示し、URL ならデフォルトのブラウザで開きます。
- パスを <strong>Command 右クリック</strong>すると<strong>新規ファイルタブ／新規ファイルペイン（New File Tab / New File Pane）</strong>、URL なら<strong>新規ブラウザタブ／新規ブラウザペイン（New Browser Tab / New Browser Pane）</strong>を選べます。
- マウスレポートを有効にする全画面プログラムには、修飾なしの右クリックを渡します。**Shift** を押しながら右クリックすると Zshell のターミナル・ペインメニューを開きます。

コンパイラ出力やエージェントの会話から、同じプロジェクトへ直接戻れます。ブラウザの動作は[ブラウザペイン](/ja/docs/browser)を参照してください。

## 通知 [#notifications]

Zshell は次の 2 つのターミナルイベントを通知センターへ送ります。

- フォーカスされていないセッションからのベル
- 長時間のビルドやコーディングエージェントなどのプログラムからの `OSC 777;notify` 要求

通知ではシステムサウンドも再生できます。クリックすると Zshell がアクティブになり、通知を出したセッションへ直接移動します。
macOS が通知の許可を求めるのは Zshell 起動時ではなく、ターミナルが初めて通知しようとしたときです。

### コマンドの完了 [#command-completion]

<strong>設定 → ターミナル → コマンド通知（Command Notifications）</strong>で完了時の通知を設定できます。

- **長時間コマンド（Long-running commands）**：5、10、30、60 秒から選択します。その時間以上かかったコマンドの完了時に通知します。標準は**オフ**です。
- **失敗したコマンド（Failed commands）**：実行時間にかかわらず、終了ステータスが 0 以外なら通知します。こちらも標準ではオフで、独立して有効にできます。

設定は変更後に作成した zsh ターミナルに適用され、どちらのバックエンドでも使えます。
元のシェルの完了イベントを使うため、入れ子のシェルや対話プログラムの内部で実行したコマンドは、個別の完了をこの連携で報告しません。

同じ設定を `~/.config/zshell/config.toml` に保存できます。

```toml
terminal.notify-finish-seconds = 30
terminal.notify-on-error = true
```

実行時間による通知をオフにするには、`terminal.notify-finish-seconds` を `0` にします。通知の配信は macOS の通知設定に従います。

## 進捗報告 [#progress-reports]

`OSC 9;4` で進捗を送るプログラムには、ターミナル上部の細いバーで通常・一時停止・エラーの状態を区別して表示します。有効化の操作は不要です。プログラムが報告すればペインに表示されます。

## クリップボード、ドロップ、貼り付けの安全性 [#clipboard-drops-and-paste-safety]

- **クリップボードの読み取りは確認します。** SSH 越しのリモートホストも `OSC 52` で macOS のクリップボードを要求できます。Zshell は返す前に確認します。
- **危険な貼り付けには確認を出します。** 複数行やコマンドらしいテキストはすぐに送信せず、確認を挟みます。
- **ファイルはシェルで安全に使えるパスになります。** Finder からコピー・ドラッグしたファイルは、引用符付きの絶対パスとして挿入します。クリップボードの画像も画像対応 TUI に渡せます。

## Option キー入力 [#option-key-input]

標準では Option キーを現在の macOS 入力ソースに任せるため、Polish Pro などの配列で合成文字を入力できます。
ターミナルプログラムへ Meta ショートカットとして渡すには、設定の <strong>Option を Alt/Meta として使用（Use Option as Alt/Meta）</strong>を有効にします。
[`terminal.macos-option-as-alt`](/ja/docs/configuration#terminalmacos-option-as-alt)も参照してください。

## `zshell` コマンド [#the-zshell-command]

すべての Zshell ターミナルに、プロジェクトを認識する CLI が含まれます。

```sh
zshell                         # 現在のディレクトリにプロジェクトを作成
zshell vim ~/src/app.swift     # 作成し、最初のターミナルでこの argv を実行
zshell +themes                 # 対話的にテーマを閲覧・プレビュー
zshell +themes --list --dark   # ブラウザを使わずテーマ名を出力
zshell +help                   # すべてのコマンドグループを表示
```

テーマブラウザは選択ごとにアプリ全体をプレビューします。Return で保存し、Escape で以前のテーマに戻ります。

## フォント [#fonts]

JetBrains Mono と Nerd Font 記号を同梱しています。インストール済みの等幅フォントを欧文フォントとして選べるほか、CJK フォントを記号・システムの代替フォントより先に追加できます。
[`font-family`](/ja/docs/configuration#font-family)、[`terminal.font-fallback-family`](/ja/docs/configuration#terminalfont-fallback-family)、[`font-size`](/ja/docs/configuration#font-size)、[`terminal.font-thicken`](/ja/docs/configuration#terminalfont-thicken)、[`terminal.line-height`](/ja/docs/configuration#terminalline-height)を参照してください。

## グローバルクイックターミナル [#global-quick-terminal]

Zshell の実行中に <kbd>Cmd</kbd>+<kbd>I</kbd> を押すと、別のアプリの上に独立したターミナルを開き、もう一度押すと閉じます。
プロジェクトのタブとは別の一時的なシェルです。<strong>設定 → ターミナル → クイックターミナル（Quick Terminal）</strong>でサイズ、不透明度、ショートカットを変更できます。

- ウィンドウを固定すると、アプリを切り替えても開いたままにできます。
- 固定していないウィンドウはフォーカスを失うか、外側をクリックすると閉じます。
- **Zshell コマンドをブロック**がオフなら、<kbd>Esc</kbd> またはグローバルショートカットでウィンドウを閉じ、シェルと実行中の処理を終了します。再び開くと新しいセッションになります。

長時間稼働するサービスにはプロジェクトのターミナルを使ってください。コマンドを保存・起動する[クイック起動](/ja/docs/quick-launch)は別の機能です。

## Vim コマンドヒント [#vim-command-hints]

**設定 → ターミナル → 動作 → Vim コマンドヒント（Vim command hints）**を有効にし、右サイドバーの**情報**タブを開きます。
Vim、Vi、Neovim がアクティブな間、セッション情報の下に **VIM COMMANDS** セクションを表示します。標準ではオフで、両バックエンドの既存ターミナルにも即座に適用されます。

よく使うコマンドの全一覧は常に利用でき、変わるのは優先順位だけです。Normal では `:w`、`:q`、`yy`、`p`/`P`、Visual Block では `I`/`A`、矩形変更、角への移動が先に並びます。
Insert、Replace、Visual、Visual Line、Select、コマンドライン、検索の各モードにも独自の順序があります。各項目には適用モードを表示します。
キー、説明、モード名で検索でき、説明と検索 UI はアプリの 17 言語に対応します。検索を消すと全一覧に戻ります。
ヒントはリファレンスであり、エディタへ入力を送ることはありません。

ローカルのエディタはフォアグラウンドの実行ファイルで識別します。
SSH、Mosh、ターミナルマルチプレクサ内では、リモートプラグインを入れず、表示中の Vim モード／ステータス行と画面配置で判定します。
Vim の `showmode` または認識可能なステータス行を有効にしてください。
モード名を隠す・変える設定では Normal のヒントに戻ったり、リモート判定ができなくなったりします。独自のキーマッピングは解釈しません。
アクティブな情報パネルだけをサンプリングし、前面プログラムが変わるかエディタを認識できなくなるとヒントを隠します。

設定ファイルで `terminal.vim-command-hints = true` を指定しても有効にできます。
