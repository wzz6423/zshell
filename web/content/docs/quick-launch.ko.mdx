title: 빠른 실행
description: 자주 실행하는 명령과 SSH 연결을 저장하고 단축키로 빠르게 시작하세요.
---

<kbd>Cmd</kbd>+<kbd>O</kbd>로 **빠른 실행**을 엽니다. 검색 가능한 실행 항목 목록이며, 각 항목은 터미널 세션이 있는 새 프로젝트를 엽니다. 저장 항목은 `npm run dev` 또는 `make watch`처럼 자주 입력하는 **명령**이나 **SSH 연결**입니다.

## 실행 [#launching]

이름, 명령, 연결 대상 또는 그룹을 입력하여 목록을 유사 검색으로 필터링하세요. 행을 클릭하거나 방향키로 선택한 다음 <kbd>Return</kbd>을 누릅니다. 항목 이름을 사용하는 새 프로젝트가 열리고 독립적인 터미널 세션과 디렉터리에서 실행됩니다.

명령이 끝나거나 연결이 닫혀도 분할 창이 사라지지 않고 일반 셸 프롬프트로 돌아옵니다. 실행한 작업이 분할 창을 조용히 닫아 버리는 일은 없습니다.

어떤 Zshell 터미널에서든 저장된 항목을 이름으로 실행할 수도 있습니다.

```bash
zshell "Entry name"
```

항목 이름을 정확히 사용하고, 공백이 있으면 따옴표로 감싸세요. 빠른 실행 아래쪽에 이 구문이 안내되어 있습니다. 항목은 새 프로젝트에서 열립니다.

## 항목 관리 [#managing-entries]

- <kbd>Cmd</kbd>+<kbd>N</kbd> — 새 항목
- <kbd>Cmd</kbd>+<kbd>E</kbd> — 선택한 항목 편집
- <kbd>Cmd</kbd>+<kbd>Delete</kbd> — 선택한 항목 삭제

선택 사항인 **그룹** 입력란으로 항목을 이름 있는 구역으로 정리할 수 있습니다. 편집 및 삭제 버튼은 항목을 실행하지 않고 해당 항목에 작업을 적용합니다.

명령 항목에는 항상 시작할 **작업 디렉터리**를 고정할 수 있습니다. 지정하지 않으면 새 프로젝트의 기본 디렉터리를 사용합니다. SSH 항목에는 호스트, 선택적인 사용자와 포트, `-L 8080:localhost:80` 같은 추가 `ssh` 옵션을 자유롭게 입력할 수 있습니다.

## 항목 저장 위치 [#where-entries-live]

항목은 `~/.config/zshell/quick-launch.json`에 저장되며 모든 창에서 공유됩니다. 일반 사용자 데이터이므로 파일을 직접 편집하거나 자유롭게 백업할 수 있습니다.

<Callout type="info">
명령은 로그인 셸을 통해 실행하므로 프로필의 환경을 사용합니다. 실행 후에도 분할 창은 일반 세션으로 남으며 별칭과 프롬프트가 유지됩니다.
</Callout>
