---
title: 分割とペイン
description: タブを分割し、ペイン間の移動、サイズ変更、全体への拡大を行います。
---

どのタブもペインに分割できます。通常はターミナルを表示しますが、ファイル、差分、[ブラウザ](/ja/docs/browser)も表示できます。読む対象を、それを生んだシェルの隣に置くためです。

## 分割 [#splitting]

| 操作 | ショートカット |
| --- | --- |
| 右に分割 | <kbd>Cmd</kbd>+<kbd>D</kbd> |
| 下に分割 | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> |
| 左に分割 | — |
| 上に分割 | — |

左と上への分割には標準のショートカットがありません。<strong>タブ（Tabs）</strong>メニュー、コマンドパレット（<kbd>Cmd</kbd>+<kbd>P</kbd>）、ペインのコンテキストメニューから実行します。新しいペインはフォーカス中のペインの作業ディレクトリを引き継ぎます。

入れ子のレイアウトでも、常に**フォーカス中のペイン**を分割します。無関係な隣のペインのサイズは変えません。
各ペインのヘッダーには、内容に応じて更新される小さなタイトルと分割操作があり、そのペインの情報を確認できます。

開いているペインも並べ替えられます。上端の細い帯をつかみ、別のペインの端へドラッグしてください。離す前に、移動先のどちら側へ入るかが表示されます。

タブ全体をペインにすることもできます。上部のタブを現在のタブの内容の左・右・上・下の端へドラッグします。ドロップ前のプレビューで分割結果を確認できます。

## ペイン間の移動 [#moving-between-panes]

| 操作 | ショートカット |
| --- | --- |
| 左／右／上／下のペインにフォーカス | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+矢印キー |
| フォーカスを前／次へ移動 | <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> |

## 拡大とサイズ変更 [#zoom-and-resize]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> でフォーカス中のペインをタブ全体に拡大し、もう一度押すと元に戻します。
拡大中はタブヘッダーにボタンが表示されるため、ショートカットを使わなくても戻せます。

| 操作 | ショートカット |
| --- | --- |
| ペインの拡大を切り替える | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> |
| 指定方向へペインを広げる | <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+矢印キー |
| 全ペインを均等にする | <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> |

ペイン間の境界もドラッグできます。

## 閉じる [#closing]

<kbd>Cmd</kbd>+<kbd>W</kbd> でフォーカス中のペインを閉じます。タブ内の最後のペインを閉じると、タブも閉じます。

<Callout type="warn">
ターミナルペインを閉じると、そこで動くシェルと、そのシェルが起動した処理が終了します。ほかのターミナルを閉じる場合と同じく、Zshell は事前の確認をしません。
</Callout>
