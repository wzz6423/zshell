يحتفظ `zshell-server` بالصدفة ومهامها على جهاز macOS أو Linux. يدعم محركي الطرفية في Zshell. إغلاق العميل أو انقطاع الشبكة لا ينهي المهام، وتعيد إعادة الاتصال الشاشة وسجل التمرير والمؤشر وأوضاع الطرفية.

## التثبيت [#install]

في **المضيفون البعيدون…** اختر **تثبيت / تحديث الخادم** عبر SSH. يستخدم Mac ذو البنية المطابقة البرنامج المرفق. لـLinux اختر `zshell-server` المبني للمنصة والبنية. تُتحقق عملية النقل والتوافق قبل الاستبدال. تبقى الخدمة الحالية بإصدارها حتى إعادة التشغيل، التي تنهي مهامها. يمكنك أيضاً البناء على المضيف:

```sh
cargo build --locked --release --manifest-path remote/Cargo.toml
install -d "$HOME/.local/bin"
install -m 755 remote/target/release/zshell-server "$HOME/.local/bin/zshell-server"
```

يستطيع العميل استخدام صدفة وملفات حساب الخادم. يدعم macOS وLinux.

## SSH [#ssh]

تحقق أولاً من مفتاح المضيف والمصادقة بالمفتاح أو الوكيل:

```sh
ssh devbox true
```

افتح المضيفين البعيدين من قائمة الشبكة في الشريط الجانبي. أدخل اسماً و`ssh://me@devbox:22` أو اسم SSH مستعاراً و`~/.local/bin/zshell-server`. يجلب الاتصال المشاريع والجلسات الموجودة. أدخل مجلداً مثل `~/repo` وافتح المشروع البعيد لإنشاء صدفة. المسافات في المسارات مدعومة، وكذلك تعمل علامات التبويب والتقسيمات الجديدة على المضيف البعيد.

يبدأ SSH الخدمة تلقائياً ويستخدم إعدادات OpenSSH والمفاتيح والوكيل ومفاتيح المضيف الموثوقة. تظهر المفاتيح غير المعروفة وفشل المصادقة كأخطاء. تستخدم الملفات وGit اتصال SSH إلى المضيف نفسه حتى إن استخدمت الطرفية Tailscale. لا تصل المسارات البعيدة إلى ملفات Mac. يمكن لـ`ZSHELL_SSH_CONFIG_FILE` تحديد مسار مطلق لملف OpenSSH منفصل قابل للقراءة.

## Tailscale [#tailscale]

سجل الجهازين في Tailscale وابدأ المستمع الخاص قبل إنشاء الجلسات:

```sh
zshell-server serve --listen tailscale://:7373
```

أضف `tailscale://devbox:7373`. تُقبل MagicDNS وعناوين Tailscale من نوع IPv4 وIPv6 وتُرفض العناوين العامة. يسمح الإعداد الافتراضي بأجهزة مالك المضيف غير الموسومة فقط. يسمح `--allow-user` باسم دخول آخر مطابق تماماً، بينما تبقى الأجهزة الموسومة مرفوضة. استخدم SSH من جهاز الخادم نفسه. تُطبق أيضاً قواعد ACL للشبكة. يستطيع العميل المسموح تشغيل حساب Unix الخاص بالخدمة.

لمشاركة هذا Mac اتصل بـTailscale ثم اختر **مشاركة هذا Mac** في المضيفين البعيدين. حدد منفذاً وأسماء دخول دقيقة مسموحة إن أردت. تبدأ المشاركة بطلب صريح؛ **إيقاف المشاركة** أو الخروج من Zshell ينهي الجلسات المشتركة.

## المشاركة والإنهاء [#sharing]

يتلقى الجميع المخرجات نفسها. يمنح تركيز الطرفية أو استلام التحكم ذلك العميل حق الإدخال وتغيير الحجم. عند فصله يتولى أقدم عميل متبقٍ التحكم. تعرض لوحة المعلومات الحالة وعدد العملاء والتحكم وتتيح الفصل وإعادة الاتصال. تعاد محاولات الشبكة تلقائياً ويُهمل الإدخال أثناء الانقطاع. يعود التخطيط المحفوظ إلى UUID البعيد نفسه.

إغلاق جزء أو مشروع أو نافذة، وخيارا إنهاء التطبيق، يفصلان العميل فقط. يتطلب إنهاء الجلسة البعيدة تأكيداً ثم يوقف الصدفة ومهامها للجميع. على المضيف: `zshell-server terminate --project ~/repo --session UUID`.

عند استيقاظ Mac، تتحقق الجلسات البعيدة المشتركة من الاتصال وتعيد الاتصال بالمهمة البعيدة نفسها عند الحاجة. وتبقى الجلسات التي فصلتها يدوياً مفصولة.

## الملفات واللقطات [#paste]

انسخ ملفات عادية أو صورة والصق في الجزء البعيد، أو اسحب الملفات إليه. يرفعها Zshell إلى مجلد خاص على المضيف ثم يُدرج مسارات بعيدة مقتبسة للصدفة دون تنفيذ أمر. تتحول صور PNG وTIFF وJPEG وGIF وWebP إلى PNG؛ وتستخدم الصور المتحركة إطارها الأول. حتى 32 ملفاً و32 MiB لكل ملف و64 MiB إجمالاً؛ تُرفض المجلدات والروابط الرمزية. تبقى الرفعات المشتركة سبعة أيام. تدعم أجزاء Unix SSH العادية الرفع نفسه.

في **الإعدادات → الطرفية → الملفات البعيدة** يكون **رفع الملفات والصور المنسوخة** (`terminal.remote-paste-upload`) و**رفع الملفات المسحوبة** (`terminal.remote-drop-upload`) مفعّلين افتراضياً. أوقف أي خيار لإيقاف رفعه التلقائي؛ لن يُدرج مسار محلي. يظل **رفع ملفات…** في قائمة سياق الطرفية البعيدة متاحاً لاختيار الملفات صراحةً. أعد الاتصال وتسلم التحكم بالجلسة المشتركة قبل الرفع. مغادرة الجزء أو فقدان التحكم أو قطع الاتصال يلغي إدراج المسارات المنتظر.

## محادثات الوكيل البعيد [#agents]

تستخدم أنشطة الوكيل البعيد وتقدمه وطلبات الموافقة واكتماله الحالات والإشعارات الحالية. يتضمن **سجل محادثات الوكيل** محادثات Claude Code وCodex وOpenCode وPi على المضيف. الاستئناف يعيد الاتصال بالمحادثة الحية أو يبدأ جلستها الدقيقة على المضيف والمجلد الأصليين. يبقى سجل المحادثة بعد إعادة الخدمة؛ لا تبقى المهام وسجل الطرفية. يجب توفر المزود وإعداداته أو ملف الجلسة الأصلي.

## الحدود [#limits]

تستمر الجلسات ما دامت الخدمة حية، ولا تتجاوز إعادة تشغيل المضيف أو تعطل الخدمة أو إعادة تشغيلها. تظهر الجلسة المفقودة كخطأ ولا تُستبدل سراً بصدفة جديدة. الحدود هي 128 جلسة ولقطة طرفية 16 MiB وطابور مباشر 1 MiB لكل عميل. لا يمنع العميل البطيء الآخرين، ويظل السجل في ذاكرة المضيف. راجع [مرجع الخادم](https://github.com/wzz6423/zshell/tree/main/remote) للخدمات وCLI.

## الوصول عبر المتصفح [#browser-access]

استخدم **الإعدادات ← الوصول عبر المتصفح** للتحكم في لوحات الطرفية المحلية على هذا الـ Mac. الوصول متوقف افتراضيًا. بعد التفعيل، افتح لوحة جديدة واستخدم الصفحة المحلية أو اختر صراحة واجهة IPv4 خاصة على LAN/Tailscale ومنفذ HTTPS. تحتفظ اللوحات الحالية بعملياتها. تتصل الصفحة بلوحات Mac فقط؛ لا تنشئ shell ولا تتصل بمضيف بعيد.

تستخدم صفحة HTTP المحلية عادة منفذ HTTPS المحدد زائد واحد (`7444` افتراضياً). يحافظ السكون وإعادة المحاولة وإعادة الفتح على العنوان والتفويض ما دام توفر المنافذ لم يتغير. إذا كان المنفذ مشغولاً، يجرب Zshell المنافذ المحلية السبعة التالية؛ وبعد `65535` يبدأ من `1024`. إذا تغير توفر المنافذ، فقد تختار إعادة التشغيل عنواناً مختلفاً. يظل التفويض الحالي مرتبطاً بالأصل السابق، لذا يتطلب العنوان الجديد إقراناً جديداً. تبقى الأجهزة المحفوظة ظاهرة ويمكن إلغاء اعتمادها عند تعطيل الوصول. عند بلوغ 32 عميلاً، ألغِ اعتماد أحدها قبل الموافقة على آخر. إذا تعذر التحقق من خدمة الجلسات، يبقى الوصول مفعّلاً؛ انقر إعادة المحاولة عندما تصبح الخدمة جاهزة.

على جهاز آخر، صدّر شهادة TLS وقارن بصمتها بالإعدادات وثق بها قبل فتح عنوان HTTPS. أدخل اسم العميل واختر **طلب الاقتران**. خلال دقيقتين، قارن الرمز والعنوان والأصل على Mac ثم اختر **موافقة**. يستمر التصريح حتى 90 يومًا للعنوان والبروتوكول المحددين فقط. **سحب التصريح** أو **سحب تصريح جميع العملاء** يقطع الاتصال ويرفض بيانات الاعتماد فورًا.

اختر جلسة لرؤية الشاشة الحالية والمخرجات المباشرة، بما فيها ألوان ANSI وUnicode، والكتابة في العملية نفسها. يشترك Mac والمتصفح في الإدخال. يتحكم Mac بالحجم ما لم تحدد **ضبط حجم الطرفية حسب المتصفح**. يُهمل الإدخال أثناء انقطاع الاتصال، وتعيد إعادة الاتصال الجلسة الحية نفسها. يحتفظ تحديث الصفحة ببيانات اعتماد علامة التبويب؛ إغلاق علامة التبويب أو اختيار **نسيان هذا المتصفح** يزيلها. تغيّر العنوان يتطلب اقترانًا جديدًا.

تعطيل الوصول أو سكون Mac أو الخروج من Zshell يوقف الخدمة ويقطع العملاء. إغلاق لوحة ينهي عمليتها. الاحتفاظ بـ shell عند الخروج يظل تابعًا لـ `terminal.preserve-sessions`. أعد فتح Zshell للوصول إلى اللوحات الحية. إعادة تشغيل المضيف أو إيقاف الخدمة الخلفية ينهي shells. قوائم المخرجات محدودة، ويُقطع العملاء البطيئون دون تعطيل Mac. الصفحة مضمّنة في التطبيق ولا تتصل بـ CDN.

إذا كانت جلسات محفوظة من إصدار قديم ما زالت تعمل، يطلب الوصول عبر المتصفح الخروج وإنهاء جميع الجلسات ثم فتح Zshell مجددًا. تبقى المهام حتى تختار ذلك.
