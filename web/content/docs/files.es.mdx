Pulsa <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> para abrir el árbol de archivos. Al igual que el panel de Git, tiene su raíz en [el directorio del proyecto](/es/docs/projects#the-project-directory), por lo que no cambia de raíz cada vez que ejecutas `cd`.

## El árbol [#the-tree]

Con el panel de archivos visible y Zshell activo, los directorios locales se actualizan en segundo plano. En los proyectos SSH, Zshell vuelve a leer periódicamente la raíz remota y las carpetas expandidas.

Haz clic en un archivo para abrirlo en el panel con el foco. Haz clic derecho para acceder al resto de opciones:

| Opción | Qué hace |
| --- | --- |
| **Abrir** / **Abrir al lado** | Abre aquí o en una nueva división |
| **Abrir con la aplicación predeterminada** | Lo abre con la aplicación que macOS tenga asociada |
| **Mostrar en Finder** | |
| **Copiar ruta** | Copia la ruta absoluta |
| **cd aquí** | Ejecuta `cd <folder>` en el terminal con el foco |
| **Nuevo archivo…** / **Nueva carpeta…** | Crea un elemento dentro de la carpeta seleccionada |
| **Renombrar** | |
| **Mover a la papelera** | Lo envía a la papelera; no lo elimina definitivamente |

Las filas usan iconos de Material según el nombre del archivo. Dentro de un repositorio Git, las rutas modificadas también muestran colores e indicadores de estado, y los archivos ignorados aparecen atenuados. Así, el árbol muestra el mismo estado del árbol de trabajo que el panel de Git sin necesidad de abrirlo.

## Archivos remotos [#remote-files]

Abre archivos SSH desde el panel Archivos. Para crear, renombrar, mover a la papelera remota o guardar, activa **Ajustes → Editor → Archivos → Permitir cambios en archivos remotos** (`files.remote-write-enabled`, desactivado de forma predeterminada).

Zshell solo utiliza herramientas ya instaladas en el host y no instala nada. La lectura y edición utilizan sus módulos básicos de Perl existentes. Cada escritura también comprueba las funciones necesarias del sistema de archivos; las operaciones no compatibles siguen desactivadas. Se rechazan enlaces simbólicos, archivos especiales y rutas fuera del proyecto. Los textos UTF-8 pueden tener hasta 5 MiB; el Markdown remoto se abre como código fuente.

El guardado remoto comprueba los cambios aunque la protección local esté desactivada. Si hay un conflicto, puedes comparar, conservar el borrador, recargar desde el host o autorizar la sobrescritura. Se vuelve a comprobar la versión comparada justo antes de publicar el archivo completo; un proceso externo aún puede escribir después de esa última comprobación.

**Mover a la papelera remota** conserva el contenido y la ruta original en el directorio privado `.zshell-trash` del proyecto. **Restaurar el último elemento remoto** restaura el último elemento durante la selección actual del proyecto sin reemplazar nombres existentes. Los elementos anteriores siguen disponibles para recuperarlos manualmente desde ese directorio.

## Importar archivos y carpetas [#import-files-and-folders]

Elige **Archivo → Importar archivos…**, el botón de importación del panel Archivos o la opción del menú contextual de una carpeta. Selecciona varios archivos o carpetas; Zshell los copia a esa carpeta o a la raíz actual del árbol, conservando los originales.

Para soltar elementos de Finder sobre una carpeta o el espacio vacío del árbol, activa **Ajustes → Editor → Archivos → Importar al arrastrar al árbol de archivos** (`files.drag-import`). Está desactivado de forma predeterminada. El menú sigue disponible.

Si ya existe el nombre, puedes **Reemplazar**, **Omitir** o **Cancelar**. Se reemplaza la carpeta completa, sin combinar contenidos. Cancelar detiene toda la importación, elimina las copias añadidas y restaura los elementos reemplazados cuando es posible. Si otro programa modifica un elemento antes de restaurarlo, Zshell conserva el cambio e indica una carpeta que puede contener archivos de recuperación. Los árboles SSH no aceptan importaciones locales. Los enlaces simbólicos se copian como enlaces, sin seguir su destino.

## Buscar archivos y contenido [#find-files-and-search-contents]

La paleta de comandos (<kbd>Cmd</kbd>+<kbd>P</kbd>) busca archivos por nombre o ruta en los proyectos locales abiertos en la ventana actual, además de comandos y sesiones abiertas. Al seleccionar un archivo, cambia a su proyecto y lo abre allí.

Para buscar texto dentro de los archivos, haz clic en la lupa del panel Archivos o elige **Buscar en el contenido de archivos** en la paleta de comandos. Introduce texto y pulsa <kbd>Return</kbd> para buscar en el directorio del proyecto local actual. Usa **Aa** para distinguir mayúsculas y minúsculas, y abre un resultado para ir a la línea correspondiente en el editor.

La búsqueda de contenido encuentra texto literal, omite archivos binarios y las carpetas habituales de dependencias y compilación, y se detiene al llegar a 2000 coincidencias. Puedes detener una búsqueda en curso conservando sus resultados o cerrarla para volver al árbol de archivos. Los proyectos SSH quedan fuera de estas búsquedas locales.

## El editor [#the-editor]

Al abrir un archivo obtienes un editor real en un panel, con resaltado de sintaxis.

Las vistas previas locales de imágenes PNG, JPEG, GIF, HEIC, WebP, TIFF, BMP e ICNS aceptan archivos normales de hasta 64 MiB; los archivos más grandes muestran un mensaje que indica que el archivo es demasiado grande.

| Acción | Atajo |
| --- | --- |
| Guardar | <kbd>Cmd</kbd>+<kbd>S</kbd> |
| Buscar | <kbd>Cmd</kbd>+<kbd>F</kbd> |
| Buscar y reemplazar | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> |
| Buscar siguiente | <kbd>Cmd</kbd>+<kbd>G</kbd> |

Al cerrar un archivo, diff, proyecto o ventana de trabajo, o al salir de Zshell, se pregunta si quieres guardar los cambios pendientes. **Cancelar** o un fallo al guardar mantiene abiertos el espacio de trabajo y sus terminales. En el modo de barra de menús, cerrar la última ventana solo la oculta y conserva los cambios; al salir se sigue preguntando si quieres guardarlos.

Las líneas largas se ajustan al ancho del panel de forma predeterminada. Desactiva [`editor.wrap-lines`](/es/docs/configuration#editorwrap-lines) para desplazarte horizontalmente.

Renombrar un archivo en el árbol actualiza cualquier panel que lo tenga abierto, incluidos los archivos dentro de una carpeta renombrada.

Si otro programa modifica un archivo abierto, Zshell actualiza la vista sin cambios pendientes cuando la aplicación vuelve a estar activa. Nunca sustituye el contenido de un editor con cambios sin guardar.

Si otro programa cambia el archivo mientras lo edita, guardar abre un diálogo de conflicto. **Comparar…** muestra el disco y el borrador juntos; **Conservar borrador** cancela, **Recargar desde el disco** descarta el borrador y **Sobrescribir archivo** reemplaza la versión comparada. La comprobación también se aplica al guardar antes de cerrar y a los diffs editables. Contrólela en **Ajustes → Editor → Proteger contra conflictos al guardar** o [`editor.protect-saves`](/es/docs/configuration#editorprotect-saves).

<Callout type="info">
Este editor sirve para el cambio que ya estás revisando: corregir una errata, ajustar una constante o leer un archivo mencionado en las diferencias. No tiene servidor de lenguaje, autocompletado ni refactorización de todo el proyecto. Es una decisión deliberada.
</Callout>

## Recuperar borradores sin guardar [#recover-unsaved-drafts]

Zshell respalda por defecto los cambios sin guardar de archivos locales y diferencias editables del árbol de trabajo. Tras un cierre inesperado, los paneles reabiertos recuperan sus borradores, selecciones y distribución. Para otras copias, abre **Archivo → Recuperar borradores…** o **Ajustes → Editor → Recuperar borradores…**, elige una copia, revisa su contenido y pulsa **Restaurar borrador**. Restaurar abre un editor sin guardar y no modifica el archivo del disco. Al guardar se siguen comprobando los cambios externos con la versión anterior a tus ediciones.

Controla las copias en **Ajustes → Editor → Respaldar borradores sin guardar** o con `editor.recover-drafts`. Desactivarlo detiene las copias nuevas y la recuperación automática, pero conserva las copias existentes para recuperarlas o eliminarlas manualmente. **Eliminar copia** solo quita la copia seleccionada; las ediciones abiertas permanecen. Guardar correctamente o elegir **No guardar** al completar el cierre elimina la copia. Las copias son archivos privados en este Mac, con un máximo de 32 borradores y 128 MiB, recuperables hasta 30 días. Los límites de capacidad pueden eliminar las copias antiguas antes. Se excluyen archivos y textos editados de más de 5 MiB.

Zshell elimina las copias caducadas al iniciar y cada hora mientras se ejecuta, incluso con las copias desactivadas. Si Zshell está cerrado, los archivos caducados permanecen en el disco hasta el siguiente inicio.

## Vista previa de Markdown [#markdown-preview]

Abre un archivo `.md` para leer su vista previa renderizada en el mismo panel. Haz clic en **Editar**, en la esquina superior derecha, para trabajar con el código fuente y después en **Vista previa** para ver el resultado. Zshell recuerda el modo que prefieres para otros archivos Markdown y para el siguiente inicio.

Cambiar de modo conserva tus ediciones y el historial de deshacer. Guarda los cambios con <kbd>Cmd</kbd>+<kbd>S</kbd>, como siempre. Los archivos Markdown con otras extensiones se abren como código fuente.

## Diferencias [#diffs]

Una vista de diferencias abierta desde [el panel de Git](/es/docs/git) es otro panel más, por lo que puedes tener unas diferencias, un archivo y un terminal juntos en una pestaña. Utiliza la fuente del terminal, y un conjunto de cambios de mil archivos se abre tan rápido como uno de una línea. Las diferencias actuales y sin preparar del árbol de trabajo también permiten pasar de Revisar a Editar; las diferencias preparadas e históricas siguen siendo de solo lectura. Consulta [Leer diferencias](/es/docs/git#reading-diffs).
