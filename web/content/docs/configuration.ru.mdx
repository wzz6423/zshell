Большинство постоянных настроек Zshell хранится в одном файле:

```
~/.config/zshell/config.toml
```

Окно настроек (<kbd>Cmd</kbd>+<kbd>,</kbd>) записывает тот же файл. Некоторые параметры macOS — язык и автоматические обновления — хранятся отдельно и перечислены в конце страницы.

## Как работает файл [#how-the-file-behaves]

Перед ручным редактированием полезно знать:

- **Файл читается при запуске.** Изменение файла при работающем Zshell не действует до перезапуска. Изменения в окне настроек применяются сразу, если элемент управления не указывает иное.
- **Zshell перезаписывает файл при каждом изменении хранящегося в нём параметра.** Файл создаётся заново, поэтому комментарии и неизвестные ключи будут потеряны при следующем использовании такого элемента управления. Выберите один способ редактирования или храните основную копию в своих dotfiles.
- **Записываются только значения, отличающиеся от стандартных, с одним исключением.** `font-size` присутствует всегда. Удаление любого другого ключа восстанавливает стандартное значение.
- **Парсер намеренно ограничен.** Он поддерживает простые и разделённые точками ключи, заголовки `[table]`, комментарии `#`, строки, числа и логические значения. Массивы, встроенные таблицы и многострочные строки не поддерживаются.
- **Неверные значения безопасно заменяются стандартными.** Размер вне диапазона, неизвестный движок или ошибка в имени темы не мешают запуску Zshell.

## Оформление [#appearance]

### `theme` [#theme]

`"system"` · `"light"` · `"dark"` — по умолчанию `"system"`

Выбирает оформление приложения. `"system"` следует macOS, два других значения фиксируют светлое или тёмное оформление.

### `theme-dark` и `theme-light` [#theme-dark-and-theme-light]

Строки — по умолчанию `"Default Dark"` и `"Default Light"`

Цветовая тема для каждого оформления. Тема одновременно меняет цвета терминалов, элементов окна, боковых панелей, редактора и сравнений. Стандартные темы сохраняют полупрозрачную боковую панель; другие окрашивают её в соответствии со своей палитрой.

В настройках доступен подобранный каталог тем, общий для обоих движков. Введённое вручную имя должно точно совпадать с отображаемым именем, включая регистр, иначе используется соответствующая стандартная тема.

### `toolbar.visibility` [#toolbarvisibility]

`"hide"` · `"auto"` · `"always"` — по умолчанию `"hide"`

Управляет компактной панелью инструментов под активной вкладкой:

- `"hide"` полностью скрывает её.
- `"auto"` показывает её только тогда, когда каталог проекта — репозиторий Git.
- `"always"` оставляет доступ к Git во всех проектах, включая состояние **Нет репозитория Git**.

Содержимое описано в разделе [Панель инструментов Git](/ru/docs/git#the-git-toolbar).

## Текст [#text]

### `font-family` [#font-family]

Строка — по умолчанию `""`, то есть встроенный JetBrains Mono

Это семейство для латиницы используется терминалом, редактором и просмотрщиком сравнений. Указывайте семейство, а не начертание: `"IBM Plex Mono"`, а не `"IBM Plex Mono Regular"`. Неизвестные или немоноширинные семейства заменяются встроенным шрифтом.

Порядок подстановки в терминале: семейство латиницы, необязательное семейство CJK ниже, встроенный Symbols Nerd Font, затем системная подстановка движка. Редактор и сравнения продолжают использовать обычную подстановку macOS/WebKit.

### `terminal.font-fallback-family` [#terminalfont-fallback-family]

Строка — по умолчанию `""`, то есть подстановка движка/системы

Добавляет одно установленное семейство CJK в цепочку подстановки терминала. Список настроек включает семейства с характерными китайскими, японскими или корейскими символами; строгая моноширинность не требуется, поскольку они предоставляют только символы, отсутствующие в основном латинском шрифте.

### `font-size` [#font-size]

Число, 8–32 — по умолчанию `13`

Общий размер шрифта терминала, редактора и сравнений в пунктах. Это единственный ключ, который Zshell записывает даже при стандартном значении.

### `interface.scale` [#interfacescale]

Число, 0.9–1.5 — по умолчанию `1`

Масштабирует вкладки, значки, кнопки, боковые панели и остальной интерфейс. Содержимое терминала, редактора и сравнений сохраняет отдельно настроенный выше размер шрифта.

### `sidebar.font-size` [#sidebarfont-size]

Число, 9–24 — по умолчанию `14`

Базовый размер текста обеих боковых панелей. Заголовки разделов, строки, метаданные и элементы управления сохраняют относительную иерархию при изменении базы.

### `terminal.font-thicken` [#terminalfont-thicken]

Логическое значение — по умолчанию `false`

Немного утолщает штрихи символов терминала, подобно классическому сглаживанию macOS. Поддерживается обоими движками; результат виден в предпросмотре настроек. Старый ключ `font-thicken` по-прежнему читается, а затем перезаписывается современным ключом с точкой.

### `terminal.font-thicken-strength` [#terminalfont-thicken-strength]

Целое число, 0–255 — по умолчанию `255`

Регулирует утолщение, когда `terminal.font-thicken` равно true. Ноль означает минимальное утолщение, а не отключение. Ghostty использует нативную интенсивность macOS, Alacritty сопоставляет тот же диапазон обводке CoreText. Направление и крайние значения совпадают, но растровые пиксели могут различаться.

### `terminal.line-height` [#terminalline-height]

Число, 0.75–2 — по умолчанию `1`

Умножает естественную высоту ячейки каждого движка, сохраняя символы по вертикальному центру. Меняет только строки терминала, не интервалы редактора и сравнений.

Zshell не предоставляет отдельную настройку базовой насыщенности шрифта. Ghostty выбирает именованные начертания или оси вариаций, а Alacritty/CoreText определяет обычное и жирное начертания по признакам. Одно общее значение не обеспечило бы одинакового различия обычного/жирного начертания и насыщенности подстановочных шрифтов для статических и вариативных семейств.

### `editor.wrap-lines` [#editorwrap-lines]

Логическое значение — по умолчанию `true`

Переносит длинные строки по ширине панели в [редакторе файлов](/ru/docs/files). При false длинные строки прокручиваются горизонтально. Перенос в терминале и сравнениях не меняется.

## Терминал [#terminal]

### `terminal.startup-program` / `terminal.startup-arguments` [#terminalstartup-program--terminalstartup-arguments]

Строки — по умолчанию не заданы

Выбирают исполняемый файл и вектор аргументов для создаваемых после изменения терминалов. Без `terminal.startup-program` Zshell использует оболочку входа учётной записи с `-l`. Программа должна быть исполняемым файлом по абсолютному пути. Если путь отсутствует или не исполняемый, запускается оболочка входа, чтобы не создавать неработающую панель.

`terminal.startup-arguments` разбивается на аргументы без вызова оболочки. Кавычки и обратные косые черты сохраняют границы, включая пробелы и пустые аргументы, но переменные, шаблоны и подстановки команд не раскрываются. Неверные кавычки также возвращают оболочку входа. Явный argv из CLI Zshell имеет приоритет для соответствующего терминала.

### `terminal.backend` [#terminalbackend]

`"libghostty"` · `"alacritty"` — по умолчанию `"libghostty"`

Выбирает эмулятор для новых терминалов. Существующие панели сохраняют исходный движок. Оба варианта нативные, ускоряются GPU, поддерживают изображения и одни и те же темы Zshell; Alacritty обычно расходует меньше памяти.

Переменные окружения и совместимость описаны в разделе [Движки терминала](/ru/docs/terminal#terminal-backends).

### `terminal.macos-option-as-alt` [#terminalmacos-option-as-alt]

Логическое значение — по умолчанию `false`

При true сочетания с Option передаются терминальным программам как Alt/Meta. По умолчанию Option остаётся у активного источника ввода macOS, чтобы раскладки вроде Polish Pro могли вводить составные символы.

### `terminal.bell` [#terminalbell]

Логическое значение — по умолчанию `true`

Управляет звуком и визуальным привлечением внимания macOS при сигнале терминальной программы. При false Zshell не воспроизводит звук, не отправляет уведомление о звонке и не запрашивает внимание в Dock. Вспомогательные технологии всё равно получают семантическое объявление сигнала. Настройка действует в обоих движках.

### `terminal.vim-command-hints` [#terminalvim-command-hints]

Логическое значение — по умолчанию `false`

Показывает команды Vim / Neovim с учётом режима под информацией о сеансе на панели **Информация**. Применяется сразу в обоих движках, включая распознаваемые редакторы через SSH. Требования распознавания режима приведены в разделе [Подсказки команд Vim](/ru/docs/terminal#vim-command-hints).

### `terminal.restore-history` [#terminalrestore-history]

Логическое значение — по умолчанию `false`

После перезапуска восстанавливает предыдущий вывод терминала над новой оболочкой. Восстановленное содержимое — статический текст, а не продолжающий работу процесс.

История сохраняется на диске и может содержать показанные в терминале секреты. Поэтому настройка выключена по умолчанию. [Проекты, вкладки и расположение панелей](/ru/docs/projects#what-survives-a-relaunch) восстанавливаются в любом случае.

## Автоматизация [#automation]

### `ai.enabled` [#aienabled]

Логическое значение — по умолчанию `true`

Позволяет поддерживаемым агентам программирования координировать фоновые панели Zshell по вашему запросу обычными словами и показывает сообщённое провайдером состояние жизненного цикла. Zshell не определяет состояние по тексту терминала. Лучше менять параметр переключателем настроек: ошибки показываются рядом, а конфликтующая существующая настройка не изменяется.

Пользовательский процесс описан в разделе [Работа с ИИ-агентами](/ru/docs/automation).

## Резервное копирование и перенос [#backup-and-migration]

Выберите **Zshell → Экспортировать настройки…**, чтобы сохранить TOML, и **Импортировать настройки…**, чтобы загрузить его. Импорт запрашивает подтверждение замены и пытается сохранить текущий файл как `config.toml.bak` в том же каталоге.

Пока импорт восстанавливает только часть параметров: темы, основные настройки шрифта, курсор, движок терминала, восстановление истории, копирование выделения, быстрый терминал и поддержку ИИ. Не все экспортируемые настройки проходят полный цикл. После импорта проверьте масштаб интерфейса, значок приложения, внешний редактор и фон терминала. Для полного переноса закройте Zshell, сделайте резервную копию и скопируйте `config.toml`, затем запустите приложение. Переключатель ИИ меняется только при явном наличии `ai.enabled` в импортируемом файле; проверьте его после импорта. Переменные окружения проектов и вкладок относятся к данным сеансов и не включаются в этот файл.

## Полный пример [#a-complete-example]

```toml title="~/.config/zshell/config.toml"
theme = "dark"
theme-dark = "Catppuccin Mocha"
theme-light = "Catppuccin Latte"
font-family = "IBM Plex Mono"
font-size = 14
interface.scale = 1.25
sidebar.font-size = 13
toolbar.visibility = "auto"
terminal.font-fallback-family = "PingFang SC"
terminal.font-thicken = true
terminal.font-thicken-strength = 180
terminal.line-height = 1.15
terminal.macos-option-as-alt = false
terminal.bell = false
terminal.startup-program = "/opt/homebrew/bin/fish"
terminal.startup-arguments = "--no-config"
terminal.backend = "alacritty"
terminal.restore-history = true
editor.wrap-lines = true
ai.enabled = true
```

Все ключи необязательны. Удалите ключ, чтобы вернуть его стандартное значение.

## Сочетания клавиш [#keyboard-shortcuts]

В **Настройки → Сочетания клавиш** можно записать новое сочетание основной команды. Zshell отклоняет конфликты и показывает команду, уже использующую сочетание. **Восстановить стандартные сочетания** сбрасывает все переопределения. Стандартные значения перечислены в [справочнике клавиатуры](/ru/docs/shortcuts).

## Настройки вне этого файла [#settings-outside-this-file]

- **Язык.** В настройках доступны системный язык и 17 языков сайта. Изменение применяется немедленно, терминальные сеансы продолжают работать. Выбор использует языковую настройку macOS для приложения и хранится в предпочтениях Zshell, не в TOML. Системное значение следует порядку языков macOS.
- **Автоматические обновления.** Переключатели автоматической проверки, загрузки и установки в **Настройки → Обновления** хранятся вне TOML и сохраняются между запусками. Установка показывается только при включённой автоматической загрузке. См. [Установка](/ru/docs/installation#updates).
- **Состояние окна и расположения.** Размер окна, ширина боковых панелей, выбранные панели, проекты, вкладки, панели содержимого, URL браузеров и предпочтения сравнений хранятся в предпочтениях macOS и снимке сеанса Zshell.
- **Файлы движков.** Zshell не читает `~/.config/ghostty` или настройки Alacritty. Для обоих поддерживается настройка через Zshell.
