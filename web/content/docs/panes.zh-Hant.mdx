---
title: 分割畫面與窗格
description: 把分頁切成多個窗格，在它們之間移動、調整大小，或把一個放大到全螢幕。
---

任何分頁都能分割畫面。窗格裡通常是終端機，也可以是檔案、diff 或[瀏覽器](/zh-Hant/docs/browser)——
這正是重點：正在讀的東西就擺在產生它的那個 shell 旁邊。

## 分割畫面 [#splitting]

| 操作 | 快速鍵 |
| --- | --- |
| 向右分割畫面 | <kbd>Cmd</kbd>+<kbd>D</kbd> |
| 向下分割畫面 | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> |
| 向左分割畫面 | — |
| 向上分割畫面 | — |

向左和向上分割畫面沒有預設快速鍵；從 **Tabs** 選單、指令面板（<kbd>Cmd</kbd>+<kbd>P</kbd>）或窗格自己的快速選單裡執行。新窗格會繼承當前窗格的工作目錄。

分割畫面永遠只切開**當前聚焦的窗格**，嵌套佈局裡也一樣，不會改變無關鄰居的尺寸。每個窗格頭部都有一條小標題和本地分割畫面控件，終端機實時標題也會顯示在那裡。

已經打開的窗格也可以重排：抓住窗格頂部那條細條，拖到另一個窗格的邊緣。鬆手之前，目標窗格會先顯示它將落在哪一半。

整個分頁也能變成窗格。把頂部標籤拖到當前分頁內容的左、右、上或下邊緣，鬆手前會先看到最終分割畫面的預覽。

## 在窗格之間移動 [#moving-between-panes]

| 操作 | 快速鍵 |
| --- | --- |
| 聚焦左 / 右 / 上 / 下方的窗格 | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+方向鍵 |
| 向前 / 向後循環切換焦點 | <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> |

## 放大與調整大小 [#zoom-and-resize]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> 把當前窗格放大到鋪滿分頁，再按一次還原。有窗格處於放大狀態時，分頁頭部會出現一個按鈕，所以你總有一條不靠快速鍵的退路。

| 操作 | 快速鍵 |
| --- | --- |
| 切換窗格放大 | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> |
| 朝某個方向放大窗格 | <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+方向鍵 |
| 讓所有窗格等分 | <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> |

窗格之間的分隔條也可以直接拖。

## 關閉 [#closing]

<kbd>Cmd</kbd>+<kbd>W</kbd> 關閉當前窗格。關掉分頁裡最後一個窗格，分頁也一起關掉。

<Callout type="warn">
關閉一個終端機窗格會終止裡面的 shell，以及它啟動的所有東西。Zshell 不會先問一句——這和在別處關掉一個終端機是一回事。
</Callout>
