Zshell은 Apple의 공증을 받지 않았습니다. 현재 릴리스에 필요한 최소 macOS 버전은 [홈페이지](/ko)의 다운로드 옆에 표시됩니다.

## 다운로드 [#download]

[홈페이지](/ko)에서 `.dmg`를 다운로드하세요. 현재 0.1.8 릴리스는 Universal, Apple Silicon 및 Intel 패키지를 제공하며 Gitee 미러도 이용할 수 있습니다. 디스크 이미지를 열고 **Zshell**을 응용 프로그램 폴더로 드래그하세요.

처음 실행할 때 macOS가 앱을 차단할 수 있습니다. 한 번 실행을 시도한 다음 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**로 이동하여 Zshell 열기를 확인하세요. Homebrew로 설치한 경우에도 같은 절차가 적용됩니다.

## Homebrew [#homebrew]

```bash
brew install wzz6423/tap/zshell
```

cask는 `wzz6423/homebrew-tap`에서 제공하며 Mac의 프로세서에 맞는 ZIP을 설치합니다. 설치 후에는 Sparkle로 업데이트합니다. Homebrew로 직접 업데이트하거나 설치된 버전이 오래되었을 때는 다음 명령을 사용하세요.

```bash
brew upgrade --cask --greedy-auto-updates zshell
```

## 업데이트 [#updates]

직접 다운로드와 Homebrew 설치 모두 [Sparkle](https://sparkle-project.org)을 사용합니다. 중국 본토에서는 Gitee를 먼저, 그다음 GitHub를 시도하며, 다른 지역에서는 순서가 반대입니다. 네트워크 IP의 국가 정보를 사용할 수 있으면 이를 따르고, 조회에 실패하면 macOS 지역 설정을 사용합니다. 피드나 다운로드가 실패하면 다른 소스로 한 번 다시 시도합니다. 국가 조회에는 [ipinfo.io/country](https://ipinfo.io/country)를 사용하며 시간 제한은 5초, 메모리 캐시 유지 시간은 30분입니다. 이 요청으로 네트워크의 공인 IP가 해당 서비스에 전달되지만 Zshell은 IP를 저장하지 않습니다. 자동 확인을 끄면 백그라운드 국가 조회도 중지됩니다.

Zshell은 설치 전에 서명된 피드와 업데이트 패키지를 검증하고 설치된 아키텍처를 유지합니다. 단, Rosetta로 실행 중인 Intel 앱은 Apple Silicon 버전으로 전환됩니다.

<strong>설정 → 업데이트</strong>(<kbd>Cmd</kbd>+<kbd>,</kbd>)에서 자동 확인과 <strong>자동으로 업데이트 다운로드</strong>를 설정하세요. 다운로드는 기본적으로 꺼져 있으며 자동 확인이 켜져 있어야 합니다. 다운로드를 켜면 별도의 <strong>자동으로 업데이트 설치</strong> 스위치가 나타나며 이 역시 기본적으로 꺼져 있습니다. 자동 설치가 꺼져 있으면 백그라운드에서 다운로드한 업데이트를 Zshell 종료 시 설치합니다. 두 스위치를 모두 켜면 준비된 업데이트를 자동으로 설치하고 Zshell을 다시 실행합니다. 재시작 중에는 실행 중인 터미널 프로세스가 종료되며 앱이 다시 열리면 작업 공간이 복원됩니다. 다운로드를 끄면 설치 스위치를 숨기고 자동 재시작을 막지만, 다음에 다운로드를 켤 때 사용할 설치 설정은 기억합니다. 두 설정 모두 앱 재시작 후에도 유지됩니다. 업데이트가 있으면 프로젝트 사이드바 아래쪽의 피드백 버튼 왼편에 업데이트 아이콘이 표시됩니다. 클릭하면 업데이트나 진행 상태를 보거나 대기 중인 재시작을 다시 시도할 수 있습니다. 수동으로 확인하려면 <strong>업데이트 확인…</strong>을 선택하세요. 위의 Homebrew 명령으로 직접 업데이트할 수도 있습니다.

## 추천 도구 [#recommended-tools]

**설정 → 추천**에서 Zisla를 비롯한 터미널, 네트워크, 개발, 유틸리티 및 데스크톱 도구를 살펴보세요. 페이지가 열려 있는 동안 설치된 도구와 사용 가능한 업데이트를 확인합니다. 각 도구의 **설치** 또는 **업데이트** 버튼을 사용하거나, **누락된 도구 설치**로 설치되지 않은 모든 추천 도구를 설치하거나, **모두 업데이트**로 Homebrew에서 관리하는 도구를 업데이트할 수 있습니다.

도구는 Homebrew로 설치합니다. Homebrew가 없으면 페이지에 설치 안내 링크가 표시됩니다. 확인 작업 자체가 도구를 설치하거나 업데이트하지는 않습니다. Homebrew 외부에서 감지된 도구에는 **Homebrew 외부** 표시가 붙습니다. **Homebrew 사용**을 선택하면 Homebrew가 관리하는 복사본을 설치하지만 기존 복사본이 셸의 `PATH`에서 우선할 수 있습니다. 설치를 변경한 뒤 **새로 고침**으로 다시 확인하세요. Zshell 자체는 **설정 → 업데이트**에서 관리합니다.

## Finder에서 폴더 열기 [#open-a-folder-from-finder]

Zshell은 **여기에 새 Zshell 프로젝트**라는 macOS 서비스를 등록합니다. Finder에서 폴더를 하나 이상 선택하고 오른쪽 클릭한 다음 **서비스** 하위 메뉴에서 선택하세요. 각 폴더가 프로젝트로 열리며 해당 위치에서 터미널이 바로 시작됩니다.

메뉴에 없다면 **시스템 설정 → 키보드 → 키보드 단축키 → 서비스 → 파일 및 폴더**에서 켜세요. macOS는 앱을 한 번 실행한 뒤에 새 서비스를 표시합니다.

## 삭제 [#uninstalling]

**설정 → 자동화 → AI**가 켜져 있다면 앱을 삭제하기 전에 끄세요. 그러면 Zshell이 설치한 에이전트 지원 기능을 제거할 수 있습니다.

응용 프로그램 폴더에서 `zshell.app`을 삭제하세요. 설정도 완전히 지우려면 다음 명령을 실행합니다.

```bash
rm -rf ~/.config/zshell
```

창 배치, 사이드바 너비와 세션 스냅샷은 macOS의 환경설정 저장소에 보관됩니다.

```bash
defaults delete sh.zshell
```
