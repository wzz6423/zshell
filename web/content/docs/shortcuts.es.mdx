---
title: Atajos de teclado
description: Todos los atajos predeterminados de Zshell, agrupados por función.
---

¿Has olvidado alguno? <kbd>Cmd</kbd>+<kbd>P</kbd> abre la paleta de comandos y muestra el atajo junto a cada comando.

## Terminal rápido global [#global-quick-terminal]

| Atajo | Acción |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>I</kbd> | Mostrar / cerrar el terminal rápido |
| <kbd>Esc</kbd> | Cerrar el terminal rápido y terminar su shell |

Registra otro atajo en **Ajustes → Terminal → Terminal rápido**. Un terminal sin fijar también se cierra al perder el foco. Consulta [Terminal rápido](/es/docs/terminal#global-quick-terminal).

## Proyectos y sesiones [#projects-and-sessions]

| Atajo | Acción |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>N</kbd> | Nuevo proyecto |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | Nueva sesión |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | Nueva ventana |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | Cerrar el panel con el foco |
| <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Cambiar al proyecto 1–9 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Proyecto siguiente / anterior |
| <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Cambiar a la pestaña 1–9 |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Selector de pestañas, por uso reciente |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Pestaña siguiente / anterior |

## Paneles divididos [#panes]

| Atajo | Acción |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Dividir a la derecha |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Dividir abajo |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+flechas | Enfocar el panel en esa dirección |
| <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> | Alternar el foco entre paneles |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> | Alternar la ampliación del panel |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+flechas | Cambiar el tamaño del panel con el foco |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> | Igualar paneles |

Dividir a la izquierda y arriba no tienen atajos predeterminados; usa el menú **Pestañas**, el menú contextual del panel o la paleta de comandos.

## Paneles laterales [#panels]

| Atajo | Acción |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>P</kbd> | Paleta de comandos |
| <kbd>Cmd</kbd>+<kbd>O</kbd> | Inicio rápido |
| <kbd>Cmd</kbd>+<kbd>B</kbd> | Mostrar u ocultar la barra lateral izquierda |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | Mostrar u ocultar la barra lateral derecha |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Panel de Git |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Panel Archivos |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | Panel Información |

## Navegador y agentes [#browser-and-agents]

| Atajo | Acción |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>L</kbd> | Enfocar la barra de direcciones del navegador actual |
| <kbd>Cmd</kbd>+<kbd>R</kbd> | Recargar la página actual del navegador |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Ir al siguiente agente que necesite atención |

Las nuevas pestañas y paneles de navegador no tienen un atajo predeterminado; usa el menú **Archivo** o la paleta de comandos.

## Texto y búsqueda [#text-and-search]

| Atajo | Acción |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>F</kbd> | Buscar en el panel con el foco |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> | Buscar y reemplazar (editor) |
| <kbd>Cmd</kbd>+<kbd>G</kbd> | Buscar siguiente |
| <kbd>Shift</kbd>+<kbd>Return</kbd> | Buscar anterior desde la barra de búsqueda |
| <kbd>Cmd</kbd>+<kbd>E</kbd> | Usar la selección para buscar |
| <kbd>Cmd</kbd>+<kbd>K</kbd> | Limpiar el terminal |
| <kbd>Cmd</kbd>+<kbd>S</kbd> | Guardar el archivo abierto |
| <kbd>Cmd</kbd>+<kbd>,</kbd> | Ajustes |

## Buscar anterior [#find-previous]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> es el atajo habitual de macOS para Buscar anterior, pero en Zshell muestra u oculta el panel de Git. Usa <kbd>Shift</kbd>+<kbd>Return</kbd> dentro de la barra de búsqueda; también funciona la opción del menú **Edición → Buscar**.
