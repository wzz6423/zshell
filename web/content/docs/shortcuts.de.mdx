---
title: Tastenkürzel
description: Alle Standardtastenkürzel in Zshell, nach Funktion geordnet.
---

Ein Kürzel vergessen? <kbd>Cmd</kbd>+<kbd>P</kbd> öffnet die Befehlspalette und zeigt neben jedem Befehl sein Tastenkürzel an.

## Globales Schnellterminal [#global-quick-terminal]

| Tastenkürzel | Aktion |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>I</kbd> | Schnellterminal anzeigen / schließen |
| <kbd>Esc</kbd> | Schnellterminal schließen und seine Shell beenden |

Unter **Einstellungen → Terminal → Schnellterminal** können Sie ein anderes Kürzel aufzeichnen. Ein nicht angeheftetes Terminal schließt sich auch beim Fokusverlust. Siehe [Schnellterminal](/de/docs/terminal#global-quick-terminal).

## Projekte und Sitzungen [#projects-and-sessions]

| Tastenkürzel | Aktion |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>N</kbd> | Neues Projekt |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | Neue Sitzung |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | Neues Fenster |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | Fokussierten Bereich schließen |
| <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Zu Projekt 1–9 wechseln |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Nächstes / vorheriges Projekt |
| <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Zu Tab 1–9 wechseln |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Tab-Wechsler nach letzter Verwendung |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Nächster / vorheriger Tab |

## Bereiche [#panes]

| Tastenkürzel | Aktion |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Nach rechts teilen |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Nach unten teilen |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+Pfeiltasten | Bereich in dieser Richtung fokussieren |
| <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> | Fokus zwischen Bereichen wechseln |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> | Bereichsvergrößerung umschalten |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+Pfeiltasten | Größe des fokussierten Bereichs ändern |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> | Bereiche gleich groß machen |

Für das Teilen nach links und oben gibt es keine Standardkürzel. Nutzen Sie das Menü **Tabs**, das Kontextmenü des Bereichs oder die Befehlspalette.

| Tastenkürzel | Aktion |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>P</kbd> | Befehlspalette |

## Browser und Agenten [#browser-and-agents]

| Tastenkürzel | Aktion |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>L</kbd> | Adressleiste des aktuellen Browsers fokussieren |
| <kbd>Cmd</kbd>+<kbd>R</kbd> | Aktuelle Browserseite neu laden |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Zum nächsten Agenten wechseln, der Aufmerksamkeit benötigt |

Für neue Browser-Tabs und -Bereiche gibt es keine Standardkürzel. Nutzen Sie das Menü **Ablage** oder die Befehlspalette.

## Text und Suche [#text-and-search]

| Tastenkürzel | Aktion |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>F</kbd> | Im fokussierten Bereich suchen |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> | Suchen und Ersetzen im Editor |
| <kbd>Cmd</kbd>+<kbd>G</kbd> | Nächsten Treffer suchen |
| <kbd>Shift</kbd>+<kbd>Return</kbd> | In der Suchleiste den vorherigen Treffer suchen |

| <kbd>Cmd</kbd>+<kbd>K</kbd> | Terminal leeren |
| <kbd>Cmd</kbd>+<kbd>S</kbd> | Geöffnete Datei speichern |
| <kbd>Cmd</kbd>+<kbd>,</kbd> | Einstellungen |

## Vorherigen Treffer suchen [#find-previous]

Unter macOS sucht <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> normalerweise den vorherigen Treffer; in Zshell schaltet es jedoch das Git-Panel um. Verwenden Sie stattdessen <kbd>Shift</kbd>+<kbd>Return</kbd> in der Suchleiste oder den entsprechenden Menüeintrag unter **Bearbeiten → Suchen**.
