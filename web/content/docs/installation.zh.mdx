Zshell 未经 Apple 公证。当前版本需要的最低
macOS 版本，标在[首页](/)的下载按钮旁边。

## 下载

从[首页](/)下载 `.dmg`。当前 0.1.0 提供 **Universal** 包，同时支持 Apple Silicon 和 Intel。
分架构安装包和 Gitee 镜像发布后，首页会显示对应的下载选项。
打开磁盘映像后，把 **Zshell** 拖进「应用程序」文件夹。

首次打开时，macOS 可能会拦截应用。尝试打开后，前往
**系统设置 → 隐私与安全性 → 仍要打开**，确认打开 Zshell。
通过 Homebrew 安装也可能需要这一步。

## Homebrew

```bash
brew install wzz6423/tap/zshell
```

cask 放在 `wzz6423/homebrew-tap`。后续分架构版本会按本机处理器安装 ZIP 包，安装后由 Sparkle 更新。
需要显式通过 Homebrew 更新，或补齐落后的已安装版本时，可以运行：

```bash
brew upgrade --cask --greedy-auto-updates zshell
```

## 更新

最初发布的 0.1.0 下载包仍使用原 GitHub 更新源，Homebrew 安装交给 Homebrew 更新。
下面的更新方式将在下一次重新发版后提供，尚未包含在原下载包中。

重新发版后，直接下载和 Homebrew 安装都通过 [Sparkle](https://sparkle-project.org) 更新。
Zshell 优先访问 Gitee 更新源；feed 或下载失败时，自动重试 GitHub 一次。
安装前会验证 feed 和更新包的签名，并保留安装包的架构；在 Rosetta 下运行的 Intel 版
会迁移到 Apple Silicon 版。

用 <kbd>Cmd</kbd>+<kbd>,</kbd> 打开 **设置 → Updates**，可控制自动检查，
或选择 **Check for Updates…** 立即检查。下载完成后，在退出或重启 Zshell 时安装。
需要显式更新或补齐落后的已安装版本时，使用上面的 Homebrew 命令。

## 从 Finder 打开文件夹

Zshell 注册了一个名为 **New Zshell Project Here** 的 macOS 服务。在 Finder 里选中一个或多个文件夹，右键，从 **服务** 子菜单里选它——每个文件夹都会作为一个项目打开，终端已经在对应目录里启动好了。

如果菜单里没有它，去 **系统设置 → 键盘 → 键盘快捷键 → 服务 → 文件和文件夹** 打开。macOS
只会在应用至少启动过一次之后才列出新服务。

## 卸载

如果打开了 **设置 → Automation → AI**，请先关掉再删除应用，让 Zshell 移除它安装的 agent 支持。

从「应用程序」里删掉 `zshell.app`，如果想彻底清干净，再删掉它的配置：

```bash
rm -rf ~/.config/zshell
```

窗口布局、侧边栏宽度和会话快照存在 macOS 自己的偏好设置里：

```bash
defaults delete sh.zshell
```
