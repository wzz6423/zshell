每个构建都经过 Apple 签名与公证，所以打开时不会弹出 Gatekeeper 警告。当前版本需要的最低
macOS 版本，标在[首页](/)的下载按钮旁边。

## 下载

从[首页](/)下载 `.dmg`，打开后把 **Zshell** 拖进「应用程序」文件夹。

## Homebrew

```bash
brew install wzz6423/tap/zshell
```

cask 放在 `wzz6423/homebrew-tap`，所以要写完整的 tap 名。升级方式和别的软件一样：

```bash
brew upgrade --cask --greedy-auto-updates zshell
```

## 更新

Zshell 会检测安装来源并使用对应的更新方式。直接下载的版本通过
[Sparkle](https://sparkle-project.org) 后台检查、静默下载，等你下次退出时安装；通过
Homebrew 安装的版本则交给 Homebrew 更新。

想改这个行为，用 <kbd>Cmd</kbd>+<kbd>,</kbd> 打开 **设置 → Updates**：

- **Automatically check for updates**——控制直接下载版本的 Sparkle 后台检查。
- **Check for Updates…**——直接下载版本检查 Sparkle，Homebrew 版本运行 Homebrew 更新。

<Callout title="用 Homebrew 装的？">
「Updates」区域会标明 Homebrew 安装来源，更新按钮会运行
`brew upgrade --cask --greedy-auto-updates zshell`。你也可以在终端手动执行这条命令。
</Callout>

## 从 Finder 打开文件夹

Zshell 注册了一个名为 **New Zshell Project Here** 的 macOS 服务。在 Finder 里选中一个或多个文件夹，右键，从 **服务** 子菜单里选它——每个文件夹都会作为一个项目打开，终端已经在对应目录里启动好了。

如果菜单里没有它，去 **系统设置 → 键盘 → 键盘快捷键 → 服务 → 文件和文件夹** 打开。macOS
只会在应用至少启动过一次之后才列出新服务。

## 卸载

如果打开了 **设置 → Automation → AI**，请先关掉再删除应用，让 Zshell 移除它安装的 agent 支持。

从「应用程序」里删掉 `zshell.app`，如果想彻底清干净，再删掉它的配置：

```bash
rm -rf ~/.config/zshell
```

窗口布局、侧边栏宽度和会话快照存在 macOS 自己的偏好设置里：

```bash
defaults delete sh.zshell
```
