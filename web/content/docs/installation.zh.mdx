Zshell 未经 Apple 公证。当前版本需要的最低
macOS 版本，标在[首页](/)的下载按钮旁边。

## 下载

从[首页](/)下载 `.dmg`。当前 0.1.6 提供 **Universal**、Apple Silicon 和 Intel
安装包，Gitee 同时提供镜像下载。
打开磁盘映像后，把 **Zshell** 拖进「应用程序」文件夹。

首次打开时，macOS 可能会拦截应用。尝试打开后，前往
**系统设置 → 隐私与安全性 → 仍要打开**，确认打开 Zshell。
通过 Homebrew 安装也可能需要这一步。

## Homebrew

```bash
brew install wzz6423/tap/zshell
```

cask 放在 `wzz6423/homebrew-tap`，会按本机处理器安装 ZIP 包，安装后由 Sparkle 更新。
需要显式通过 Homebrew 更新，或补齐落后的已安装版本时，可以运行：

```bash
brew upgrade --cask --greedy-auto-updates zshell
```

## 更新

直接下载和 Homebrew 安装都通过 [Sparkle](https://sparkle-project.org) 更新。
中国大陆优先访问 Gitee，失败后尝试 GitHub；其他地区优先访问 GitHub，失败后尝试 Gitee。
地区优先使用当前网络出口 IP 的国家码，查询失败时使用 macOS 系统地区。
国家码查询使用 [ipinfo.io/country](https://ipinfo.io/country)，最多等待 5 秒，结果仅在内存中
缓存 30 分钟。服务会接收到网络公网 IP，Zshell 不保存 IP；关闭自动检查也会停止后台国家码查询。

feed 或更新包下载失败时，只切换到另一个源重试一次。安装前会验证 feed 和更新包的签名，
并保留安装包的架构；在 Rosetta 下运行的 Intel 版会迁移到 Apple Silicon 版。

用 <kbd>Cmd</kbd>+<kbd>,</kbd> 打开 **设置 → 更新**，可分别控制**自动检查更新**和
**自动下载并安装更新**。自动下载默认关闭，需要先开启自动检查；开启后会在后台下载，
并在退出或重启 Zshell 时安装。也可以选择**检查更新…**立即手动检查，或使用上面的
Homebrew 命令显式更新。

## 推荐工具

打开 **设置 → 推荐**，可以浏览终端效率、网络与数据、开发工具链、实用工具和桌面应用，
其中包括 Zisla。页面打开期间会自动检测已安装的工具和可用更新。点击单项的
**安装**或**更新**，用 **安装未安装项**安装所有尚未安装的推荐工具，或用 **全部更新**
更新 Homebrew 管理且有新版本的工具。

工具安装使用 Homebrew；尚未安装 Homebrew 时，页面会提供安装说明入口。
自动检查不会自行安装或更新工具。通过其他方式安装的工具会标注 **非 Homebrew 安装**；
**通过 Homebrew 安装** 会安装一份由 Homebrew 管理的副本，Shell 的 `PATH` 仍可能优先找到
原来的版本。更改安装后，可以点击 **刷新**重新检查。Zshell 自身的更新在**设置 → 更新**中管理。

## 从 Finder 打开文件夹

Zshell 注册了一个名为 **New Zshell Project Here** 的 macOS 服务。在 Finder 里选中一个或多个文件夹，右键，从 **服务** 子菜单里选它——每个文件夹都会作为一个项目打开，终端已经在对应目录里启动好了。

如果菜单里没有它，去 **系统设置 → 键盘 → 键盘快捷键 → 服务 → 文件和文件夹** 打开。macOS
只会在应用至少启动过一次之后才列出新服务。

## 卸载

如果打开了 **设置 → Automation → AI**，请先关掉再删除应用，让 Zshell 移除它安装的 agent 支持。

从「应用程序」里删掉 `zshell.app`，如果想彻底清干净，再删掉它的配置：

```bash
rm -rf ~/.config/zshell
```

窗口布局、侧边栏宽度和会话快照存在 macOS 自己的偏好设置里：

```bash
defaults delete sh.zshell
```
