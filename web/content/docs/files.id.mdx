Tekan <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> untuk pohon berkas. Seperti panel Git, akarnya adalah [direktori proyek](/id/docs/projects#the-project-directory), sehingga tidak berubah setiap kali Anda menjalankan `cd`.

## Pohon berkas [#the-tree]

Saat panel Berkas terlihat dan Zshell aktif, direktori lokal diperbarui di latar belakang. Untuk proyek SSH, Zshell secara berkala membaca ulang akar jarak jauh dan folder yang diperluas.

Klik berkas untuk membukanya dalam panel aktif. Klik kanan untuk tindakan lainnya:

| Item | Kegunaan |
| --- | --- |
| **Buka (Open)** / **Buka di Samping (Open to the Side)** | Buka dalam panel ini atau panel terbagi baru |
| **Buka di Aplikasi Bawaan (Open in Default App)** | Serahkan ke aplikasi yang ditetapkan macOS |
| **Tampilkan di Finder (Reveal in Finder)** | |
| **Salin Jalur (Copy Path)** | Jalur absolut |
| **cd di Sini (cd Here)** | Jalankan `cd <folder>` dalam terminal aktif |
| **Berkas Baru… (New File…)** / **Folder Baru… (New Folder…)** | Buat di dalam folder yang dipilih |
| **Ubah Nama (Rename)** | |
| **Pindahkan ke Tong Sampah (Move to Trash)** | Masukkan ke Tong Sampah, bukan hapus permanen |

Baris memakai ikon Material sesuai nama berkas. Dalam repositori Git, jalur yang berubah memakai warna dan lencana status, sedangkan berkas yang diabaikan diredupkan. Pohon menampilkan keadaan pohon kerja yang sama dengan panel Git tanpa harus membukanya.

## Mengimpor berkas dan folder [#import-files-and-folders]

Pilih **Berkas → Impor Berkas…**, tombol impor di panel Berkas, atau pilihan tersebut dari menu klik kanan folder. Pilih beberapa berkas atau folder; Zshell menyalinnya ke folder tersebut atau akar pohon saat ini sambil mempertahankan aslinya.

Untuk menjatuhkan item Finder ke folder atau area kosong pohon, aktifkan **Pengaturan → Editor → Berkas → Impor dengan menyeret ke pohon berkas** (`files.drag-import`). Opsi ini nonaktif secara bawaan. Menu tetap tersedia.

Nama yang sudah ada menawarkan **Ganti**, **Lewati**, dan **Batal**. Mengganti folder mengganti seluruh folder tanpa menggabungkan isinya. Membatalkan menghentikan seluruh impor dan memulihkan salinan yang telah ditambahkan. Jika program lain mengubah item sebelum dipulihkan, Zshell mempertahankan perubahan dan menunjukkan folder yang mungkin berisi file pemulihan. Pohon SSH tidak menerima impor lokal. Tautan simbolis disalin sebagai tautan tanpa mengikuti targetnya.

## Cari berkas dan isi [#find-files-and-search-contents]

Palet perintah (<kbd>Cmd</kbd>+<kbd>P</kbd>) menemukan berkas menurut nama atau jalur di proyek lokal yang terbuka pada jendela saat ini, bersama perintah dan sesi terbuka. Memilih berkas berpindah ke proyeknya dan membukanya di sana.

Untuk mencari teks dalam berkas, klik kaca pembesar di panel Berkas atau pilih **Cari Isi Berkas (Search File Contents)** dalam palet perintah.
Masukkan teks dan tekan <kbd>Return</kbd> untuk mencari dalam direktori proyek lokal saat ini. Gunakan **Aa** untuk membedakan huruf besar-kecil, lalu buka hasil untuk menuju baris yang cocok di editor.

Pencarian isi mencocokkan teks literal, melewati berkas biner serta folder dependensi dan build yang umum, lalu berhenti pada 2.000 kecocokan.
Anda dapat menghentikan pencarian sambil mempertahankan hasilnya, atau menutup pencarian untuk kembali ke pohon berkas. Proyek SSH tidak disertakan dalam pencarian berkas lokal ini.

## Editor [#the-editor]

Membuka berkas menghadirkan editor sungguhan dalam panel, dengan penyorotan sintaks.

| Tindakan | Pintasan |
| --- | --- |
| Simpan | <kbd>Cmd</kbd>+<kbd>S</kbd> |
| Cari | <kbd>Cmd</kbd>+<kbd>F</kbd> |
| Cari dan ganti | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> |
| Cari berikutnya | <kbd>Cmd</kbd>+<kbd>G</kbd> |

Menutup berkas, diff, proyek, atau jendela ruang kerja, maupun keluar dari Zshell, akan meminta konfirmasi untuk menyimpan perubahan. **Batal** atau kegagalan penyimpanan membuat ruang kerja dan terminal terkait tetap terbuka. Dalam mode bar menu, menutup jendela terakhir hanya menyembunyikannya dan mempertahankan perubahan; keluar dari aplikasi tetap meminta konfirmasi penyimpanan.

Baris panjang dibungkus sesuai lebar panel secara bawaan. Nonaktifkan [`editor.wrap-lines`](/id/docs/configuration#editorwrap-lines) untuk menggulir secara horizontal.

Mengganti nama berkas di pohon memperbarui semua panel yang membukanya, termasuk berkas di dalam folder yang diganti namanya.

Jika program lain mengubah berkas terbuka, Zshell memperbarui pratinjau yang tidak memiliki perubahan saat aplikasi aktif kembali. Buffer editor dengan perubahan belum tersimpan tidak pernah diganti.

Jika program lain mengubah file saat Anda mengeditnya, menyimpan membuka dialog konflik. **Bandingkan…** menampilkan disk dan draf berdampingan; **Simpan Draf** membatalkan penyimpanan, **Muat Ulang dari Disk** membuang draf, dan **Timpa File** mengganti versi yang dibandingkan. Pemeriksaan juga berlaku sebelum menutup dan pada diff yang dapat diedit. Atur melalui **Pengaturan → Editor → Lindungi dari konflik penyimpanan** atau [`editor.protect-saves`](/id/docs/configuration#editorprotect-saves).

<Callout type="info">
Editor ini untuk perubahan yang sedang Anda lihat: memperbaiki salah ketik, mengubah konstanta, atau membaca berkas yang dirujuk oleh diff. Tidak ada server bahasa, pelengkapan, atau refaktor seluruh proyek. Itu disengaja.
</Callout>

## Memulihkan draf yang belum disimpan [#recover-unsaved-drafts]

Zshell secara default mencadangkan perubahan yang belum disimpan pada berkas lokal dan diff pohon kerja yang dapat diedit. Setelah keluar secara tak terduga, panel yang dibuka kembali memulihkan draf, pilihan, dan tata letaknya. Untuk cadangan lain, buka **Berkas → Pulihkan Draf…** atau **Pengaturan → Editor → Pulihkan Draf…**, pilih cadangan, tinjau isinya, lalu pilih **Pulihkan Draf**. Pemulihan membuka editor yang belum disimpan tanpa mengubah berkas di disk. Penyimpanan tetap memeriksa perubahan eksternal menggunakan versi sebelum edit Anda.

Kendalikan cadangan melalui **Pengaturan → Editor → Cadangkan draf yang belum disimpan** atau `editor.recover-drafts`. Menonaktifkannya menghentikan cadangan baru dan pemulihan otomatis, tetapi menyimpan cadangan yang ada untuk pemulihan atau penghapusan manual. **Hapus Cadangan** hanya menghapus cadangan terpilih; edit terbuka tetap ada. Penyimpanan berhasil atau **Jangan Simpan** saat penutupan selesai menghapus cadangan. Berkas privat tetap di Mac ini, dibatasi 32 draf dan 128 MiB dan dapat dipulihkan hingga 30 hari. Batas kapasitas dapat menghapus cadangan lama lebih awal. Berkas dan teks edit di atas 5 MiB dikecualikan.

Zshell menghapus cadangan kedaluwarsa saat memulai dan setiap jam selama berjalan, meskipun pencadangan dinonaktifkan. Jika Zshell ditutup, berkas kedaluwarsa tetap di disk hingga pembukaan berikutnya.

## Pratinjau Markdown [#markdown-preview]

Buka berkas `.md` untuk membaca hasil render dalam panel yang sama. Klik **Edit** di kanan atas untuk mengubah sumber, lalu **Pratinjau (Preview)** untuk melihat hasilnya.
Zshell mengingat mode pilihan Anda untuk berkas Markdown lain dan peluncuran berikutnya.

Pergantian mode mempertahankan suntingan dan riwayat undo. Simpan seperti biasa dengan <kbd>Cmd</kbd>+<kbd>S</kbd>. Berkas Markdown berekstensi lain dibuka sebagai sumber.

## Perbedaan [#diffs]

Diff dari [panel Git](/id/docs/git) juga merupakan panel biasa, sehingga diff, berkas, dan terminal dapat berdampingan dalam satu tab.
Tampilannya memakai font terminal, dan perubahan berisi seribu berkas terbuka secepat perubahan satu baris. Diff pohon kerja aktif yang belum di-stage juga dapat beralih dari Tinjau ke Edit; diff yang telah di-stage dan diff historis tetap hanya baca.
Lihat [Membaca perbedaan](/id/docs/git#reading-diffs).
