Premi <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> per l'albero dei file. Come il pannello Git, usa la [directory del progetto](/it/docs/projects#the-project-directory) come radice e non la cambia a ogni `cd`.

## L'albero [#the-tree]

Con il pannello File visibile e Zshell attivo, le directory locali vengono aggiornate in background. Per i progetti SSH, Zshell rilegge periodicamente la radice remota e le cartelle espanse.

Fai clic su un file per aprirlo nel pannello attivo. Il clic destro offre il resto:

| Voce | Funzione |
| --- | --- |
| **Apri** / **Apri a lato** | Nel pannello corrente o in una nuova divisione |
| **Apri nell'app predefinita** | Usa l'app associata da macOS |
| **Mostra nel Finder** | |
| **Copia percorso** | Il percorso assoluto |
| **cd qui** | Esegue `cd <folder>` nel terminale attivo |
| **Nuovo file…** / **Nuova cartella…** | Crea nella cartella selezionata |
| **Rinomina** | |
| **Sposta nel Cestino** | Sposta nel Cestino senza eliminare definitivamente |

Le righe usano icone Material in base al nome del file. Nei repository Git, i percorsi modificati mostrano anche colori e indicatori di stato, mentre i file ignorati sono attenuati. L'albero riflette così lo stesso worktree del pannello Git senza aprirlo.

## Importare file e cartelle [#import-files-and-folders]

Scegli **File → Importa file…**, il pulsante di importazione nel pannello File o la voce del menu contestuale di una cartella. Puoi selezionare più file o cartelle: Zshell li copia nella cartella scelta o nella radice corrente dell’albero, conservando gli originali.

Per rilasciare elementi del Finder su una cartella o nell’area vuota dell’albero, abilita **Impostazioni → Editor → File → Importa trascinando nell’albero dei file** (`files.drag-import`). L’opzione è disattivata per impostazione predefinita; il menu rimane disponibile.

In caso di nomi esistenti puoi **Sostituire**, **Ignorare** o **Annullare**. Una cartella viene sostituita interamente, senza unire i contenuti. Annullare interrompe tutta l’importazione e ripristina le copie già aggiunte. Se un altro programma modifica un elemento prima del ripristino, Zshell conserva la modifica e indica dove recuperare le copie salvate. Gli alberi SSH non accettano importazioni locali. I collegamenti simbolici vengono copiati come collegamenti, senza seguirne la destinazione.

## Trovare file e cercare nei contenuti [#find-files-and-search-contents]

La palette (<kbd>Cmd</kbd>+<kbd>P</kbd>) trova file per nome o percorso tra i progetti locali aperti nella finestra corrente, insieme a comandi e sessioni. Selezionare un file passa al suo progetto e lo apre lì.

Per cercare testo nei file, fai clic sulla lente nel pannello File o scegli **Cerca contenuto dei file** nella palette. Inserisci il testo e premi <kbd>Return</kbd> per cercare nella directory del progetto locale corrente. **Aa** distingue maiuscole e minuscole; apri un risultato per raggiungere la riga corrispondente nell'editor.

La ricerca usa testo letterale, salta binari e cartelle comuni di dipendenze e build, e si ferma a 2.000 corrispondenze. Puoi interromperla mantenendo i risultati o chiuderla per tornare all'albero. I progetti SSH sono esclusi dalle ricerche locali.

## L'editor [#the-editor]

Aprire un file offre un vero editor in un pannello, con evidenziazione della sintassi.

| Azione | Scorciatoia |
| --- | --- |
| Salva | <kbd>Cmd</kbd>+<kbd>S</kbd> |
| Trova | <kbd>Cmd</kbd>+<kbd>F</kbd> |
| Trova e sostituisci | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> |
| Trova successivo | <kbd>Cmd</kbd>+<kbd>G</kbd> |

Chiudere un file, un diff, un progetto o una finestra di lavoro, oppure uscire da Zshell, richiede di scegliere se salvare le modifiche. **Annulla** o un salvataggio non riuscito mantiene aperti lo spazio di lavoro e i terminali interessati. In modalità barra dei menu, chiudere l’ultima finestra la nasconde soltanto e conserva le modifiche; uscire dall’app richiede comunque di salvarle.

Le righe lunghe vanno a capo alla larghezza del pannello. Disattiva [`editor.wrap-lines`](/it/docs/configuration#editorwrap-lines) per scorrere orizzontalmente.

Rinominare un file nell'albero aggiorna tutti i pannelli che lo hanno aperto, anche per file contenuti in una cartella rinominata.

Se un altro programma modifica un file aperto, Zshell aggiorna l'anteprima senza modifiche pendenti quando l'app torna attiva. Non sostituisce mai un buffer con modifiche non salvate.

<Callout type="info">
Questo editor serve alla modifica che stai già esaminando: correggere un refuso, cambiare una costante o leggere un file citato nel diff. Non include server di linguaggio, completamento o refactoring dell'intero progetto. È intenzionale.
</Callout>

## Anteprima Markdown [#markdown-preview]

Apri un file `.md` per leggerne l'anteprima renderizzata nello stesso pannello. Fai clic su **Modifica** in alto a destra per lavorare sul sorgente, poi su **Anteprima** per vedere il risultato. Zshell ricorda la modalità preferita per gli altri file Markdown e per il prossimo avvio.

Cambiare modalità conserva modifiche e cronologia di annullamento. Salva con <kbd>Cmd</kbd>+<kbd>S</kbd> come al solito. I file Markdown con altre estensioni si aprono come sorgente.

## Diff [#diffs]

Un diff aperto dal [pannello Git](/it/docs/git) è un altro pannello: diff, file e terminale possono stare affiancati nella stessa scheda. Usa il font del terminale, e un insieme di modifiche con mille file si apre velocemente quanto uno di una riga. I diff correnti non in staging possono passare da Revisione a Modifica; quelli in staging e storici restano in sola lettura. Vedi [Leggere i diff](/it/docs/git#reading-diffs).
