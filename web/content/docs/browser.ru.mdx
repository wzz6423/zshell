Встроенный браузер Zshell можно открыть в любой вкладке или разделённой панели. Это удобно для локального сервера разработки, документации API, задачи или любой страницы, которую хочется видеть рядом с использующим её терминалом.

## Открытие браузера [#opening-a-browser]

- Выберите **Файл → Новая вкладка браузера**, чтобы открыть пустую вкладку.
- Откройте палитру команд (<kbd>Cmd</kbd>+<kbd>P</kbd>) и выполните **Новая вкладка браузера** или **Новая панель браузера**.
- Щёлкните распознанный URL в терминале правой кнопкой с зажатой Command и выберите **Новая вкладка браузера** или **Новая панель браузера**, чтобы открыть адрес без копирования.

Вкладки браузера принадлежат выбранному проекту и входят в его обычную раскладку вкладок и панелей. Если открытых проектов нет, Zshell создаёт проект для браузера.

## Адрес и поиск [#address-and-search]

Поле вверху принимает полный URL, имя хоста или поисковый запрос:

- `zshell.sh` превращается в HTTPS-адрес.
- Для `localhost`, локальных имён хостов, IP-адресов и явно указанных портов используется HTTP.
- Остальной ввод становится поисковым запросом Google.

Нажмите <kbd>Cmd</kbd>+<kbd>L</kbd> для перехода в поле или <kbd>Cmd</kbd>+<kbd>R</kbd> для перезагрузки. На панели инструментов также есть «Назад», «Вперёд», «Остановить/Перезагрузить», «Поделиться» и **Открыть в стандартном браузере**. Поддерживаются жесты трекпада для перехода назад и вперёд.

| Действие | Сочетание клавиш |
| --- | --- |
| Перейти в адресную строку | <kbd>Cmd</kbd>+<kbd>L</kbd> |
| Перезагрузить страницу | <kbd>Cmd</kbd>+<kbd>R</kbd> |

## Открытие ссылок в нужном месте [#opening-links-where-you-want-them]

Щёлкните ссылку на странице правой кнопкой и выберите **Открыть ссылку в новой вкладке** или **Открыть ссылку в новой панели**. Новая страница останется в рабочей среде того же проекта.

Обычный щелчок с Command по распознанному веб-адресу в терминале открывает стандартный браузер. Щелчок правой кнопкой с Command предлагает вкладку или панель Zshell. Аналогичные действия с локальными путями описаны в разделе [Пути и URL](/ru/docs/terminal#paths-and-urls).

## Что сохраняется [#what-is-preserved]

При переключении вкладок и проектов сохраняются история страницы, прокрутка, формы и внутреннее состояние. После перезапуска Zshell восстанавливает текущий URL и раскладку, но не полную историю переходов назад и вперёд.

Панели браузера сохраняют cookie, входы в аккаунты и другие данные сайтов между вкладками и запусками. Это не режим частного просмотра.
