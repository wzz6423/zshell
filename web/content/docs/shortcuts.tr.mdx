---
title: "Klavye kısayolları"
description: "Zshell’in tüm varsayılan kısayolları, işlevlerine göre gruplanmış olarak."
---

Birini unuttunuz mu? <kbd>Cmd</kbd>+<kbd>P</kbd> komut paletini açar ve her komutun kısayolunu yanında gösterir.

## Genel Hızlı Terminal [#global-quick-terminal]

| Kısayol | İşlem |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>I</kbd> | Hızlı Terminal’i göster / kapat |
| <kbd>Esc</kbd> | Hızlı Terminal’i kapat ve kabuğunu sonlandır |

**Ayarlar → Terminal → Hızlı Terminal**’de başka kısayol kaydedin. Sabitlenmemiş terminal odağı kaybedince de kapanır. [Hızlı Terminal](/tr/docs/terminal#global-quick-terminal) bölümüne bakın.

## Projeler ve oturumlar [#projects-and-sessions]

| Kısayol | İşlem |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>N</kbd> | Yeni proje |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | Yeni oturum |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | Yeni pencere |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | Odaktaki bölmeyi kapat |
| <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Proje 1–9’a geç |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Sonraki / önceki proje |
| <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Sekme 1–9’a geç |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Son kullanıma göre sekme seçici |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Sonraki / önceki sekme |

## Bölmeler [#panes]

| Kısayol | İşlem |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Sağa böl |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Aşağı böl |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+ok tuşları | O yöndeki bölmeye odaklan |
| <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> | Bölme odağını döndür |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> | Bölme büyütmesini aç/kapat |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+ok tuşları | Odaktaki bölmeyi boyutlandır |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> | Bölmeleri eşitle |

Sola ve yukarı bölmenin varsayılan kısayolu yoktur; **Sekmeler** menüsünü, bölme bağlam menüsünü veya komut paletini kullanın.

| Kısayol | İşlem |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>P</kbd> | Komut paleti |
| <kbd>Cmd</kbd>+<kbd>O</kbd> | Hızlı Başlat |
| <kbd>Cmd</kbd>+<kbd>B</kbd> | Sol kenar çubuğunu aç/kapat |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | Sağ kenar çubuğunu aç/kapat |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Git paneli |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Dosyalar paneli |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | Bilgi paneli |

## Tarayıcı ve ajanlar [#browser-and-agents]

| Kısayol | İşlem |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>L</kbd> | Geçerli tarayıcının adres çubuğuna odaklan |
| <kbd>Cmd</kbd>+<kbd>R</kbd> | Geçerli tarayıcı sayfasını yeniden yükle |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Dikkat gerektiren sonraki ajana geç |

Yeni tarayıcı sekmesi ve bölmesinin varsayılan kısayolu yoktur; **Dosya** menüsünü veya komut paletini kullanın.

## Öncekini bul [#find-previous]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd>, macOS’te genellikle Öncekini Bul’dur; Zshell’de Git panelini açıp kapatır. Arama çubuğunda <kbd>Shift</kbd>+<kbd>Return</kbd> kullanın; **Düzen → Bul** menüsündeki öğe de çalışır.
