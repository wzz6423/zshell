---
title: اختصارات لوحة المفاتيح
description: جميع الاختصارات الافتراضية في Zshell، مرتبة حسب الوظيفة.
---

نسيت اختصارًا؟ يفتح <span dir="ltr"><kbd>Cmd</kbd>+<kbd>P</kbd></span> لوحة الأوامر ويعرض اختصار كل أمر بجانبه.

## الطرفية السريعة العامة [#global-quick-terminal]

| الاختصار | الإجراء |
| --- | --- |
| <span dir="ltr"><kbd>Cmd</kbd>+<kbd>I</kbd></span> | إظهار / إغلاق الطرفية السريعة |
| <kbd>Esc</kbd> | إغلاق الطرفية السريعة وإنهاء صدفتها |

سجّل اختصارًا مختلفًا في **الإعدادات ← الطرفية ← الطرفية السريعة**. تُغلق الطرفية غير المثبتة أيضًا عندما تفقد التركيز. راجع [الطرفية السريعة](/ar/docs/terminal#global-quick-terminal).

## المشاريع والجلسات [#projects-and-sessions]

| الاختصار | الإجراء |
| --- | --- |
| <span dir="ltr"><kbd>Cmd</kbd>+<kbd>N</kbd></span> | مشروع جديد |
| <span dir="ltr"><kbd>Cmd</kbd>+<kbd>T</kbd></span> | جلسة جديدة |
| <span dir="ltr"><kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd></span> | نافذة جديدة |
| <span dir="ltr"><kbd>Cmd</kbd>+<kbd>W</kbd></span> | إغلاق اللوحة المركّز عليها |
| <span dir="ltr"><kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd></span> | الانتقال إلى المشروع 1–9 |
| <span dir="ltr"><kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd></span> / <kbd>[</kbd> | المشروع التالي / السابق |
| <span dir="ltr"><kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd></span> | الانتقال إلى علامة التبويب 1–9 |
| <span dir="ltr"><kbd>Ctrl</kbd>+<kbd>Tab</kbd></span> | مبدّل علامات التبويب حسب آخر استخدام |
| <span dir="ltr"><kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd></span> / <kbd>[</kbd> | علامة التبويب التالية / السابقة |

## اللوحات [#panes]

| الاختصار | الإجراء |
| --- | --- |
| <span dir="ltr"><kbd>Cmd</kbd>+<kbd>D</kbd></span> | تقسيم إلى اليمين |
| <span dir="ltr"><kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd></span> | تقسيم إلى الأسفل |
| <span dir="ltr"><kbd>Opt</kbd>+<kbd>Cmd</kbd></span>+الأسهم | التركيز على اللوحة في ذلك الاتجاه |
| <span dir="ltr"><kbd>Cmd</kbd>+<kbd>[</kbd></span> / <span dir="ltr"><kbd>Cmd</kbd>+<kbd>]</kbd></span> | التنقل الدوري بين اللوحات |
| <span dir="ltr"><kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd></span> | تبديل تكبير اللوحة |
| <span dir="ltr"><kbd>Ctrl</kbd>+<kbd>Cmd</kbd></span>+الأسهم | تغيير حجم اللوحة المركّز عليها |
| <span dir="ltr"><kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd></span> | توحيد أحجام اللوحات |

لا يوجد اختصار افتراضي للتقسيم إلى اليسار أو الأعلى؛ استخدم قائمة **علامات التبويب** أو القائمة السياقية للوحة أو لوحة الأوامر.

## المتصفح والوكلاء [#browser-and-agents]

| الاختصار | الإجراء |
| --- | --- |
| <span dir="ltr"><kbd>Cmd</kbd>+<kbd>L</kbd></span> | التركيز على شريط عنوان المتصفح الحالي |
| <span dir="ltr"><kbd>Cmd</kbd>+<kbd>R</kbd></span> | إعادة تحميل صفحة المتصفح الحالية |
| <span dir="ltr"><kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd></span> | الانتقال إلى الوكيل التالي الذي يحتاج إلى الانتباه |

لا يوجد اختصار افتراضي لعلامات تبويب المتصفح ولوحاته الجديدة؛ استخدم قائمة **ملف** أو لوحة الأوامر.

## البحث عن السابق [#find-previous]

الاختصار المعتاد في macOS للبحث عن السابق هو <span dir="ltr"><kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd></span>، لكنه يُظهر لوحة Git أو يخفيها في Zshell. استخدم بدلًا منه <span dir="ltr"><kbd>Shift</kbd>+<kbd>Return</kbd></span> داخل شريط البحث؛ ويعمل أيضًا عنصر القائمة في **تحرير ← بحث**.
