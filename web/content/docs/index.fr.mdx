## Structure de l'espace de travail [#workspace-structure]

| Élément | Rôle |
| --- | --- |
| Projet | Un dossier local ou une connexion SSH, organisé dans les groupes de la barre latérale |
| Session | Un onglet de projet que vous pouvez renommer, colorer, épingler et regrouper |
| Volet | Un terminal, un navigateur, un éditeur ou un diff dans un onglet ; divisez les volets pour travailler côte à côte |
