title: Atalhos de teclado
description: Todos os atalhos padrão do Zshell, organizados por função.
---

Esqueceu algum? <kbd>Cmd</kbd>+<kbd>P</kbd> abre a paleta de comandos e mostra o atalho ao lado de cada comando.

## Terminal Rápido global [#global-quick-terminal]

| Atalho | Ação |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>I</kbd> | Mostrar / fechar o Terminal Rápido |
| <kbd>Esc</kbd> | Fechar o Terminal Rápido e encerrar seu shell |

Grave outro atalho em **Ajustes → Terminal → Terminal Rápido**. Um terminal não fixado também fecha ao perder o foco. Consulte [Terminal Rápido](/pt-BR/docs/terminal#global-quick-terminal).

## Projetos e sessões [#projects-and-sessions]

| Atalho | Ação |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>N</kbd> | Novo projeto |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | Nova sessão |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | Nova janela |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | Fechar o painel em foco |
| <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Alternar para o projeto 1–9 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Próximo / projeto anterior |
| <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Alternar para a aba 1–9 |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Seletor de abas por uso recente |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Próxima / aba anterior |

## Painéis [#panes]

| Atalho | Ação |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Dividir à direita |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Dividir abaixo |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+setas | Focar o painel nessa direção |
| <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> | Alternar foco entre painéis |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> | Alternar ampliação do painel |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+setas | Redimensionar o painel em foco |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> | Igualar painéis |

Dividir à esquerda e acima não tem atalho padrão. Use o menu **Abas**, o menu de contexto do painel ou a paleta.

| <kbd>Cmd</kbd>+<kbd>P</kbd> | Paleta de comandos |

## Navegador e agentes [#browser-and-agents]

| Atalho | Ação |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>L</kbd> | Focar a barra de endereço do navegador atual |
| <kbd>Cmd</kbd>+<kbd>R</kbd> | Recarregar a página atual |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Ir ao próximo agente que precisa de atenção |

Novas abas e painéis de navegador não têm atalho padrão; use **Arquivo** ou a paleta.

| <kbd>Cmd</kbd>+<kbd>,</kbd> | Ajustes |

## Buscar ocorrência anterior [#find-previous]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> costuma significar Buscar Anterior no macOS, mas no Zshell alterna o painel Git. Use <kbd>Shift</kbd>+<kbd>Return</kbd> dentro da barra de busca; o item em **Editar → Buscar** também funciona.
