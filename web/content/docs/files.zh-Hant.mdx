按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> 打開檔案樹。和 git 面板一樣，它以
[專案目錄](/zh-Hant/docs/projects#the-project-directory)為根，所以不會每次 `cd` 都換根。

## 檔案樹 [#the-tree]

檔案面板可見且 Zshell 處於前景時，本機目錄會在背景重新整理。SSH 專案會定期從遠端主機重新讀取根目錄與已展開的資料夾。

點檔案在當前窗格裡打開。右鍵是其餘的操作：

| 選單項 | 作用 |
| --- | --- |
| **Open** / **Open to the Side** | 在當前窗格打開，或新開一個分割畫面 |
| **Open in Default App** | 交給 macOS 的預設應用 |
| **Reveal in Finder** | |
| **Copy Path** | 絕對路徑 |
| **cd Here** | 在當前終端機裡執行 `cd <folder>` |
| **New File…** / **New Folder…** | 在選中的資料夾裡新建 |
| **Rename** | |
| **Move to Trash** | 移到廢紙簍，不是直接刪除 |

每一行都使用能識別檔案名的 Material 圖示。在 Git 儲存庫裡，改動過的路徑還會顯示狀態顏色與徽章，被忽略的檔案會變淡，所以不打開 Git 面板也能看出工作區狀態。

## 遠端檔案 [#remote-files]

在檔案面板中開啟 SSH 檔案。**設定 → 編輯器 → 檔案 → 允許修改遠端檔案**（`files.remote-write-enabled`）預設開啟，可建立、重新命名、移至遠端回收目錄或儲存。

Zshell 只使用主機已有的工具，不安裝任何相依項目。讀取和編輯檔案使用主機已有的 Perl 核心模組。每項寫入操作也會檢測所需的檔案系統能力，不支援的操作維持停用。不支援符號連結、特殊檔案和專案外的路徑。UTF-8 文字檔案最大為 5 MiB；遠端 Markdown 以原始碼開啟。

即使關閉本機儲存保護，遠端儲存仍會檢查檔案變更。發生衝突時，可比較、保留草稿、從遠端重新載入或明確允許覆寫。發佈完整檔案前會立即複查已比較的版本；外部程序仍可能在最終檢查後寫入。

**移至遠端回收目錄**會將內容和原路徑資訊保存在專案的私有 `.zshell-trash` 目錄中。**回復上一個遠端項目**可在目前專案選取期間回復最近移入的項目，不取代同名內容。較早的項目仍保留在該目錄中，可手動回復。

## 匯入檔案與資料夾 [#import-files-and-folders]

選擇 **檔案 → 匯入檔案…**、點擊檔案面板的匯入按鈕，或在資料夾上按右鍵並選擇 **匯入檔案…**。可選取多個檔案或資料夾；Zshell 會將它們複製到選取的資料夾或目前檔案樹根目錄，保留原始檔案。

**設定 → 編輯器 → 檔案 → 拖入檔案樹以匯入**（`files.drag-import`）預設開啟，可把 Finder 項目拖到資料夾或檔案樹空白處；關閉拖放時，選單匯入仍可使用。

同名項目會提供 **取代**、**略過** 與 **取消**。取代資料夾會取代整個資料夾，不會合併內容。取消會停止整個匯入並還原本次已加入的副本。若其他程式在還原前修改匯入項目，Zshell 會保留修改，並顯示可能包含復原檔案的目錄。SSH 檔案樹不接受本機匯入。符號連結會複製為連結，不會跟隨目標。

## 查找檔案與搜尋內容 [#find-files-and-search-contents]

指令面板（<kbd>Cmd</kbd>+<kbd>P</kbd>）按檔案名或路徑查找當前視窗中已打開的本地專案，
同時顯示匹配的指令和工作階段。選中檔案後，會切到它所屬的專案並打開檔案。

要搜尋檔案裡的文字，點擊檔案面板中的放大鏡，或在指令面板中選擇 **搜尋檔案內容**。
輸入文字並按 <kbd>Return</kbd>，即可搜尋當前本地專案目錄。**Aa** 控制是否區分大小寫；
打開搜尋結果，會在編輯器中跳到對應的行。

內容搜尋按字面文字匹配，跳過二進制檔案和常見依賴、構建目錄，最多顯示 2,000 條結果。
可以停止正在執行的搜尋並保留已有結果，或關閉搜尋回到檔案樹。這些本地檔案搜尋不包含
SSH 專案。

## 編輯器 [#the-editor]

打開檔案後，窗格裡是一個真正的編輯器，帶語法高亮。

本機 PNG、JPEG、GIF、HEIC、WebP、TIFF、BMP 和 ICNS 圖片預覽只讀取不超過 64 MiB 的一般檔案；超限會提示檔案過大。

| 操作 | 快速鍵 |
| --- | --- |
| 儲存 | <kbd>Cmd</kbd>+<kbd>S</kbd> |
| 查找 | <kbd>Cmd</kbd>+<kbd>F</kbd> |
| 查找並替換 | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> |
| 查找下一個 | <kbd>Cmd</kbd>+<kbd>G</kbd> |

關閉檔案、Diff、專案或工作區視窗，以及結束 Zshell 時，會詢問是否儲存未儲存的修改。選擇 **取消** 或儲存失敗時，相關工作區與終端機會保持開啟。在選單列模式下，關閉最後一個視窗只會隱藏它並保留修改；結束應用程式前仍會詢問是否儲存。

長行預設按窗格寬度軟折行。關閉
[`editor.wrap-lines`](/zh-Hant/docs/configuration#editorwrap-lines) 後改為橫向捲動。

在檔案樹裡重新命名檔案，所有打開了它的窗格都會跟著更新，包括被重新命名資料夾底下的檔案。

如果外部程式改了一個已經打開的檔案，Zshell 會在應用重新啟用時重新整理沒有本地修改的預覽；有未儲存改動的編輯器緩衝區絕不會被覆蓋。

編輯期間外部程式變更了檔案時，儲存會開啟衝突對話框。**比較…** 並排顯示磁碟版本與草稿；**保留草稿** 取消儲存，**從磁碟重新載入** 捨棄草稿，**覆寫檔案** 取代剛比較的磁碟版本。關閉前儲存與可編輯的工作區 Diff 也使用相同檢查。在 **設定 → 編輯器 → 防止儲存衝突** 或 [`editor.protect-saves`](/zh-Hant/docs/configuration#editorprotect-saves) 中控制。

<Callout type="info">
這是一個用來改你眼前這處改動的編輯器——修個錯字、調個常量、讀一眼 diff 裡提到的檔案。沒有語言伺服器，沒有補全，也沒有跨專案重構。這是有意為之。
</Callout>

## 還原未儲存的草稿 [#recover-unsaved-drafts]

Zshell 預設備份本機檔案與可編輯工作樹 Diff 中未儲存的修改。意外結束後，重新開啟的窗格會還原草稿、選取範圍與版面。其他備份可從 **檔案 → 還原草稿…** 或 **設定 → 編輯器 → 還原草稿…** 找回：選取備份、查看內容，再按 **還原草稿**。還原只會開啟未儲存的編輯器，不會變更磁碟檔案；儲存時仍以編輯前的版本檢查外部變更。

在 **設定 → 編輯器 → 備份未儲存的草稿** 或 `editor.recover-drafts` 中控制備份。關閉後停止新增備份與自動還原，現有備份仍可手動還原或刪除。**刪除備份** 只移除選取的備份，保留已開啟的編輯內容。成功儲存或完成關閉時選擇 **不儲存** 會移除備份。備份以私有檔案儲存在此 Mac，最多 32 份、共 128 MiB，最多保留 30 天。容量限制可能導致較舊的備份提前刪除。超過 5 MiB 的檔案與編輯文字不會備份。

Zshell 在啟動時及執行期間每小時清理過期備份，關閉備份開關後仍會清理。應用程式關閉期間，過期檔案會留在磁碟上，直到下次啟動時刪除。

## Markdown 預覽 [#markdown-preview]

打開 `.md` 檔案後，可以直接在窗格裡閱讀渲染後的文檔。點擊右上角的 **編輯** 修改源文，
再用 **預覽** 查看效果。Zshell 會記住這個模式，後續打開 Markdown 檔案和重新啟動時繼續沿用。

切換模式會保留編輯內容和撤銷歷史；按 <kbd>Cmd</kbd>+<kbd>S</kbd> 儲存改動。
其他副檔名的 Markdown 檔案仍以原始碼打開。

## Diff [#diffs]

從 [git 面板](/zh-Hant/docs/git)打開的 diff 也只是一個窗格，所以 diff、檔案和終端機可以在一個分頁裡並排。它使用你的終端機字型，上千個檔案的改動集，打開速度和一行的一樣。實時工作區裡尚未暫存的 diff 還可以從 Review 切到 Edit；已暫存和歷史 diff 始終只讀。見
[看 diff](/zh-Hant/docs/git#reading-diffs)。
