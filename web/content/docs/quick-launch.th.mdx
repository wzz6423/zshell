<kbd>Cmd</kbd>+<kbd>O</kbd> เปิด **เรียกใช้ด่วน** ซึ่งเป็นรายการที่ค้นหาได้ แต่ละรายการเปิดโปรเจกต์ใหม่พร้อมเซสชันเทอร์มินัล รายการที่บันทึกเป็น **คำสั่ง** ที่พิมพ์บ่อย เช่น `npm run dev` หรือ `make watch` หรือเป็น **การเชื่อมต่อ SSH**

## เรียกใช้รายการ [#launching]

พิมพ์ชื่อ คำสั่ง เป้าหมายเชื่อมต่อ หรือกลุ่มเพื่อกรองแบบใกล้เคียง คลิกแถวหรือใช้ลูกศรเลือกแล้วกด <kbd>Return</kbd> รายการรันในโปรเจกต์ใหม่ที่ตั้งชื่อตามรายการ พร้อมเซสชันและไดเรกทอรีของตนเอง

เมื่อคำสั่งจบหรือการเชื่อมต่อปิด ช่องกลับสู่พรอมป์ shell ปกติแทนที่จะหายไป สิ่งที่เรียกใช้จะไม่ปิดตัวเองเงียบ ๆ

เรียกรายการที่บันทึกตามชื่อจากเทอร์มินัล Zshell ใดก็ได้:

```bash
zshell "Entry name"
```

ใช้ชื่อรายการตรงตัวและใส่เครื่องหมายคำพูดหากมีช่องว่าง คำแนะนำด้านล่างหน้าต่างแสดงรูปแบบนี้ รายการเปิดในโปรเจกต์ใหม่

## จัดการรายการ [#managing-entries]

- <kbd>Cmd</kbd>+<kbd>N</kbd> — รายการใหม่
- <kbd>Cmd</kbd>+<kbd>E</kbd> — แก้ไขรายการที่เลือก
- <kbd>Cmd</kbd>+<kbd>Delete</kbd> — ลบรายการที่เลือก

ใช้ช่อง **กลุ่ม** ที่ไม่บังคับเพื่อจัดรายการเป็นส่วนที่มีชื่อ ปุ่มแก้ไขและลบทำงานกับรายการโดยไม่เรียกใช้

รายการคำสั่งปักหมุด **ไดเรกทอรีทำงาน** ที่ต้องเริ่มเสมอได้ หากไม่ระบุจะใช้ไดเรกทอรีเริ่มต้นของโปรเจกต์ใหม่ รายการ SSH รับโฮสต์ ผู้ใช้และพอร์ตที่ไม่บังคับ พร้อมตัวเลือก `ssh` เพิ่มเติมแบบอิสระ เช่น `-L 8080:localhost:80`

## ที่เก็บรายการ [#where-entries-live]

รายการบันทึกใน `~/.config/zshell/quick-launch.json` และใช้ร่วมกันทุกหน้าต่าง เป็นข้อมูลผู้ใช้ทั่วไป จึงแก้ไขหรือสำรองไฟล์ได้ตามต้องการ

<Callout type="info">
คำสั่งรันผ่าน login shell จึงเห็นสภาพแวดล้อมโปรไฟล์ของคุณ หลังจากนั้นช่องเป็นเซสชันปกติ โดย alias และพรอมป์ยังอยู่ครบ
</Callout>
