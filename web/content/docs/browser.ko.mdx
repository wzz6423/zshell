---

Zshell은 모든 탭이나 분할 창에 내장 브라우저를 표시할 수 있습니다. 로컬 개발 서버, API 문서, 이슈 등 관련 터미널 옆에 두고 싶은 페이지를 열 때 유용합니다.

## 브라우저 열기 [#opening-a-browser]

- **파일 → 새 브라우저 탭**을 선택하면 빈 탭이 열립니다.
- 명령 팔레트(<kbd>Cmd</kbd>+<kbd>P</kbd>)를 열고 **새 브라우저 탭** 또는 **새 브라우저 분할 창**을 실행하세요.
- 터미널에서 감지된 URL을 Command 키를 누른 채 오른쪽 클릭하고 **새 브라우저 탭** 또는 **새 브라우저 분할 창**을 선택하면 주소를 복사하지 않고 열 수 있습니다.

브라우저 탭은 선택한 프로젝트에 속하며 일반 탭 및 분할 창 배치에 포함됩니다. 열린 프로젝트가 없으면 Zshell이 브라우저를 담을 프로젝트를 만듭니다.

## 주소와 검색 [#address-and-search]

위쪽 입력란에는 전체 URL, 호스트 이름 또는 검색어를 입력할 수 있습니다.

- `zshell.sh`은 HTTPS 주소로 연결됩니다.
- `localhost`, 로컬 호스트 이름, IP 주소와 명시적인 포트는 HTTP를 사용합니다.
- 그 밖의 입력은 Google 검색으로 처리됩니다.

<kbd>Cmd</kbd>+<kbd>L</kbd>로 주소 입력란에 포커스를 이동하고 <kbd>Cmd</kbd>+<kbd>R</kbd>로 새로 고칩니다. 도구 막대에는 뒤로, 앞으로, 중지/새로 고침, 공유 및 **기본 브라우저에서 열기**도 있습니다. 트랙패드의 뒤로/앞으로 탐색 제스처도 지원됩니다.

| 작업 | 단축키 |
| --- | --- |
| 주소 막대로 포커스 이동 | <kbd>Cmd</kbd>+<kbd>L</kbd> |
| 페이지 새로 고침 | <kbd>Cmd</kbd>+<kbd>R</kbd> |

## 원하는 위치에 링크 열기 [#opening-links-where-you-want-them]

페이지의 링크를 오른쪽 클릭하면 **링크를 새 탭에서 열기** 또는 **링크를 새 분할 창에서 열기**를 선택할 수 있습니다. 새 페이지는 같은 프로젝트 작업 공간에 남습니다.

터미널에서 감지된 웹 URL을 Command 키를 누른 채 클릭하면 기본 브라우저에서 열립니다. Command 키를 누른 채 오른쪽 클릭하면 Zshell 탭이나 분할 창에서 여는 메뉴가 표시됩니다. 로컬 경로도 비슷한 방식으로 다룰 수 있으며 [경로와 URL](/ko/docs/terminal#paths-and-urls)에서 설명합니다.

## 유지되는 항목 [#what-is-preserved]

탭이나 프로젝트를 전환해도 페이지의 탐색 기록, 스크롤 위치, 양식과 페이지 내부 상태가 그대로 유지됩니다. Zshell을 다시 실행하면 현재 URL과 배치가 복원되지만 전체 뒤로/앞으로 기록은 복원되지 않습니다.

브라우저 분할 창은 탭을 전환하거나 앱을 다시 실행해도 쿠키, 로그인 및 기타 사이트 데이터를 유지합니다. 비공개 브라우징 모드가 아닙니다.
