---
title: Pintasan keyboard
description: Semua pintasan bawaan Zshell, dikelompokkan menurut kegunaannya.
---

Lupa pintasan? <kbd>Cmd</kbd>+<kbd>P</kbd> membuka palet perintah dan menampilkan pintasan di samping setiap perintah.

## Terminal Cepat global [#global-quick-terminal]

| Pintasan | Tindakan |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>I</kbd> | Tampilkan / tutup Terminal Cepat |
| <kbd>Esc</kbd> | Tutup Terminal Cepat dan hentikan shell-nya |

Rekam pintasan lain di **Pengaturan → Terminal → Terminal Cepat**. Terminal yang tidak disematkan juga menutup saat kehilangan fokus. Lihat [Terminal Cepat](/id/docs/terminal#global-quick-terminal).

## Proyek dan sesi [#projects-and-sessions]

| Pintasan | Tindakan |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>N</kbd> | Proyek baru |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | Sesi baru |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | Jendela baru |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | Tutup panel yang difokuskan |
| <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Pindah ke proyek 1–9 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Proyek berikutnya / sebelumnya |
| <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Pindah ke tab 1–9 |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Pengalih tab menurut penggunaan terbaru |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Tab berikutnya / sebelumnya |

## Panel terbagi [#panes]

| Pintasan | Tindakan |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Bagi ke kanan |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Bagi ke bawah |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+tombol panah | Fokus panel ke arah tersebut |
| <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> | Putar fokus panel |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> | Alihkan pembesaran panel |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+tombol panah | Ubah ukuran panel yang difokuskan |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> | Samakan panel |

Pembagian ke kiri dan atas tidak memiliki pintasan bawaan. Gunakan menu **Tab**, menu konteks panel, atau palet perintah.

## Panel samping [#panels]

| Pintasan | Tindakan |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>P</kbd> | Palet perintah |
| <kbd>Cmd</kbd>+<kbd>O</kbd> | Peluncuran Cepat |
| <kbd>Cmd</kbd>+<kbd>B</kbd> | Alihkan bilah samping kiri |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | Alihkan bilah samping kanan |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Panel Git |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Panel Berkas |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | Panel Info |

## Browser dan agen [#browser-and-agents]

| Pintasan | Tindakan |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>L</kbd> | Fokus bilah alamat browser saat ini |
| <kbd>Cmd</kbd>+<kbd>R</kbd> | Muat ulang halaman browser saat ini |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Lompat ke agen berikutnya yang perlu perhatian |

Tab dan panel browser baru tidak memiliki pintasan bawaan. Gunakan menu **Berkas** atau palet perintah.

## Teks dan pencarian [#text-and-search]

| Pintasan | Tindakan |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>F</kbd> | Cari dalam panel aktif |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> | Cari dan ganti (editor) |
| <kbd>Cmd</kbd>+<kbd>G</kbd> | Cari berikutnya |
| <kbd>Shift</kbd>+<kbd>Return</kbd> | Cari sebelumnya dari bilah pencarian |
| <kbd>Cmd</kbd>+<kbd>E</kbd> | Gunakan seleksi untuk pencarian |
| <kbd>Cmd</kbd>+<kbd>K</kbd> | Bersihkan terminal |
| <kbd>Cmd</kbd>+<kbd>S</kbd> | Simpan berkas terbuka |
| <kbd>Cmd</kbd>+<kbd>,</kbd> | Pengaturan |

## Cari sebelumnya [#find-previous]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> biasanya merupakan pintasan macOS untuk Cari Sebelumnya, tetapi di Zshell pintasan ini mengalihkan panel Git.
Gunakan <kbd>Shift</kbd>+<kbd>Return</kbd> dalam bilah pencarian; item menu **Edit → Cari (Find)** juga dapat digunakan.
