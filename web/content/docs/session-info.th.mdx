description: "ดูว่าเซสชันกำลังรันอะไรจริง และเปิดพอร์ตใดไว้"
---

กด <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> แผงข้อมูลอธิบาย **เซสชันที่มีโฟกัส** ไม่ใช่โปรเจกต์ และอัปเดตเมื่อสิ่งต่าง ๆ เริ่มหรือหยุด

## ไดเรกทอรี [#directory]

แยกแสดงเพราะสองค่านี้ไม่เหมือนกันเสมอ:

- **ไดเรกทอรีปัจจุบัน** — ไดเรกทอรีทำงานสดของ shell แสดงเมื่อแตกต่างจากค่าด้านล่าง
- **ไดเรกทอรีโปรเจกต์** — โฟลเดอร์ที่แผงไฟล์และ Git ยึดไว้ มี `(AUTO)` ขณะ Zshell หาให้ ป๊อปโอเวอร์ `?` อธิบายทั้งสอง

ข้างกันมีปุ่มเปิดโฟลเดอร์ใน **Finder**, เปิดใน **VS Code** หากติดตั้ง และ **คัดลอก** เส้นทาง

## โปรเซส [#processes]

ทุกอย่างที่รันใต้ shell ของเซสชัน พร้อม PID เปอร์เซ็นต์ CPU และหน่วยความจำ resident คลิกขวาเพื่อ:

- **ยุติ** — ส่ง `SIGTERM` ตามปกติ
- **บังคับหยุด** — ใช้ `SIGKILL` หากไม่ยอมหยุด
- **คัดลอก PID** / **คัดลอกเส้นทางโปรแกรม**

โปรเซสลูกที่ออกแล้วแต่รอเก็บสถานะ (`<defunct>`) ไม่แสดง เพราะไม่มีอะไรให้ดูหรือหยุดแล้ว

## พอร์ต [#ports]

พอร์ต TCP ที่โปรเซสเหล่านั้นฟัง พร้อมโปรเซสเจ้าของ ช่วยตอบคำถามประจำว่าเซิร์ฟเวอร์พัฒนาเลือกพอร์ตอะไรครั้งนี้ และอะไรยังยึด 3000 อยู่

- คลิกพอร์ตเพื่อเปิด `http://localhost:<port>/` ในเบราว์เซอร์
- **คัดลอก URL**
- **หยุดโปรเซส** — เมื่อสิ่งที่ยึดพอร์ตคือโปรเซสที่คุณลืมไปแล้ว

<Callout type="info">
รายการอัปเดตเมื่อแผงเปิด และหยุดอัปเดตชั่วคราวเมื่อซ่อนแผง
</Callout>
