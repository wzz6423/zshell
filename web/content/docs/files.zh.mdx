按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> 打开文件树。和 git 面板一样，它以
[项目目录](/docs/projects#项目目录)为根，所以不会每次 `cd` 都换根。

## 文件树

点文件在当前窗格里打开。右键是其余的操作：

| 菜单项 | 作用 |
| --- | --- |
| **Open** / **Open to the Side** | 在当前窗格打开，或新开一个分屏 |
| **Open in Default App** | 交给 macOS 的默认应用 |
| **Reveal in Finder** | |
| **Copy Path** | 绝对路径 |
| **cd Here** | 在当前终端里执行 `cd <folder>` |
| **New File…** / **New Folder…** | 在选中的文件夹里新建 |
| **Rename** | |
| **Move to Trash** | 移到废纸篓，不是直接删除 |

每一行都使用能识别文件名的 Material 图标。在 Git 仓库里，改动过的路径还会显示状态颜色与徽章，被忽略的文件会变淡，所以不打开 Git 面板也能看出工作区状态。

## 查找文件与搜索内容

命令面板（<kbd>Cmd</kbd>+<kbd>P</kbd>）按文件名或路径查找当前窗口中已打开的本地项目，
同时显示匹配的命令和会话。选中文件后，会切到它所属的项目并打开文件。

要搜索文件里的文字，点击文件面板中的放大镜，或在命令面板中选择 **搜索文件内容**。
输入文字并按 <kbd>Return</kbd>，即可搜索当前本地项目目录。**Aa** 控制是否区分大小写；
打开搜索结果，会在编辑器中跳到对应的行。

内容搜索按字面文字匹配，跳过二进制文件和常见依赖、构建目录，最多显示 2,000 条结果。
可以停止正在运行的搜索并保留已有结果，或关闭搜索回到文件树。这些本地文件搜索不包含
SSH 项目。

## 编辑器

打开文件后，窗格里是一个真正的编辑器，带语法高亮。

| 操作 | 快捷键 |
| --- | --- |
| 保存 | <kbd>Cmd</kbd>+<kbd>S</kbd> |
| 查找 | <kbd>Cmd</kbd>+<kbd>F</kbd> |
| 查找并替换 | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> |
| 查找下一个 | <kbd>Cmd</kbd>+<kbd>G</kbd> |

长行默认按窗格宽度软折行。关闭
[`editor.wrap-lines`](/docs/configuration#editorwrap-lines) 后改为横向滚动。

在文件树里重命名文件，所有打开了它的窗格都会跟着更新，包括被重命名文件夹底下的文件。

如果外部程序改了一个已经打开的文件，Zshell 会在应用重新激活时刷新没有本地修改的预览；有未保存改动的编辑器缓冲区绝不会被覆盖。

<Callout type="info">
这是一个用来改你眼前这处改动的编辑器——修个错字、调个常量、读一眼 diff 里提到的文件。没有语言服务器，没有补全，也没有跨项目重构。这是有意为之。
</Callout>

## Markdown 预览

打开 `.md` 文件后，可以直接在窗格里阅读渲染后的文档。点击右上角的 **编辑** 修改源文，
再用 **预览** 查看效果。Zshell 会记住这个模式，后续打开 Markdown 文件和重启时继续沿用。

切换模式会保留编辑内容和撤销历史；按 <kbd>Cmd</kbd>+<kbd>S</kbd> 保存改动。
其他扩展名的 Markdown 文件仍以源码打开。

## Diff

从 [git 面板](/docs/git)打开的 diff 也只是一个窗格，所以 diff、文件和终端可以在一个标签页里并排。它使用你的终端字体，上千个文件的改动集，打开速度和一行的一样。实时工作区里尚未暂存的 diff 还可以从 Review 切到 Edit；已暂存和历史 diff 始终只读。见
[看 diff](/docs/git#看-diff)。
