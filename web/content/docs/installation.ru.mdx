Zshell не прошёл нотариальную проверку Apple. Минимальная версия macOS для текущего выпуска указана рядом со ссылкой для скачивания на [главной странице](/ru).

## Скачать [#download]

Скачайте `.dmg` с [главной страницы](/ru). Для текущей версии 0.1.9 доступны пакеты Universal, Apple Silicon и Intel, а также зеркало на Gitee. Откройте образ диска и перетащите **Zshell** в папку «Программы».

При первом запуске macOS может заблокировать приложение. После попытки открыть его перейдите в **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** и подтвердите запуск Zshell. Это относится и к установке через Homebrew.

## Homebrew [#homebrew]

```bash
brew install wzz6423/tap/zshell
```

Cask находится в `wzz6423/homebrew-tap` и устанавливает ZIP для процессора вашего Mac. После установки Zshell использует Sparkle для обновлений. Чтобы явно обновить приложение через Homebrew или перейти на актуальную версию, если установленная отстаёт:

```bash
brew upgrade --cask --greedy-auto-updates zshell
```

## Обновления [#updates]

И загруженное напрямую приложение, и установка через Homebrew используют [Sparkle](https://sparkle-project.org). В материковом Китае Zshell сначала обращается к Gitee, затем к GitHub; в других регионах — сначала к GitHub, затем к Gitee. Если возможно, страна определяется по IP-адресу сети; при неудаче используется регион macOS. Если не удалось получить ленту обновлений или скачать пакет, выполняется одна повторная попытка с другого источника. Для определения страны используется [ipinfo.io/country](https://ipinfo.io/country) с тайм-аутом в пять секунд и кешем в памяти на 30 минут. При этом запросе сервис получает публичный IP-адрес сети; Zshell не сохраняет IP-адрес. Отключение автоматической проверки также прекращает фоновое определение страны.

Перед установкой Zshell проверяет подписанную ленту обновлений и пакет, сохраняя установленную архитектуру; версия Intel, работающая через Rosetta, заменяется версией Apple Silicon.

Откройте **Настройки → Обновления** (<kbd>Cmd</kbd>+<kbd>,</kbd>), чтобы управлять автоматической проверкой и параметром **Автоматически загружать обновления**. Загрузка по умолчанию выключена и требует включённой автоматической проверки. При включении загрузки появляется отдельный переключатель **Автоматически устанавливать обновления**, по умолчанию выключенный. Если установка выключена, обновления загружаются в фоне и устанавливаются при выходе из Zshell. Если включены оба переключателя, подготовленные обновления устанавливаются с автоматическим перезапуском Zshell. При перезапуске работающие процессы терминала останавливаются; рабочее пространство восстанавливается при повторном открытии Zshell. Отключение загрузки скрывает переключатель установки и предотвращает автоматические перезапуски, сохраняя его значение до следующего включения загрузки. Оба параметра сохраняются между запусками приложения. Когда доступно обновление, внизу боковой панели проектов, слева от кнопки обратной связи, появляется значок обновления. Нажмите его, чтобы открыть обновление, увидеть ход выполнения или повторить ожидающий перезапуск. Для ручной проверки выберите **Проверить наличие обновлений…**. Команда Homebrew выше также позволяет явно запустить обновление.

## Рекомендуемые инструменты [#recommended-tools]

Откройте **Настройки → Рекомендации**, чтобы просмотреть инструменты для терминала, сети, разработки, служебных задач и рабочего стола, включая Zisla. Пока страница открыта, она определяет установленные инструменты и проверяет доступные обновления. Используйте кнопку **Установить** или **Обновить** у нужного инструмента, **Установить недостающие** для всех отсутствующих рекомендаций или **Обновить всё** для доступных обновлений инструментов, управляемых Homebrew.

Для установки инструментов используется Homebrew. Если Homebrew отсутствует, на странице есть ссылка на инструкции по его установке. Проверки сами по себе не устанавливают и не обновляют инструменты. Инструменты, найденные вне Homebrew, помечаются **Вне Homebrew**. **Использовать Homebrew** устанавливает копию под управлением Homebrew; существующая копия может по-прежнему иметь приоритет в `PATH` вашей оболочки. После изменения установки нажмите **Обновить сведения**, чтобы проверить ещё раз. Сам Zshell управляется в разделе **Настройки → Обновления**.

## Открыть папку из Finder [#open-a-folder-from-finder]

Zshell регистрирует службу macOS **Новый проект Zshell здесь**. Выберите одну или несколько папок в Finder, нажмите правой кнопкой и выберите эту службу в подменю **Службы** — каждая папка откроется как проект с терминалом, уже запущенным в ней.

Если службы нет в меню, включите её в **Системные настройки → Клавиатура → Сочетания клавиш → Службы → Файлы и папки**. macOS добавляет новую службу в список только после первого запуска приложения.

## Удаление [#uninstalling]

Если включён параметр **Настройки → Автоматизация → ИИ**, выключите его перед удалением приложения, чтобы Zshell мог удалить установленную им поддержку агентов.

Удалите `zshell.app` из папки «Программы», а затем при желании удалите его настройки, чтобы начать с чистого листа:

```bash
rm -rf ~/.config/zshell
```

Расположение окон, ширина боковых панелей и снимок сеанса хранятся в собственном хранилище настроек macOS:

```bash
defaults delete sh.zshell
```
