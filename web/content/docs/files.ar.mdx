اضغط <span dir="ltr"><kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd></span> لفتح شجرة الملفات. مثل لوحة Git، تستخدم الشجرة [مجلد المشروع](/ar/docs/projects#the-project-directory) جذرًا لها، فلا تغيّر الجذر كلما نفذت `cd`.

## الشجرة [#the-tree]

انقر ملفًا لفتحه في اللوحة المركّز عليها. يعرض النقر بزر الفأرة الأيمن بقية الإجراءات:

| العنصر | الوظيفة |
| --- | --- |
| **فتح** / **فتح بجانب اللوحة** | في هذه اللوحة أو في تقسيم جديد |
| **فتح في التطبيق الافتراضي** | استخدام التطبيق الذي يفتحه به macOS |
| **إظهار في Finder** | |
| **نسخ المسار** | المسار المطلق |
| **cd هنا** | تنفيذ `cd <folder>` في الطرفية المركّز عليها |
| **ملف جديد…** / **مجلد جديد…** | الإنشاء داخل المجلد المحدد |
| **إعادة تسمية** | |
| **نقل إلى سلة المهملات** | النقل إلى السلة دون حذف نهائي مباشر |

تستخدم الصفوف أيقونات Material المناسبة لاسم الملف. داخل مستودع Git، تعرض المسارات المعدلة أيضًا ألوان الحالة وشاراتها، وتظهر الملفات المتجاهلة بلون باهت. وهكذا تعكس الشجرة حالة شجرة العمل نفسها التي تعرضها لوحة Git دون الحاجة إلى فتحها.

## العثور على الملفات والبحث في المحتوى [#find-files-and-search-contents]

تعثر لوحة الأوامر (<span dir="ltr"><kbd>Cmd</kbd>+<kbd>P</kbd></span>) على الملفات بالاسم أو المسار عبر المشاريع المحلية المفتوحة في النافذة الحالية، إلى جانب الأوامر والجلسات المفتوحة. يؤدي تحديد ملف إلى الانتقال إلى مشروعه وفتحه هناك.

للبحث عن نص داخل الملفات، انقر العدسة المكبرة في لوحة الملفات أو اختر **البحث في محتوى الملفات** من لوحة الأوامر. أدخل النص واضغط <kbd>Return</kbd> للبحث في مجلد المشروع المحلي الحالي. استخدم **Aa** لمراعاة حالة الأحرف، وافتح نتيجة للانتقال إلى السطر المطابق في المحرر.

يطابق بحث المحتوى النص حرفيًا، ويتجاوز الملفات الثنائية ومجلدات الاعتماديات والبناء الشائعة، ويتوقف عند 2,000 تطابق. يمكنك إيقاف بحث جارٍ مع الاحتفاظ بالنتائج، أو إغلاقه للعودة إلى الشجرة. لا تشمل عمليات البحث المحلية هذه مشاريع SSH.

## المحرر [#the-editor]

يمنحك فتح الملف محررًا فعليًا داخل لوحة، مع تمييز بنية الشيفرة.

| الإجراء | الاختصار |
| --- | --- |
| حفظ | <span dir="ltr"><kbd>Cmd</kbd>+<kbd>S</kbd></span> |
| بحث | <span dir="ltr"><kbd>Cmd</kbd>+<kbd>F</kbd></span> |
| بحث واستبدال | <span dir="ltr"><kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd></span> |
| البحث عن التالي | <span dir="ltr"><kbd>Cmd</kbd>+<kbd>G</kbd></span> |

تلتف الأسطر الطويلة إلى عرض اللوحة افتراضيًا. عطّل [`editor.wrap-lines`](/ar/docs/configuration#editorwrap-lines) للتمرير أفقيًا.

تحدّث إعادة تسمية ملف في الشجرة كل لوحة تفتحه، بما في ذلك الملفات داخل مجلد أُعيدت تسميته.

إذا عدّل برنامج آخر ملفًا مفتوحًا، يحدّث Zshell المعاينة التي لا تحتوي على تغييرات غير محفوظة عندما يصبح التطبيق نشطًا مجددًا. ولا يستبدل مطلقًا مخزن المحرر الذي يتضمن تعديلات غير محفوظة.

<Callout type="info">
هذا محرر للتغيير الذي تفحصه بالفعل: تصحيح خطأ مطبعي أو تعديل ثابت أو قراءة ملف أشار إليه عرض الفروق. لا يوجد خادم لغات أو إكمال تلقائي أو إعادة هيكلة على مستوى المشروع. هذا مقصود.
</Callout>

## معاينة Markdown [#markdown-preview]

افتح ملف `.md` لقراءة معاينته المنسقة في اللوحة نفسها. انقر **تعديل** في الزاوية العلوية اليمنى للعمل على المصدر، ثم **معاينة** لرؤية النتيجة. يتذكر Zshell الوضع المفضل لملفات Markdown الأخرى وللتشغيل التالي.

يحافظ تبديل الوضع على تعديلاتك وسجل التراجع. احفظ كالمعتاد باستخدام <span dir="ltr"><kbd>Cmd</kbd>+<kbd>S</kbd></span>. تفتح ملفات Markdown ذات الامتدادات الأخرى بوضع المصدر.

## الفروق [#diffs]

عرض الفروق المفتوح من [لوحة Git](/ar/docs/git) هو لوحة أخرى عادية، لذلك يمكن أن تجتمع الفروق والملف والطرفية جنبًا إلى جنب في علامة تبويب واحدة. يستخدم خط الطرفية، وتُفتح مجموعة تغييرات تضم ألف ملف بسرعة تغيير من سطر واحد. يمكن أيضًا تحويل فروق شجرة العمل الحالية غير المضافة إلى منطقة التجهيز من المراجعة إلى التعديل؛ أما الفروق المجهّزة والتاريخية فتبقى للقراءة فقط. راجع [قراءة الفروق](/ar/docs/git#reading-diffs).
