## โครงสร้างพื้นที่ทำงาน [#workspace-structure]

| องค์ประกอบ | หน้าที่ |
| --- | --- |
| โปรเจกต์ | โฟลเดอร์ในเครื่องหรือการเชื่อมต่อ SSH จัดเป็นกลุ่มในแถบด้านข้าง |
| เซสชัน | แท็บในโปรเจกต์ที่เปลี่ยนชื่อ สี ปักหมุด และจัดกลุ่มได้ |
| ช่อง | เทอร์มินัล เบราว์เซอร์ ตัวแก้ไข หรือมุมมอง diff ในแท็บ แบ่งช่องเพื่อทำงานเคียงกันได้ |

## คู่มือคุณสมบัติ [#feature-reference]

| คุณสมบัติ | หัวข้อ |
| --- | --- |
| [โปรเจกต์และเซสชัน](/th/docs/projects) | โครงการในเครื่อง / SSH แท็บ เทมเพลต สภาพแวดล้อมและการกู้คืน |
| [เซสชันร่วมและการเข้าถึงผ่านเบราว์เซอร์](/th/docs/remote-sessions) | เซสชัน SSH / Tailscale อัปโหลดระยะไกลและจับคู่เบราว์เซอร์กับ Mac นี้ |
| [ช่อง](/th/docs/panes) | การแบ่ง โฟกัส ขยาย และจัดวาง |
| [เทอร์มินัล](/th/docs/terminal) | Ghostty / Alacritty ประวัติคำสั่ง การเติมคำ ใบ้แป้นพิมพ์ โปรไฟล์และคิว |
| [เรียกใช้ด่วน](/th/docs/quick-launch) | คำสั่งที่บันทึก การเชื่อมต่อ SSH และกลุ่ม |
| [ช่องเบราว์เซอร์](/th/docs/browser) | หน้าเว็บพัฒนาในเครื่องและระยะไกล นำเข้าข้อมูล บล็อกโฆษณาและ WebExtensions |
| [แผง Git](/th/docs/git) | diff ตัดบรรทัด การจัดเตรียม คอมมิต worktree ตรวจทานแต่ละรอบของ Agent และ PR GitHub |
| [ไฟล์และตัวแก้ไข](/th/docs/files) | ค้นหาเนื้อหา นำเข้า Finder จัดการไฟล์ SSH ความขัดแย้งตอนบันทึกและกู้คืนร่าง |
| [โปรเซสและพอร์ต](/th/docs/session-info) | โปรเซสของเซสชัน พอร์ตที่รับการเชื่อมต่อ และการใช้ทรัพยากร |
| [การประสานงานเอเจนต์](/th/docs/automation) | ประสาน Agent กฎรู้จำ เหตุการณ์สด ประวัติและแยกบทสนทนาแบบเนทีฟ |
