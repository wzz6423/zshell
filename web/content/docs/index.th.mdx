## โครงสร้างพื้นที่ทำงาน [#workspace-structure]

| องค์ประกอบ | หน้าที่ |
| --- | --- |
| โปรเจกต์ | โฟลเดอร์ในเครื่องหรือการเชื่อมต่อ SSH จัดเป็นกลุ่มในแถบด้านข้าง |
| เซสชัน | แท็บในโปรเจกต์ที่เปลี่ยนชื่อ สี ปักหมุด และจัดกลุ่มได้ |
| ช่อง | เทอร์มินัล เบราว์เซอร์ ตัวแก้ไข หรือมุมมอง diff ในแท็บ แบ่งช่องเพื่อทำงานเคียงกันได้ |

## คู่มือคุณสมบัติ [#feature-reference]

| คุณสมบัติ | หัวข้อ |
| --- | --- |
| [โปรเจกต์และเซสชัน](/th/docs/projects) | โปรเจกต์ในเครื่อง / SSH แท็บ สภาพแวดล้อมเทอร์มินัล และการกู้คืน |
| [ช่อง](/th/docs/panes) | การแบ่ง โฟกัส ขยาย และจัดวาง |
| [เทอร์มินัล](/th/docs/terminal) | Ghostty / Alacritty ค้นหา การแจ้งเตือน คิวคำสั่ง และเทอร์มินัลด่วน |
| [เรียกใช้ด่วน](/th/docs/quick-launch) | คำสั่งที่บันทึก การเชื่อมต่อ SSH และกลุ่ม |
| [ช่องเบราว์เซอร์](/th/docs/browser) | เว็บไซต์และบริการในเครื่องข้างเทอร์มินัล |
| [แผง Git](/th/docs/git) | Diff การ stage, commit, branch, stash และ worktree |
| [ไฟล์และตัวแก้ไข](/th/docs/files) | ค้นหาไฟล์ แก้ไข พรีวิว Markdown และตัวแก้ไขภายนอก |
| [โปรเซสและพอร์ต](/th/docs/session-info) | โปรเซสของเซสชัน พอร์ตที่รับการเชื่อมต่อ และการใช้ทรัพยากร |
| [การประสานงานเอเจนต์](/th/docs/automation) | ประสานงานระหว่างช่อง สถานะเอเจนต์ และการใช้งานบัญชี |
