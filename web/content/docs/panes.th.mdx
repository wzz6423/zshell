---
title: "การแบ่งและช่อง"
description: "แบ่งแท็บเป็นช่อง ย้ายระหว่างช่อง ปรับขนาด และขยายช่องให้เต็มพื้นที่"
---

ทุกแท็บแบ่งเป็นหลายช่องได้ ช่องมักมีเทอร์มินัล แต่รองรับไฟล์ diff หรือ[เบราว์เซอร์](/th/docs/browser) ด้วย เพื่อให้สิ่งที่อ่านอยู่ข้าง shell ที่สร้างมัน

## การแบ่งช่อง [#splitting]

| การกระทำ | ปุ่มลัด |
| --- | --- |
| แบ่งไปขวา | <kbd>Cmd</kbd>+<kbd>D</kbd> |
| แบ่งลงล่าง | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> |
| แบ่งไปซ้าย | — |
| แบ่งขึ้นบน | — |

การแบ่งซ้ายและบนไม่มีปุ่มลัดเริ่มต้น ใช้เมนู **แท็บ** จานคำสั่ง (<kbd>Cmd</kbd>+<kbd>P</kbd>) หรือเมนูคลิกขวาของช่อง ช่องใหม่รับไดเรกทอรีทำงานจากช่องที่มีโฟกัส

การแบ่งกระทำกับ **ช่องที่มีโฟกัส** เสมอ แม้อยู่ในเค้าโครงซ้อน ไม่ปรับขนาดช่องข้างเคียงที่ไม่เกี่ยวข้อง แต่ละช่องมีชื่อขนาดเล็กที่อัปเดตสดและปุ่มแบ่งในส่วนหัว เพื่อให้เห็นบริบทของช่องนั้น

จัดช่องที่เปิดอยู่ใหม่ได้โดยจับแถบบางด้านบนแล้วลากไปยังขอบช่องอื่น ช่องปลายทางแสดงครึ่งพื้นที่ที่จะวางก่อนปล่อย

เปลี่ยนทั้งแท็บให้เป็นช่องก็ได้ ลากแท็บจากแถบบนไปขอบซ้าย ขวา บน หรือล่างของเนื้อหาแท็บปัจจุบัน ภาพตัวอย่างแสดงผลการแบ่งก่อนปล่อย

## ย้ายระหว่างช่อง [#moving-between-panes]

| การกระทำ | ปุ่มลัด |
| --- | --- |
| โฟกัสช่องซ้าย / ขวา / บน / ล่าง | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+ปุ่มลูกศร |
| วนโฟกัสย้อนกลับ / ถัดไป | <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> |

## ขยายและปรับขนาด [#zoom-and-resize]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> ขยายช่องที่มีโฟกัสให้เต็มแท็บ กดอีกครั้งคืนขนาด ขณะขยายมีปุ่มบนหัวแท็บ จึงกลับได้โดยไม่ต้องใช้ปุ่มลัด

| การกระทำ | ปุ่มลัด |
| --- | --- |
| เปิด/ปิดการขยายช่อง | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> |
| ขยายช่องไปทิศหนึ่ง | <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+ปุ่มลูกศร |
| ทำทุกช่องให้เท่ากัน | <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> |

เส้นแบ่งระหว่างช่องลากได้เช่นกัน

## ปิดช่อง [#closing]

<kbd>Cmd</kbd>+<kbd>W</kbd> ปิดช่องที่มีโฟกัส การปิดช่องสุดท้ายในแท็บปิดแท็บด้วย

<Callout type="warn">
การปิดช่องเทอร์มินัลยุติ shell และทุกอย่างที่มันเริ่ม Zshell ไม่ถามก่อน เหมือนปิดเทอร์มินัลในแอปอื่น
</Callout>
