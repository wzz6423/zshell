---
title: "Phím tắt"
description: "Mọi phím tắt mặc định của Zshell, nhóm theo tác dụng."
---

Quên phím tắt? <kbd>Cmd</kbd>+<kbd>P</kbd> mở bảng lệnh và hiển thị phím tắt bên cạnh từng lệnh.

## Terminal nhanh toàn cục [#global-quick-terminal]

| Phím tắt | Thao tác |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>I</kbd> | Hiện / đóng Terminal nhanh |
| <kbd>Esc</kbd> | Đóng Terminal nhanh và kết thúc shell |

Ghi phím tắt khác ở **Cài đặt → Terminal → Terminal nhanh**. Terminal không ghim cũng đóng khi mất tiêu điểm. Xem [Terminal nhanh](/vi/docs/terminal#global-quick-terminal).

## Dự án và phiên [#projects-and-sessions]

| Phím tắt | Thao tác |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>N</kbd> | Dự án mới |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | Phiên mới |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | Cửa sổ mới |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | Đóng ô có tiêu điểm |
| <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Chuyển tới dự án 1–9 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Dự án sau / trước |
| <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | Chuyển tới tab 1–9 |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Bộ chọn tab theo lần dùng gần nhất |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Tab sau / trước |

## Các ô [#panes]

| Phím tắt | Thao tác |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Chia phải |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Chia xuống |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+phím mũi tên | Chọn ô theo hướng đó |
| <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> | Chuyển vòng tiêu điểm ô |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> | Bật/tắt phóng lớn ô |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+phím mũi tên | Đổi kích thước ô có tiêu điểm |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> | Chia đều các ô |

Chia trái và lên không có phím mặc định; dùng menu **Tab**, menu ngữ cảnh của ô hoặc bảng lệnh.

## Các bảng [#panels]

| Phím tắt | Thao tác |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>P</kbd> | Bảng lệnh |
| <kbd>Cmd</kbd>+<kbd>O</kbd> | Khởi chạy nhanh |
| <kbd>Cmd</kbd>+<kbd>B</kbd> | Bật/tắt thanh bên trái |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | Bật/tắt thanh bên phải |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Bảng Git |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Bảng Tệp |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | Bảng Thông tin |

## Trình duyệt và tác nhân [#browser-and-agents]

| Phím tắt | Thao tác |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>L</kbd> | Chọn thanh địa chỉ trình duyệt hiện tại |
| <kbd>Cmd</kbd>+<kbd>R</kbd> | Tải lại trang trình duyệt hiện tại |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Chuyển tới tác nhân tiếp theo cần chú ý |

Tab và ô trình duyệt mới không có phím tắt mặc định; dùng menu **Tệp** hoặc bảng lệnh.

## Văn bản và tìm kiếm [#text-and-search]

| Phím tắt | Thao tác |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>F</kbd> | Tìm trong ô có tiêu điểm |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> | Tìm và thay thế (trình soạn thảo) |
| <kbd>Cmd</kbd>+<kbd>G</kbd> | Tìm tiếp |
| <kbd>Shift</kbd>+<kbd>Return</kbd> | Tìm trước, khi ở thanh tìm kiếm |
| <kbd>Cmd</kbd>+<kbd>E</kbd> | Dùng phần chọn để tìm |
| <kbd>Cmd</kbd>+<kbd>K</kbd> | Xóa màn hình terminal |
| <kbd>Cmd</kbd>+<kbd>S</kbd> | Lưu tệp đang mở |
| <kbd>Cmd</kbd>+<kbd>,</kbd> | Cài đặt |

## Tìm trước [#find-previous]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> thường là Tìm trước trên macOS, nhưng ở Zshell nó bật/tắt bảng Git. Dùng <kbd>Shift</kbd>+<kbd>Return</kbd> trong thanh tìm kiếm; mục menu **Sửa → Tìm** cũng hoạt động.
