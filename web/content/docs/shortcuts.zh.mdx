---
title: 键盘快捷键
description: Zshell 的全部默认快捷键，按用途分组。
---

忘了某个？<kbd>Cmd</kbd>+<kbd>P</kbd> 打开命令面板，每条命令旁边都标着它的快捷键。

<span id="全局快捷终端" data-canonical-heading="global-quick-terminal" />

## 全局快捷终端 [#global-quick-terminal]

| 快捷键 | 操作 |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>I</kbd> | 显示 / 关闭快捷终端 |
| <kbd>Esc</kbd> | 关闭快捷终端并终止其中的 shell |

可在 **设置 → 终端 → Quick Terminal** 录制其他组合键。未固定时，失去焦点也会关闭；详见[快捷终端](/docs/terminal#global-quick-terminal)。

<span id="项目与会话" data-canonical-heading="projects-and-sessions" />

## 项目与会话 [#projects-and-sessions]

| 快捷键 | 操作 |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>N</kbd> | 新建项目 |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | 新建会话 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | 新建窗口 |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | 关闭当前窗格 |
| <kbd>Cmd</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | 切到第 1–9 个项目 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | 下一个 / 上一个项目 |
| <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | 切到第 1–9 个标签页 |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | 标签页切换器，按最近使用排序 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | 下一个 / 上一个标签页 |

<span id="窗格" data-canonical-heading="panes" />

## 窗格 [#panes]

| 快捷键 | 操作 |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | 向右分屏 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | 向下分屏 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+方向键 | 聚焦该方向的窗格 |
| <kbd>Cmd</kbd>+<kbd>[</kbd> / <kbd>Cmd</kbd>+<kbd>]</kbd> | 循环切换窗格焦点 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Return</kbd> | 切换窗格放大 |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+方向键 | 调整当前窗格大小 |
| <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>=</kbd> | 让所有窗格等分 |

向左分屏和向上分屏没有默认快捷键——用 **Tabs** 菜单、窗格右键菜单或命令面板。

<span id="面板" data-canonical-heading="panels" />

## 面板 [#panels]

| 快捷键 | 操作 |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>P</kbd> | 命令面板 |
| <kbd>Cmd</kbd>+<kbd>O</kbd> | 快速启动 |
| <kbd>Cmd</kbd>+<kbd>B</kbd> | 切换左侧边栏 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | 切换右侧边栏 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Git 面板 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | 文件面板 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | 信息面板 |

<span id="浏览器与-agent" data-canonical-heading="browser-and-agents" />

## 浏览器与 Agent [#browser-and-agents]

| 快捷键 | 操作 |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>L</kbd> | 聚焦当前浏览器的地址栏 |
| <kbd>Cmd</kbd>+<kbd>R</kbd> | 重新加载当前浏览器页面 |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | 跳到下一个需要注意的 agent |

新建浏览器标签页和窗格没有默认快捷键，请使用 **File** 菜单或命令面板。

<span id="文本与搜索" data-canonical-heading="text-and-search" />

## 文本与搜索 [#text-and-search]

| 快捷键 | 操作 |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>F</kbd> | 在当前窗格里查找 |
| <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> | 查找并替换（编辑器） |
| <kbd>Cmd</kbd>+<kbd>G</kbd> | 查找下一个 |
| <kbd>Shift</kbd>+<kbd>Return</kbd> | 查找上一个（在查找栏内按） |
| <kbd>Cmd</kbd>+<kbd>E</kbd> | 用选中内容查找 |
| <kbd>Cmd</kbd>+<kbd>K</kbd> | 清空终端 |
| <kbd>Cmd</kbd>+<kbd>S</kbd> | 保存当前文件 |
| <kbd>Cmd</kbd>+<kbd>,</kbd> | 设置 |

<span id="查找上一个" data-canonical-heading="find-previous" />

## 查找上一个 [#find-previous]

<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> 在 macOS 上通常是「查找上一个」，但在 Zshell 里它用来切换 git 面板。请在查找栏里按 <kbd>Shift</kbd>+<kbd>Return</kbd>，或者用
**Edit → Find** 菜单里的那一项。
