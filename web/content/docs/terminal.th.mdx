ทุกช่องเทอร์มินัลรัน login shell จริงของคุณและใช้หนึ่งในสอง backend แบบ native ที่เร่งด้วย GPU Zshell ดูแลพฤติกรรมรอบข้าง ทั้งโฟกัส ค้นหา การแจ้งเตือน ลิงก์ ประวัติ ธีม และการวางอย่างปลอดภัย จึงสม่ำเสมอไม่ว่าจะเลือก emulator ใด

## Backend เทอร์มินัล [#terminal-backends]

เลือกที่ **การตั้งค่า → เทอร์มินัล → Backend**:

| Backend | หมายเหตุ |
| --- | --- |
| **Ghostty** | ค่าเริ่มต้น |
| **Alacritty** | โดยทั่วไปใช้หน่วยความจำน้อยกว่า |

ทั้งสองรองรับการเร่ง GPU เรนเดอร์รูป ชุดธีมร่วมของ Zshell ค้นหา รายงานเมาส์ การแจ้งเตือน และรายงานความคืบหน้า การเปลี่ยน backend มีผลเฉพาะเทอร์มินัลใหม่ ช่องเดิมคง emulator ที่เริ่มไว้

## Shell ของคุณเหมือนเดิม [#your-shell-unchanged]

แต่ละเซสชันเริ่ม login shell ของบัญชี พรอมป์ alias ฟังก์ชัน และ dotfile จึงโหลดเหมือนในเทอร์มินัลอื่น Zshell เพิ่มตัวแปรความสามารถและตัวตน:

| ตัวแปร | ค่า |
| --- | --- |
| `TERM_PROGRAM` | `ghostty` |
| `TERM_PROGRAM_VERSION` | รุ่นความสามารถ Ghostty ที่ Zshell รองรับ |
| `ZSHELL_TERM` | `ghostty` หรือ `alacritty` ตาม backend จริงของช่อง |

ทั้งสองประกาศ Ghostty ผ่าน `TERM_PROGRAM` เพราะ CLI ที่รองรับรูปและการแจ้งเตือนใช้เป็นสัญญาณความสามารถ ใช้ `ZSHELL_TERM` เฉพาะเมื่อต้องแยกตัวเรนเดอร์จริง ๆ

<Callout type="info">
Zshell ไม่อ่าน `~/.config/ghostty` หรือการตั้งค่า Alacritty ฟอนต์ สี พฤติกรรมอินพุต และ backend กำหนดใน[การตั้งค่า](/th/docs/configuration) ของ Zshell เอง
</Callout>

## ค้นหา [#search]

| การกระทำ | ปุ่มลัด |
| --- | --- |
| ค้นหา | <kbd>Cmd</kbd>+<kbd>F</kbd> |
| ค้นหาถัดไป | <kbd>Cmd</kbd>+<kbd>G</kbd> |
| ค้นหาก่อนหน้า | <kbd>Shift</kbd>+<kbd>Return</kbd> ในแถบค้นหา |
| ใช้ข้อความที่เลือกค้นหา | <kbd>Cmd</kbd>+<kbd>E</kbd> |
| ล้างเทอร์มินัล | <kbd>Cmd</kbd>+<kbd>K</kbd> |

ค้นหาทำงานกับช่องเทอร์มินัลหรือตัวแก้ไขที่มีโฟกัส และยังทำงานเมื่อช่องค้นหาถือโฟกัสแป้นพิมพ์

## แก้ไขพรอมป์ [#prompt-editing]

คลิกในพรอมป์ shell ที่ทำงานเพื่อย้ายเคอร์เซอร์แล้วพิมพ์ต่อที่ตำแหน่งนั้น ใน zsh ลากบนอินพุตเพื่อเลือกช่วง พิมพ์จะแทนที่ส่วนเลือก ส่วน Backspace หรือ Delete จะลบ ดับเบิล/ทริปเปิลคลิกยังเลือกข้อความเทอร์มินัล โปรแกรมที่เปิดรายงานเมาส์ เช่น TUI เต็มจอ ยังรับเหตุการณ์เมาส์ของตนเอง

หาก shell ซ้อนหรือ shell ที่มาแทนยังไม่โหลดส่วนสนับสนุนแก้พรอมป์ของ Zshell การลากยังเลือกข้อความเพื่อคัดลอกแต่ไม่แก้อินพุต เมื่อออกกลับพรอมป์เดิมจะกลับมาแก้ส่วนเลือกได้

กล่องอินพุตมาตรฐานของ Claude Code รองรับคลิกวางเคอร์เซอร์และลากแก้ไขบนทั้งสอง backend รวมร่างที่ตัดบรรทัดและหลายบรรทัด พิมพ์หรือวางเพื่อแทนส่วนเลือก กด Backspace/Delete เพื่อลบ โหมด normal/visual ของ Vim กล่องโต้ตอบ ตัวยึดตำแหน่งไฟล์แนบหรือข้อความวางที่ยุบ และข้อความสนทนาที่เลื่อนไปแล้วคงพฤติกรรมเลือกข้อความเทอร์มินัลเดิม แอปที่จับเมาส์ยังดูแลอินพุตของตน

เสียงป้อนเข้าจาก Zisla ใช้การวางของเทอร์มินัล ใน Claude Code ยังแทนที่ช่วงอินพุตที่เลือกได้ และรองรับการพูดวลีซ้ำโดยตั้งใจ

## ปุ่มลัดแอปเบื้องหน้า [#foreground-application-shortcuts]

หากปุ่มลัดโปรแกรมเทอร์มินัลชนกับ Zshell คลิกขวาช่องแล้วเปิด **บล็อกคำสั่ง Zshell** ปุ่มที่มี modifier รวม <kbd>Ctrl</kbd>+<kbd>Return</kbd> จะไปแอปเบื้องหน้าขณะช่องถือโฟกัสแป้นพิมพ์ คัดลอก วาง และเลือกทั้งหมดยังใช้ได้

ค่านี้ใช้เฉพาะช่องนั้น คลิกขวาเอาเครื่องหมายออกเพื่อคืนปุ่ม Zshell หากแอปจับเมาส์ กด <kbd>Shift</kbd> ค้างขณะคลิกขวาเพื่อเปิดเมนู Zshell

## คิวคำสั่ง [#prompt-queue]

โฟกัสเทอร์มินัลแล้ว <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> หรือเลือก **เปิด/ปิดคิวคำสั่ง** ในจานคำสั่ง แถบเปิดใต้เทอร์มินัลนั้น พิมพ์รายการแล้ว <kbd>Return</kbd> หรือ **เพิ่มเข้าคิว** แต่ละรายการเป็นบรรทัดเดียว การขึ้นบรรทัดใหม่ที่วางถูกแทนด้วยช่องว่าง

เมื่อ zsh เดิมกลับสู่พรอมป์ว่าง Zshell ส่งรายการถัดไปแล้ว Return รายการรันตามลำดับ การส่งอัตโนมัติรอขณะเอเจนต์หรือโปรแกรมเบื้องหน้าครองเทอร์มินัล หรือพรอมป์มีร่างอินพุต ต้องใช้การผสาน zsh ของ Zshell ส่วน shell อื่นและ shell ซ้อนส่งเองได้

แต่ละรายการมี **ส่งเดี๋ยวนี้** และ **ลบ** ปุ่ม **ส่งเดี๋ยวนี้** ส่งข้อความและ Return ให้โปรแกรมปัจจุบันทันทีโดยไม่รอพรอมป์ <kbd>Esc</kbd> หรือปุ่มปิดซ่อนแถบแต่เก็บคิว ทุกเทอร์มินัลมีคิวของตนเอง การปิดเซสชันหรือออก Zshell ทิ้งคิวนั้น

## เส้นทางและ URL [#paths-and-urls]

Zshell รู้จัก URL เว็บและเส้นทางไฟล์ในเครื่องที่มีอยู่ซึ่งโปรแกรมพิมพ์ออกมา เส้นทางอาจเต็ม สัมพัทธ์ `~/`, `./`, `../` หรือเทียบกับไดเรกทอรีทำงานสดของช่อง ส่วนท้ายข้อมูลวินิจฉัย เช่น `:42` หรือ `:42:7` ไม่ขัดขวางการหาไฟล์

- **Command-คลิก** เส้นทางเพื่อแสดงใน Finder หรือ URL เพื่อเปิดในเบราว์เซอร์เริ่มต้น
- **Command-คลิกขวา** เส้นทางเพื่อ **แท็บไฟล์ใหม่** / **ช่องไฟล์ใหม่** หรือ URL เพื่อ **แท็บเบราว์เซอร์ใหม่** / **ช่องเบราว์เซอร์ใหม่**
- โปรแกรมเต็มจอที่เปิดรายงานเมาส์รับคลิกขวาที่ไม่มี modifier หากต้องการเมนูเทอร์มินัลและช่องของ Zshell ให้กด **Shift** ขณะคลิกขวา

เอาต์พุต compiler และบทสนทนาเอเจนต์จึงเชื่อมกลับสู่โปรเจกต์เดียวกันได้โดยตรง พฤติกรรมเบราว์เซอร์อยู่ที่[ช่องเบราว์เซอร์](/th/docs/browser)

## การแจ้งเตือน [#notifications]

Zshell ส่งสองเหตุการณ์ไปศูนย์การแจ้งเตือน:

- เสียง bell จากเซสชันที่ไม่ได้โฟกัส
- คำขอ `OSC 777;notify` จากโปรแกรม เช่น build ที่นานหรือเอเจนต์เขียนโค้ด

การแจ้งเตือนเล่นเสียงระบบได้ คลิกแล้วเปิดใช้ Zshell และไปเซสชันที่ส่งโดยตรง macOS ขอสิทธิ์เมื่อเทอร์มินัลพยายามแจ้งครั้งแรก ไม่ใช่ตอนเปิด Zshell

### คำสั่งเสร็จสิ้น [#command-completion]

เปิด **การตั้งค่า → เทอร์มินัล → การแจ้งเตือนคำสั่ง** เพื่อให้แจ้งเมื่อคำสั่งจบ:

- **คำสั่งที่ทำงานนาน**: เลือก 5, 10, 30 หรือ 60 วินาที คำสั่งที่รันอย่างน้อยเท่านี้แจ้งเมื่อเสร็จ ค่าเริ่มต้น **ปิด**
- **คำสั่งล้มเหลว**: แจ้งเมื่อ exit status ไม่ใช่ศูนย์ไม่ว่ารันนานเท่าใด ค่าเริ่มต้นปิดเช่นกันและเปิดแยกได้

ค่าใช้กับเทอร์มินัล zsh ที่สร้างหลังเปลี่ยน บนทั้งสอง backend ใช้เหตุการณ์จบคำสั่งของ shell เดิม คำสั่งใน shell ซ้อนหรือโปรแกรมโต้ตอบไม่รายงานการจบแต่ละครั้งผ่านการผสานนี้

บันทึกค่าเดียวกันใน `~/.config/zshell/config.toml` ได้:

```toml
terminal.notify-finish-seconds = 30
terminal.notify-on-error = true
```

ตั้ง `terminal.notify-finish-seconds` เป็น `0` เพื่อปิดการแจ้งตามระยะเวลา การส่งแจ้งเตือนเป็นไปตามการตั้งค่า macOS

## รายงานความคืบหน้า [#progress-reports]

โปรแกรมที่ส่งความคืบหน้า `OSC 9;4` มีแถบบางเหนือเทอร์มินัล พร้อมสถานะปกติ หยุดชั่วคราว และผิดพลาดที่แยกชัด ไม่ต้องเปิดอะไร หากโปรแกรมรายงาน ช่องก็แสดง

## คลิปบอร์ด การวางไฟล์ และความปลอดภัยการวาง [#clipboard-drops-and-paste-safety]

- **ยืนยันก่อนอ่านคลิปบอร์ด** `OSC 52` ขอคลิปบอร์ด macOS ได้ รวมจากโฮสต์ SSH ระยะไกล Zshell ถามก่อนส่งคืน
- **ระบุการวางที่เสี่ยง** ข้อความหลายบรรทัดหรือคล้ายคำสั่งต้องยืนยันก่อน ไม่ถูกส่งทันที
- **ไฟล์เป็นเส้นทางที่ปลอดภัยกับ shell** ไฟล์คัดลอกหรือลากจาก Finder แทรกเป็นเส้นทางเต็มใส่เครื่องหมายคำพูด รูปในคลิปบอร์ดยังส่งถึง TUI ที่รองรับรูปได้

## อินพุตปุ่ม Option [#option-key-input]

ค่าเริ่มต้นให้ Option อยู่กับแหล่งอินพุต macOS ที่ใช้งาน เพื่อให้เค้าโครงอย่าง Polish Pro พิมพ์อักขระผสมได้ เปิด **ใช้ Option เป็น Alt/Meta** ในการตั้งค่าเมื่อต้องการส่งชุดปุ่ม Option ให้โปรแกรมเป็นปุ่มลัด Meta ดู [`terminal.macos-option-as-alt`](/th/docs/configuration#terminalmacos-option-as-alt)

## คำสั่ง `zshell` [#the-zshell-command]

ทุกเทอร์มินัล Zshell มี CLI ที่รู้จักโปรเจกต์:

```sh
zshell                         # สร้างโปรเจ็กต์ในไดเรกทอรีปัจจุบัน
zshell vim ~/src/app.swift     # สร้างโปรเจ็กต์และเรียกใช้ argv นี้ในเทอร์มินัลแรก
zshell +themes                 # เรียกดูและดูตัวอย่างธีมแบบโต้ตอบ
zshell +themes --list --dark   # แสดงชื่อธีมโดยไม่เปิดตัวเลือกธีม
zshell +help                   # แสดงกลุ่มคำสั่งทั้งหมด
```

ตัวเลือกธีมพรีวิวทุกการเลือกทั่วแอป Return บันทึก และ Escape คืนธีมก่อนหน้า

## ฟอนต์ [#fonts]

Zshell มี JetBrains Mono และสัญลักษณ์ Nerd Font ฟอนต์ monospace ที่ติดตั้งเปลี่ยนฟอนต์ Latin ได้ และฟอนต์ CJK ที่ติดตั้งเพิ่มไว้ก่อนฟอนต์สัญลักษณ์และระบบสำรองได้ ดู [`font-family`](/th/docs/configuration#font-family), [`terminal.font-fallback-family`](/th/docs/configuration#terminalfont-fallback-family), [`font-size`](/th/docs/configuration#font-size), [`terminal.font-thicken`](/th/docs/configuration#terminalfont-thicken) และ [`terminal.line-height`](/th/docs/configuration#terminalline-height)

## เทอร์มินัลด่วนส่วนกลาง [#global-quick-terminal]

ขณะ Zshell ทำงาน กด <kbd>Cmd</kbd>+<kbd>I</kbd> เพื่อเปิดเทอร์มินัลอิสระเหนือแอปอื่น กดอีกครั้งปิด มี shell ชั่วคราวนอกแท็บโปรเจกต์ ปรับขนาด ความทึบ และปุ่มลัดที่ **การตั้งค่า → เทอร์มินัล → เทอร์มินัลด่วน**

- ปักหมุดหน้าต่างเพื่อให้เปิดค้างเมื่อสลับแอป
- หน้าต่างไม่ปักหมุดปิดเมื่อเสียโฟกัสหรือคลิกนอกหน้าต่าง
- เมื่อ **บล็อกคำสั่ง Zshell** ปิด <kbd>Esc</kbd> หรือปุ่มลัดส่วนกลางปิดหน้าต่างและยุติ shell กับงานที่รัน การเปิดอีกครั้งเริ่มเซสชันใหม่

ใช้เทอร์มินัลโปรเจกต์กับบริการระยะยาว [เรียกใช้ด่วน](/th/docs/quick-launch) ซึ่งบันทึกและรันคำสั่ง เป็นคนละคุณสมบัติ

## คำแนะนำคำสั่ง Vim [#vim-command-hints]

เปิด **การตั้งค่า → เทอร์มินัล → พฤติกรรม → คำแนะนำคำสั่ง Vim** แล้วเปิดแท็บ **ข้อมูล** ด้านขวา ส่วน **คำสั่ง VIM** ปรากฏใต้ข้อมูลเซสชันเมื่อ Vim, Vi หรือ Neovim ทำงาน ค่าเริ่มต้นปิดและมีผลทันทีต่อเทอร์มินัลเดิมบนทั้งสอง backend

รายการคำสั่งทั่วไปครบถ้วนยังอยู่เสมอ เปลี่ยนเฉพาะลำดับความสำคัญ Normal วาง `:w`, `:q`, `yy`, `p`/`P` ก่อน Visual Block วาง `I`/`A` การแก้บล็อกและเคลื่อนมุมก่อน ส่วน Insert, Replace, Visual, Visual Line, Select, บรรทัดคำสั่ง และค้นหามีลำดับของตน ทุกคำสั่งระบุโหมดที่ใช้ ค้นด้วยปุ่ม คำอธิบาย หรือชื่อโหมดได้ คำอธิบายและ UI ค้นหาตามหนึ่งใน 17 ภาษาของแอป ล้างคำค้นเพื่อคืนรายการเต็ม คำแนะนำมีไว้ดูอ้างอิง ไม่ส่งอินพุตเข้าตัวแก้ไข

ตัวแก้ไขในเครื่องตรวจจาก executable เบื้องหน้า ภายใน SSH, Mosh หรือ terminal multiplexer ตรวจด้วยบรรทัดโหมด/สถานะ Vim ที่เห็นและเค้าโครงหน้าจอโดยไม่ติดตั้งปลั๊กอินระยะไกล เปิด `showmode` หรือแถบสถานะที่จำแนกได้ไว้ การตั้งค่าที่ซ่อนหรือเปลี่ยนป้ายโหมดอาจกลับไปคำแนะนำ Normal หรือทำให้ตรวจระยะไกลไม่ได้ การ map ปุ่มเองไม่ถูกตีความ เก็บตัวอย่างเฉพาะแผงข้อมูลที่ใช้งาน คำแนะนำหายเมื่อโปรแกรมเบื้องหน้าเปลี่ยนหรือจำแนกตัวแก้ไขไม่ได้แล้ว

เปิดในไฟล์ตั้งค่าด้วย `terminal.vim-command-hints = true` ได้เช่นกัน
