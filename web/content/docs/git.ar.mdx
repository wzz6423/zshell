اضغط <span dir="ltr"><kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd></span>. تُفتح اللوحة على المستودع المرتبط بمشروعك؛ يوضح قسم [مجلد المشروع](/ar/docs/projects#the-project-directory) كيف يختاره Zshell.

كل إجراء هنا هو أمر Git ينفذه Zshell نيابةً عنك، وتظهر مخرجاته عندما توجد معلومات أكثر من مجرد «اكتمل». لا تُعاد كتابة الالتزامات أو دمجها باستخدام squash أو دفعها قسريًا إلا إذا طلبت ذلك.

## شريط أدوات Git [#the-git-toolbar]

يمكن لـ Zshell عرض شريط أدوات صغير أسفل علامة التبويب النشطة. داخل المستودع، يعرض الفرع الحالي وإجمالي الأسطر المضافة والمحذوفة؛ وتظهر حالة **نظيف** باللون الأخضر إن لم تكن هناك تغييرات. تُحتسب الملفات غير المتتبعة ضمن الأسطر المضافة.

- انقر الفرع للبحث بين الفروع المحلية والتبديل إليها. يُميّز الفرع الافتراضي للمستودع في القائمة.
- انقر أعداد التغييرات لفتح لوحة Git.
- خارج المستودع، يُبقي وضع **إظهار دائمًا** زر **لا يوجد مستودع Git** لفتح حالة تهيئة المستودع في اللوحة.

اختر **إخفاء** أو **تلقائي** أو **إظهار دائمًا** في **الإعدادات ← عام**، أو اضبط [`toolbar.visibility`](/ar/docs/configuration#toolbarvisibility). الإعداد الافتراضي هو الإخفاء. يمكنك أيضًا إخفاء الشريط المرئي من قائمته السياقية.

## الملفات المعدلة [#changed-files]

تُجمع الملفات ضمن التعارضات والتغييرات المجهّزة وغير المجهّزة. مرّر المؤشر على صف لإظهار أزراره، أو استخدم القائمة السياقية:

| الزر | الوظيفة |
| --- | --- |
| **+** | إضافة الملف إلى منطقة التجهيز |
| **−** | إزالة الملف من منطقة التجهيز |
| **↺** | تجاهل تعديلاته |

يوجد **تجاهل جميع التغييرات** في رأس اللوحة ويطلب تأكيدًا أولًا؛ فهو الإجراء هنا الذي لا يمكن التراجع عنه بأمر Git آخر.

تعرض الملفات المتعارضة **وضع علامة محلول (إضافة إلى التجهيز)** بدل زر التجهيز العادي، لتكون تسوية التعارض خطوة مقصودة.

يُصفّي زر القمع في الرأس القائمة حسب اسم الملف، وهي أسرع طريقة للتنقل في مجموعة تغييرات كبيرة.

## قراءة الفروق [#reading-diffs]

انقر أي ملف معدل لفتح فروقه في لوحة بجانب الطرفية، لا فوقها. تتيح القائمة السياقية أيضًا **فتح الملف** لفتح الملف نفسه بشكل قابل للتعديل، أو **فتح الملف بجانب اللوحة**.

تبقى الفروق الكبيرة سريعة الاستجابة. تُفتح مجموعة من ألف ملف بسرعة تغيير من سطر واحد، ويظل التمرير سلسًا.

تتذكر عناصر التحكم أعلى عرض الفروق خيارين على مستوى التطبيق:

- **موحّد / مقسّم** للتبديل بين عمود واحد وعرض جنبًا إلى جنب.
- يظهر **مراجعة / تعديل** للملف غير المجهّز في شجرة العمل الحالية. عدّل الجانب الجديد مباشرة واحفظ باستخدام <span dir="ltr"><kbd>Cmd</kbd>+<kbd>S</kbd></span>؛ وتُعالج محاولة إغلاق ملف معدل كما في المحرر العادي.

تبقى الفروق المجهّزة وفروق الالتزامات التاريخية للقراءة فقط، لأنها لقطات وليست ملفات يمكن لـ Zshell كتابتها بأمان. يؤدي تحويل أحد العروض إلى تعديل أو مقسّم إلى تحديث تفضيل العروض المفتوحة الأخرى، دون جعل عرض غير مؤهل قابلًا للتعديل.

## إنشاء الالتزامات [#committing]

اكتب رسالة واستخدم زر الالتزام، أو اختر من قائمته:

- **التزام التغييرات المجهّزة** — تضمين ما جهّزته بالضبط؛
- **تجهيز الكل وإنشاء التزام** — تجهيز كل الملفات المتتبعة ثم الالتزام بها؛
- **تعديل الالتزام الأخير** — ضم التغييرات المجهّزة إلى الالتزام السابق؛
- **تجهيز الكل وتعديل الالتزام الأخير**.

تظهر الالتزامات الحديثة أدناه، مع **نسخ معرّف الالتزام** و**نسخ رسالة الالتزام** في قوائمها السياقية.

## الفروع [#branches]

اسم الفرع في الرأس هو قائمة؛ اختر فرعًا آخر للتبديل إليه، أو **إنشاء فرع جديد…** لبدء فرع من موقعك الحالي.

## أشجار العمل [#worktrees]

تعرض لوحة Git كل أشجار العمل التابعة للمستودع مع الفرع ومسار نسخة العمل. تُميّز النسخة النشطة بكلمة **الحالي**. انقر شجرة عمل لفتح علامة تبويب طرفية جديدة في ذلك المجلد، بحيث تحتفظ كل نسخة بسياق صدفتها وتبقى ضمن المشروع نفسه. تُمرّر قوائم أشجار العمل الطويلة داخل مساحة محددة، بينما يبقى رأس القسم وعناصر الالتزام وقائمة الملفات المعدلة في مكانها. انقر رأس أشجار العمل لطي القسم أو توسيعه.

تعرض أشجار العمل ذات HEAD المنفصل عبارة **Detached HEAD** بدل اسم الفرع. وتُدرج المستودعات المجردة للاستكمال، لكنها لا تملك مجلد عمل ولا يمكن فتحها في علامة تبويب طرفية.

## المستودعات البعيدة [#remotes]

تضم قائمة **⋯** كل الإجراءات التي تتواصل مع مستودع بعيد:

| الإجراء | الوظيفة |
| --- | --- |
| **جلب** | تحديث مراجع التتبع البعيدة |
| **سحب (تقديم سريع فقط)** | السحب مع رفض إنشاء التزام دمج |
| **دفع** | دفع الفرع الحالي |
| **نشر الفرع** | دفع فرع لا يملك upstream بعد، مع اختيار المستودع البعيد إن تعددت الخيارات |
| **مزامنة التغييرات** | سحب بتقديم سريع ثم دفع |
| **تخزين كل التغييرات مؤقتًا** | حفظ كل شيء في stash، بما في ذلك الملفات غير المتتبعة |
| **استعادة آخر stash وإزالته** | استعادة أحدث تخزين مؤقت |

توضح الشارات بجانب الفرع عدد الالتزامات **↓ المتأخرة** و<strong>↑ المتقدمة</strong> مقارنةً بفرع التتبع.

تحتوي القائمة نفسها على **نسخ المسارات المعدلة** و**نسخ مسار المستودع** و**إظهار المستودع في Finder**.

<Callout type="info">
السحب مقصور على التقديم السريع عمدًا. إذا كان الدمج أو إعادة التأسيس ضروريًا، يوضح Git ذلك وتقرر أنت في الطرفية؛ لا تختار اللوحة استراتيجيةً نيابةً عنك.
</Callout>

## ليس مستودعًا بعد [#not-a-repository-yet]

إذا لم يحتوِ مجلد المشروع على مستودع، تعرض اللوحة **تهيئة مستودع** لتنفيذ `git init` في ذلك المجلد. وإلى حينها تبقى بعيدة عن طريقك.
