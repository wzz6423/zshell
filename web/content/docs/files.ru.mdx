Нажмите <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd>, чтобы открыть дерево файлов. Как и панель Git, оно привязано к [каталогу проекта](/ru/docs/projects#the-project-directory), поэтому его корень не меняется при каждом `cd`.

## Дерево файлов [#the-tree]

Когда панель файлов видна и Zshell активен, локальные каталоги обновляются в фоновом режиме. В SSH-проектах Zshell периодически перечитывает удалённый корневой каталог и раскрытые папки.

Нажмите на файл, чтобы открыть его в активной панели. Остальные действия доступны по правой кнопке:

| Пункт | Действие |
| --- | --- |
| **Открыть** / **Открыть сбоку** | Открыть в текущей панели или в новой разделённой панели |
| **Открыть в приложении по умолчанию** | Передать файл приложению, назначенному для него в macOS |
| **Показать в Finder** | |
| **Копировать путь** | Скопировать абсолютный путь |
| **Перейти сюда через cd** | Выполнить `cd <folder>` в активном терминале |
| **Новый файл…** / **Новая папка…** | Создать внутри выбранной папки |
| **Переименовать** | |
| **Переместить в Корзину** | Отправить в Корзину без безвозвратного удаления |

В строках используются значки Material, подобранные по имени файла. В репозитории Git изменённые пути также отмечаются цветами и значками состояния, а игнорируемые файлы приглушены. Так дерево показывает то же состояние рабочего дерева, что и панель Git, без необходимости открывать её.

## Удалённые файлы [#remote-files]

Открывайте файлы SSH в панели «Файлы». Для создания, переименования, перемещения в удалённую корзину и сохранения включите **Настройки → Редактор → Файлы → Разрешить изменение удалённых файлов** (`files.remote-write-enabled`, по умолчанию включено).

Zshell использует только имеющиеся на узле инструменты и ничего не устанавливает. Чтение и редактирование используют имеющиеся основные модули Perl. Каждая запись также проверяет необходимые возможности файловой системы; неподдерживаемые операции отключены. Узел один раз за файловую операцию разрешает символические ссылки на каталоги в корне проекта и родительских каталогах; символические ссылки внутри проекта, специальные файлы и пути вне проекта отклоняются. Тексты UTF-8 ограничены 5 MiB; удалённый Markdown открывается как исходный текст.

Удалённое сохранение проверяет изменения даже при отключённой локальной защите. При конфликте можно сравнить версии, оставить черновик, перезагрузить с узла или разрешить перезапись. Сравненная версия проверяется непосредственно перед публикацией полного файла; внешний процесс всё ещё может записать данные после последней проверки.

**Переместить в удалённую корзину** сохраняет содержимое и исходный путь в закрытой папке проекта `.zshell-trash`. **Восстановить последний удалённый объект** восстанавливает последний объект, пока выбран текущий проект, не заменяя существующие имена. Более старые объекты можно восстановить вручную из этой папки.

## Импорт файлов и папок [#import-files-and-folders]

Выберите **Файл → Импортировать файлы…**, кнопку импорта в панели файлов или этот пункт в контекстном меню папки. Можно выбрать несколько файлов и папок: Zshell копирует их в выбранную папку или текущий корень дерева, сохраняя оригиналы.

Для перетаскивания объектов Finder в папку или пустую область дерева включите **Настройки → Редактор → Файлы → Импортировать перетаскиванием в дерево файлов** (`files.drag-import`). По умолчанию настройка включена; пункт меню остаётся доступен.

При совпадении имён доступны **Заменить**, **Пропустить** и **Отмена**. Папка заменяется целиком, её содержимое не объединяется. Отмена останавливает весь импорт и восстанавливает уже добавленные копии. Если другая программа изменит объект до восстановления, Zshell сохранит изменение и покажет папку, в которой могут находиться файлы для восстановления. Деревья SSH не принимают локальный импорт. Символические ссылки копируются как ссылки, без перехода к цели.

## Поиск файлов и содержимого [#find-files-and-search-contents]

Палитра команд (<kbd>Cmd</kbd>+<kbd>P</kbd>) находит файлы по имени или пути во всех локальных проектах, открытых в текущем окне, наряду с командами и открытыми сеансами. Выбор файла переключает на его проект и открывает файл там.

Для поиска текста внутри файлов нажмите лупу в панели «Файлы» или выберите **Поиск по содержимому файлов** в палитре команд. Введите текст и нажмите <kbd>Return</kbd>, чтобы искать в каталоге текущего локального проекта. Включите **Aa** для учёта регистра; открытие результата переносит на соответствующую строку в редакторе.

Поиск содержимого ищет буквальный текст, пропускает двоичные файлы и распространённые каталоги зависимостей и сборки и останавливается после 2 000 совпадений. Можно остановить поиск, сохранив найденные результаты, или закрыть его и вернуться к дереву файлов. Проекты SSH не участвуют в этом локальном поиске.

## Редактор [#the-editor]

Открытый файл отображается в полноценном редакторе внутри панели с подсветкой синтаксиса.

Локальный предпросмотр изображений PNG, JPEG, GIF, HEIC, WebP, TIFF, BMP и ICNS поддерживает обычные файлы размером до 64 MiB; для файлов большего размера появляется сообщение о том, что файл слишком большой.

| Действие | Сочетание клавиш |
| --- | --- |
| Сохранить | <kbd>Cmd</kbd>+<kbd>S</kbd> |
| Найти | <kbd>Cmd</kbd>+<kbd>F</kbd> |
| Найти и заменить | <kbd>Opt</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> |
| Найти следующее | <kbd>Cmd</kbd>+<kbd>G</kbd> |

При закрытии файла, просмотра изменений, проекта или окна рабочего пространства, а также при выходе из Zshell предлагается сохранить несохранённые изменения. **Отмена** или ошибка сохранения оставляет рабочее пространство и его терминалы открытыми. В режиме строки меню закрытие последнего окна лишь скрывает его и сохраняет правки; при выходе из приложения запрос сохранения остаётся.

По умолчанию длинные строки переносятся по ширине панели. Отключите [`editor.wrap-lines`](/ru/docs/configuration#editorwrap-lines), чтобы использовать горизонтальную прокрутку.

При переименовании файла в дереве обновляются все панели, в которых он открыт; это относится и к файлам внутри переименованной папки.

Если другая программа изменит открытый файл, Zshell обновит просмотр без локальных правок, когда приложение снова станет активным. Буфер редактора с несохранёнными изменениями никогда не заменяется.

Если другая программа изменила файл во время редактирования, при сохранении откроется диалог конфликта. **Сравнить…** показывает диск и черновик рядом; **Сохранить черновик** отменяет запись, **Перезагрузить с диска** удаляет черновик, а **Перезаписать файл** заменяет сравниваемую версию. Проверка действует и перед закрытием, и в редактируемых diff. Управляйте ей в **Настройки → Редактор → Защита от конфликтов при сохранении** или [`editor.protect-saves`](/ru/docs/configuration#editorprotect-saves).

<Callout type="info">
Этот редактор предназначен для изменения, которое вы уже рассматриваете: исправить опечатку, скорректировать константу, прочитать файл, на который ссылается diff. Здесь нет языкового сервера, автодополнения и рефакторинга всего проекта. Это осознанное решение.
</Callout>

## Восстановление несохранённых черновиков [#recover-unsaved-drafts]

Zshell по умолчанию создаёт копии несохранённых изменений локальных файлов и редактируемых diff рабочего дерева. После неожиданного завершения повторно открытые панели восстанавливают черновики, выделения и расположение. Другие копии доступны через **Файл → Восстановить черновики…** или **Настройки → Редактор → Восстановить черновики…**: выберите копию, проверьте содержимое и нажмите **Восстановить черновик**. Восстановление открывает несохранённый редактор и не меняет файл на диске. При сохранении внешние изменения по-прежнему сравниваются с версией до ваших правок.

Управляйте копиями через **Настройки → Редактор → Сохранять резервные копии черновиков** или `editor.recover-drafts`. Отключение останавливает новые копии и автоматическое восстановление, но оставляет существующие копии для ручного восстановления или удаления. **Удалить копию** удаляет только выбранную копию; открытые правки сохраняются. Успешное сохранение или **Не сохранять** при завершённом закрытии удаляет копию. Эти частные файлы хранятся на этом Mac: до 32 черновиков и 128 MiB с возможностью восстановления в течение не более 30 дней. При достижении лимитов более старые копии могут быть удалены раньше. Файлы и изменённый текст более 5 MiB исключены.

Zshell удаляет просроченные копии при запуске и каждый час во время работы, даже если резервное копирование отключено. Если Zshell закрыт, просроченные файлы остаются на диске до следующего запуска.

## Предпросмотр Markdown [#markdown-preview]

Откройте файл `.md`, чтобы увидеть его отрисованный предпросмотр в той же панели. Нажмите **Редактировать** в правом верхнем углу для работы с исходным текстом, затем **Предпросмотр**, чтобы увидеть результат. Zshell запоминает выбранный режим для других файлов Markdown и следующего запуска.

При переключении режимов сохраняются правки и история отмены. Сохраняйте изменения сочетанием <kbd>Cmd</kbd>+<kbd>S</kbd>, как обычно. Файлы Markdown с другими расширениями открываются как исходный текст.

## Просмотр изменений [#diffs]

Diff, открытый из [панели Git](/ru/docs/git), — такая же панель, поэтому изменения, файл и терминал могут находиться рядом в одной вкладке. В нём используется шрифт вашего терминала, а набор изменений из тысячи файлов открывается так же быстро, как однострочный. Актуальные изменения рабочего дерева, ещё не добавленные в индекс, можно переключить из режима просмотра в режим редактирования; индексированные и исторические изменения остаются доступными только для чтения. См. [Чтение изменений](/ru/docs/git#reading-diffs).
